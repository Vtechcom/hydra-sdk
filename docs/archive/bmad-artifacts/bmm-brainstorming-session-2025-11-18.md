##### Branch #1: 📚 Documentation & Learning

**Sub-branch: Getting Started**
- Welcome section with "What is Hydra SDK?"
- Key differentiators showcase:
  - ✨ WASM-powered (performance)
  - ⚡ Vite/Rollup compatibility
  - 🔷 TypeScript-first with full type safety
  - 🚀 Layer 2 Hydra Protocol scaling
  - 💎 Developer-friendly API

##### Branch #2: ⚡ First Experience (Onboarding)

**Sub-branch: Installation & First Steps**

Installation:
```bash
npm install @hydra-sdk/core @hydra-sdk/cardano-wasm
```

Two Primary Onboarding Paths:
- **Path 1: New Wallet** 
  - `new AppWallet()` for fresh start
  - `getPaymentAddress()` to get address
  - Ideal for new developers
  
- **Path 2: Import Existing Keys**
  - `new CardanoCliWallet()` for existing keys
  - `getAddressBech32()` to get address  
  - Perfect for Cardano CLI users

Current Quick-Start Features:
- ✅ Quick-start page in docs
- ✅ Two clear paths documented
- ✅ Copy-paste code snippets

Enhancement Ideas Generated:
- Path decision helper ("Which path for you?")
- Tabbed interface for comparing paths
- "What's Next?" section after first success
- Common issues troubleshooting
- Interactive playground embedded
