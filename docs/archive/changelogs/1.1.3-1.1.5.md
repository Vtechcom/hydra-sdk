## Version 1.1.3 - October 29, 2025

### 🧪 Testing & CI/CD Infrastructure
- **GitHub Actions Workflows**: Comprehensive CI/CD pipeline for automated testing
  - **Jest Configuration**: Added Jest config with coverage reporting and JUnit support
  - **Test Workflow**: Automated testing workflow with detailed reporting and coverage metrics
  - **GitHub Secrets Setup**: Documentation and configuration for environment variables in CI/CD
  - **Test Commands**: Added `test:ci` script for continuous integration testing

### 🛠️ Core Utilities Improvements
- **Metadata Utilities**: Added utility functions to convert different metadata types into `CardanoWASM.TransactionMetadatum`
  - Support for Map, List, String, Number, Boolean metadata types
  - Enhanced type safety for Plutus datum operations
- **Converter Fixes**: Fixes and optimizations for converter utilities used in UTxO transformation
  - Improved performance for conversion operations
  - Better error handling and validation
