# Configuration

Hydra SDK leverages WebAssembly (WASM) for high-performance Cardano operations. This guide covers how to configure your build tools and environment for optimal performance.

## 📂 Full Examples

For complete working examples with full configuration, check out our examples repository:
- **[React + Vite Example](/examples/full-react-app)** - Complete React application setup
- **[Vue.js + TypeScript Example](/examples/full-vuejs-app)** - Complete Vue.js application setup
- **[Examples Repository](https://github.com/Vtechcom/hydra-sdk-examples)** - All examples on GitHub

## Nuxt 3

For Nuxt.js projects, configure your `nuxt.config.ts`:

```typescript
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineNuxtConfig({
  ssr: false, // Disable SSR for wallet applications
  
  vite: {
    plugins: [
      wasm(),
      topLevelAwait(),
      nodePolyfills({
        include: ['buffer'],
        globals: {
          Buffer: true,
          global: false,
          process: false
        }
      })
    ],
    optimizeDeps: {
      exclude: ['@hydra-sdk/cardano-wasm']
    }
  }
})
```

## Next.js Configuration

Configure Next.js in your `next.config.js`:

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  webpack: (config, { isServer }) => {
    if (!isServer) {
      config.experiments = {
        ...config.experiments,
        asyncWebAssembly: true,
      }
      
      config.resolve.fallback = {
        ...config.resolve.fallback,
        crypto: false,
        stream: false,
        util: false,
        buffer: require.resolve('buffer')
      }
    }
    
    return config
  },
  
  // Disable static optimization for wallet pages
  experimental: {
    esmExternals: 'loose'
  }
}

module.exports = nextConfig
```

For Next.js 13+ with app directory, also create a `globals.d.ts`:

```typescript
declare global {
  var Buffer: typeof import('buffer').Buffer
}

export {}
```
