# @hydra-sdk/bridge — Overview

Complete Hydra L2 integration: WebSocket connections, event handling, Head lifecycle commands, and transaction processing — compatible with hydra-node v1.3.0+.

## Key Features

- **hydra-node v1.3.0 compatibility** — `Greetings` extended fields, `/head` API, `slotZeroTimestamp`
- **O(1) balance & UTxO reads** — pre-computed in-memory snapshot cache; no I/O per balance call
- **Dual submit API** — `submitTxSync` (Promise) and `submitTx` (error-first callback)
- **Auto-reconnect** — configurable interval and max-attempts; safe cancellation on `disconnect()`
- **5 URL formats supported** — `ws://`, `wss://`, `http://`, `https://`, gateway with `?X-Api-Key=`

## Installation

```bash
npm install @hydra-sdk/bridge
```

## Quick Example

```ts
import { HydraBridge } from '@hydra-sdk/bridge'

const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	verbose: true,
	autoReconnect: true
})

bridge.events.on('onConnected', () => bridge.commands.init())
bridge.events.on('onMessage', payload => {
	if (payload.tag === 'HeadIsOpen') {
		// O(1) balance from in-memory cache
		const balance = bridge.getAddressBalance('addr_test1...')
		console.log('ADA:', balance?.get('lovelace'))
	}
})
bridge.connect()
```
