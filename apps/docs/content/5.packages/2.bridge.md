# @hydra-sdk/bridge — Overview

Provides complete Hydra L2 integration: connections, events, commands, and transaction processing.

## Installation

```bash
npm install @hydra-sdk/bridge
```

## Quick Example

```ts
import { HydraBridge } from '@hydra-sdk/bridge'

const bridge = new HydraBridge({ url: 'ws://localhost:4001', verbose: true })
bridge.events.on('onConnected', () => bridge.commands.init())
bridge.connect()
```
