# @hydra-sdk/core — Overview

Provides Cardano wallet functionality: HD wallet management, transaction signing, network integration, serialization utils, key utilities, and high-performance UTxO conversion.

## What's New in v1.3.0

- **`convertUTxOObjectToUTxOWithOptions`** — bounded datum deserialization cache (LRU, configurable size) for large snapshot processing
- **Converter optimizations** — `for` loops replace `reduce`/`filter` chains; no intermediate array allocations
- **Benchmark script** — `scripts/bench-converter.ts` for measuring throughput under load

## Installation

```bash
npm install @hydra-sdk/core
```

## Network Configuration

```ts
enum NETWORK_ID {
	TESTNET = 0,
	MAINNET = 1,
	PREPROD = 0
}

const wallet = new AppWallet({
	networkId: NETWORK_ID.MAINNET,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
```

## Quick Example

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

const wallet = new AppWallet({
	networkId: NETWORK_ID.PREPROD,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
const account = wallet.getAccount(0, 0)
console.log('Base:', account.baseAddressBech32)
```
