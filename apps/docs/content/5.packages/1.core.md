# @hydra-sdk/core — Overview

Provides Cardano wallet functionality: HD wallet management, transaction signing, network integration, serialization utils, key utilities, and high-performance UTxO conversion.

## What's New in v1.4.0

- **`RedeemerUtils` namespace (new)** — `mkRedeemer`, `mkSpendRedeemer`, `mkMintRedeemer`, `mkUnitRedeemer`, `mkExUnits`, `mkRedeemerTag` and `DEFAULT_EX_UNITS` for building Plutus redeemers directly from `PlutusData`
- **New `DatumUtils` encoders** — `mkBool`, `mkOption`, `mkBytesList`, `mkIntList`, `mkOutputRef`, `mkAddress`, `parseAddress` (plus `mkList`, added in v1.3.2)
- **Validation/address reorg** — new `ValidationUtils.isValidTxOutput`; `AddressUtils` now owns `isValidAddress` and `getPubkeyHashFromAddress`. The old `ValidatorUtils` namespace is **deprecated** (kept only as a back-compat re-export)
- **`Deserializer.deserializeAmountsFromTx(cborHex)`** — returns all output amounts across a transaction, merged by unit
- **Protocol v11 parameters** — `DEFAULT_PROTOCOL_PARAMETERS` updated (`minPoolCost = 170000000`)
- **Resolver memory-leak fix** — `resolveTxHash` now frees the underlying `FixedTransaction`

## Installation

```bash
npm install @hydra-sdk/core
```

## Network Configuration

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

// NETWORK_ID is a Record<Network, number> — NOT an enum.
// Keys are 'MAINNET' | 'PREPROD' | 'PREVIEW' (there is no TESTNET):
//   NETWORK_ID = { MAINNET: 1, PREPROD: 0, PREVIEW: 0 }

const wallet = new AppWallet({
	networkId: NETWORK_ID.MAINNET, // 1
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
```

## Quick Example

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

const wallet = new AppWallet({
	networkId: NETWORK_ID.PREPROD,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
const account = wallet.getAccount(0, 0)
console.log('Base:', account.baseAddressBech32)
```
