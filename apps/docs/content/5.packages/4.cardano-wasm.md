# @hydra-sdk/cardano-wasm — Overview

Provides comprehensive WASM bindings for Cardano operations: Value/Address/Tx/Script, metadata, hashing, witness, etc.

## Installation

```bash
npm install @hydra-sdk/cardano-wasm
```

## Tips

- Use `vite-plugin-wasm` and `vite-plugin-top-level-await` when running in browser
- Exclude `@hydra-sdk/cardano-wasm` from optimizeDeps
