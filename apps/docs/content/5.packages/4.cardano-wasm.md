# @hydra-sdk/cardano-wasm

The Cardano WASM package provides bindings for advanced blockchain operations, including transaction building, metadata handling, and cryptographic utilities.

## Installation

```bash
npm install @hydra-sdk/cardano-wasm
```

## Usage
```typescript
import { CardanoWASM } from '@hydra-sdk/cardano-wasm';

const { 
  min_fee, 
  min_script_fee, 
  min_ref_script_fee, 
  encode_json_str_to_metadatum
} = CardanoWASM;

// Example usage
const transaction = /* your transaction object */;
const linearFee = /* your linear fee object */;
const fee = min_fee(transaction, linearFee);
console.log('Minimum fee:', fee.to_str());

```

## Key Functions

### Transaction Fees

**`min_fee(tx, linear_fee)`**
Calculate the minimum fee for a transaction:

```typescript
const fee = min_fee(transaction, linearFee)
console.log('Minimum fee:', fee.to_str())
```

**`min_script_fee(tx, ex_unit_prices)`**
Calculate the minimum fee for Plutus scripts:

```typescript
const scriptFee = min_script_fee(transaction, exUnitPrices)
console.log('Minimum script fee:', scriptFee.to_str())
```

**`min_ref_script_fee(total_ref_scripts_size, ref_script_coins_per_byte)`**
Calculate the minimum fee for reference scripts:

```typescript
const refScriptFee = min_ref_script_fee(1024, refScriptCoinsPerByte)
console.log('Minimum reference script fee:', refScriptFee.to_str())
```

### Metadata Encoding and Decoding

**`encode_json_str_to_metadatum(json, schema)`**
Encode JSON to transaction metadata:

```typescript
const metadata = encode_json_str_to_metadatum('{"key": "value"}', MetadataJsonSchema)
console.log('Encoded metadata:', metadata)
```

**`decode_metadatum_to_json_str(metadatum, schema)`**
Decode transaction metadata to JSON:

```typescript
const json = decode_metadatum_to_json_str(metadata, MetadataJsonSchema)
console.log('Decoded JSON:', json)
```

**`encode_arbitrary_bytes_as_metadatum(bytes)`**
Encode arbitrary bytes as metadata:

```typescript
const metadata = encode_arbitrary_bytes_as_metadatum(new Uint8Array([0x01, 0x02]))
console.log('Encoded metadata:', metadata)
```

**`decode_arbitrary_bytes_from_metadatum(metadata)`**
Decode arbitrary bytes from metadata:

```typescript
const bytes = decode_arbitrary_bytes_from_metadatum(metadata)
console.log('Decoded bytes:', bytes)
```

### Plutus Data Encoding and Decoding

**`encode_json_str_to_plutus_datum(json, schema)`**
Encode JSON to Plutus datum:

```typescript
const datum = encode_json_str_to_plutus_datum('{"key": "value"}', PlutusDatumSchema)
console.log('Encoded Plutus datum:', datum)
```

**`decode_plutus_datum_to_json_str(datum, schema)`**
Decode Plutus datum to JSON:

```typescript
const json = decode_plutus_datum_to_json_str(datum, PlutusDatumSchema)
console.log('Decoded JSON:', json)
```

### Witness Creation

**`make_daedalus_bootstrap_witness(tx_body_hash, addr, key)`**
Create a Daedalus bootstrap witness:

```typescript
const witness = make_daedalus_bootstrap_witness(txBodyHash, byronAddress, legacyKey)
console.log('Daedalus bootstrap witness:', witness)
```

**`make_icarus_bootstrap_witness(tx_body_hash, addr, key)`**
Create an Icarus bootstrap witness:

```typescript
const witness = make_icarus_bootstrap_witness(txBodyHash, byronAddress, bip32Key)
console.log('Icarus bootstrap witness:', witness)
```

**`make_vkey_witness(tx_body_hash, sk)`**
Create a verification key witness:

```typescript
const vkeyWitness = make_vkey_witness(txBodyHash, privateKey)
console.log('Verification key witness:', vkeyWitness)
```

### Hashing Utilities

**`hash_auxiliary_data(auxiliary_data)`**
Hash auxiliary data:

```typescript
const auxDataHash = hash_auxiliary_data(auxiliaryData)
console.log('Auxiliary data hash:', auxDataHash)
```

**`hash_plutus_data(plutus_data)`**
Hash Plutus data:

```typescript
const dataHash = hash_plutus_data(plutusData)
console.log('Plutus data hash:', dataHash)
```

**`hash_script_data(redeemers, cost_models, datums?)`**
Hash script data:

```typescript
const scriptDataHash = hash_script_data(redeemers, costModels, datums)
console.log('Script data hash:', scriptDataHash)
```

### Transaction Utilities

**`get_implicit_input(txbody, pool_deposit, key_deposit)`**
Get implicit input for a transaction:

```typescript
const implicitInput = get_implicit_input(txBody, poolDeposit, keyDeposit)
console.log('Implicit input:', implicitInput)
```

**`get_deposit(txbody, pool_deposit, key_deposit)`**
Get deposit for a transaction:

```typescript
const deposit = get_deposit(txBody, poolDeposit, keyDeposit)
console.log('Deposit:', deposit)
```

**`min_ada_for_output(output, data_cost)`**
Calculate the minimum ADA required for an output:

```typescript
const minAda = min_ada_for_output(transactionOutput, dataCost)
console.log('Minimum ADA for output:', minAda.to_str())
```

### Cryptographic Utilities

**`encrypt_with_password(password, salt, nonce, data)`**
Encrypt data with a password:

```typescript
const encryptedData = encrypt_with_password('password', 'salt', 'nonce', 'data')
console.log('Encrypted data:', encryptedData)
```

**`decrypt_with_password(password, data)`**
Decrypt data with a password:

```typescript
const decryptedData = decrypt_with_password('password', encryptedData)
console.log('Decrypted data:', decryptedData)
```
