# @hydra-sdk/transaction — Overview

Provides tools for building and submitting transactions, with support for Plutus, multi-asset, staking, and Hydra.

## Installation

```bash
npm install @hydra-sdk/transaction
```

## Quick Example

```ts
import { TxBuilder } from '@hydra-sdk/transaction'

const tx = await new TxBuilder()
	.txOut('addr_test1...', [{ unit: 'lovelace', quantity: '1000000' }])
	.changeAddress('addr_test1...')
	.complete()
```
