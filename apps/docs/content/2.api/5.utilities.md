# Utilities

The Hydra SDK provides a comprehensive collection of utility functions to help you work with Cardano blockchain data, WASM operations, and common development tasks.

## Overview

The utilities are organized into several categories:

- **[Keys Utilities](#keys-utilities)** - Key generation and management
- **[Cardano WASM Utilities](#cardano-wasm-utilities)** - Low-level blockchain operations
- **[Data Parsing](#data-parsing)** - Convert between different data formats
- **[Datum Utilities](#datum-utilities)** - Work with Plutus data structures
- **[Policy Utilities](#policy-utilities)** - Minting policy management
- **[Metadata Utilities](#metadata-utilities)** - Transaction metadata conversion
- **[Time Utilities](#time-utilities)** - Time and slot calculations
- **[Provider Utilities](#provider-utilities)** - Blockchain data provider abstractions

## Usage

All utilities are exported as namespaced modules for better organization:

```typescript
import {
  Serializer,
  Deserializer,
  Resolver,
  Converter,
  BuildKeys,
  ParserUtils,
  TimeUtils,
  DatumUtils,
  PolicyUtils,
  MetadataUtils,
  ProviderUtils,
  CostModels,
  KeysUtils,
  SLOT_CONFIG_NETWORK
} from '@hydra-sdk/core'
```

## Keys Utilities (v1.1.4+)
Utilities for generating and managing cryptographic keys.

### KeysUtils

`KeysUtils` provides functions for key generation and conversion compatible with Cardano CLI and Hydra.

```typescript
import { KeysUtils } from '@hydra-sdk/core'

// Generate Cardano CLI compatible ed25519 key pair
const cardanoKeys = KeysUtils.cardanoCliKeygen()
// cardanoKeys.sk: PaymentSigningKeyShelley_ed25519
// cardanoKeys.vk: PaymentVerificationKeyShelley_ed25519

// Generate Hydra compatible ed25519 key pair
const hydraKeys = KeysUtils.hydraCliKeygen()
// hydraKeys.sk: HydraSigningKey_ed25519
// hydraKeys.vk: HydraVerificationKey_ed25519

// Generate verification key from signing key
const vkey = KeysUtils.genVkey(cardanoKeys.sk)
```

**Available Functions:**
- `cardanoCliKeygen()` – Generate a Cardano CLI compatible ed25519 key pair
- `hydraCliKeygen()` – Generate a Hydra compatible ed25519 key pair
- `genVkey(skey)` – Generate verification key from signing key

**Types:**
- `CardanoCLiSkey`: 
  ```js
  { 
    type: 'PaymentSigningKeyShelley_ed25519', 
    description: 'Payment Signing Key', 
    cborHex: '5820...' 
  }
  ```
- `CardanoCLiVkey`: 
  ```js
  { 
    type: 'PaymentVerificationKeyShelley_ed25519', 
    description: 'Payment Verification Key', 
    cborHex: '5820...' 
  }
  ```
- `HydraCliSkey`: 
  ```js
  { 
    type: 'HydraSigningKey_ed25519', 
    description: 'Hydra Signing Key', 
    cborHex: '5820...' 
  }
  ```
- `HydraCliVkey`: 
  ```js
  { 
    type: 'HydraVerificationKey_ed25519', 
    description: 'Hydra Verification Key', 
    cborHex: '5820...' 
  }
  ```

## Data Parsing

Parser utilities for converting between different data formats.

### ParserUtils

`ParserUtils` provides functions for converting between bytes, hex, and UTF-8 strings.

```typescript
import { ParserUtils } from '@hydra-sdk/core'

// Convert bytes to hex string
const hex = ParserUtils.bytesToHex(bytes)
// Convert hex string to bytes
const bytes = ParserUtils.hexToBytes('deadbeef')
// Convert UTF-8 string to hex
const hexString = ParserUtils.stringToHex('Hello World')
// Convert hex string to UTF-8 string
const str = ParserUtils.hexToString(hexString)
// Convert string or hex to bytes
const bytes2 = ParserUtils.toBytes('Hello World')
// Convert UTF-8 string to hex (alias)
const hex2 = ParserUtils.fromUTF8('Hello World')
// Convert hex string to UTF-8 string (alias)
const str2 = ParserUtils.toUTF8(hexString)
```

**Available Functions:**
- `bytesToHex(bytes: ArrayBuffer | Uint8Array | Buffer): string` – Convert bytes to hex string
- `hexToBytes(hex: string): Buffer` – Convert hex string to bytes
- `stringToHex(str: string): string` – Convert UTF-8 string to hex
- `hexToString(hex: string): string` – Convert hex string to UTF-8 string
- `toBytes(strOrHex: string): Uint8Array` – Convert string or hex to bytes
- `fromUTF8(str: string): string` – Convert UTF-8 string to hex string
- `toUTF8(hex: string): string` – Convert hex string to UTF-8 string

## Datum Utilities

Utilities for working with Plutus data structures and datums.

### DatumUtils

`DatumUtils` provides functions for creating PlutusData primitives and collections.

```typescript
import { DatumUtils } from '@hydra-sdk/core'

// Create integer datum
const intDatum = DatumUtils.mkInt(42)
// Create bytes datum
const bytesDatum = DatumUtils.mkBytes('deadbeef')
// Create constructor datum
const constrDatum = DatumUtils.mkConstr(0, [intDatum, bytesDatum])
// Create map datum
const mapDatum = DatumUtils.mkMap([[intDatum, bytesDatum]])
```

**Available Functions:**
- `mkInt(n: string | number | bigint): PlutusData` – Create integer datum
- `mkBytes(hex: string): PlutusData` – Create bytes datum from hex string
- `mkConstr(alt: number, fields: PlutusData[]): PlutusData` – Create constructor datum
- `mkMap(entries: Array<[PlutusData, PlutusMapValues]>): PlutusData` – Create map datum

## Policy Utilities

Utilities for working with minting policies and native scripts.

### PolicyUtils

`PolicyUtils` provides functions for building policy scripts and extracting policy IDs.

```typescript
import { PolicyUtils } from '@hydra-sdk/core'

// Build policy script from public key
const policyScript = PolicyUtils.buildPolicyScriptFromPubkey({ type: 'sig', keyHash: 'abc123...' })
// Build minting policy script from address
const mintingScript = PolicyUtils.buildMintingPolicyScriptFromAddress('addr1qx2fxv2umyhttkxyxp8x0dlpdt3k6cwng5pxj3jhsydzer3jcu5d8ps7zex2k2xt3uqxgjqnnj83ws8lhrn648jjxtwq2ytjqp')
// Build minting policy script from key hash
const mintingScript2 = PolicyUtils.buildMintingPolicyScriptFromKeyHash('abc123...')
// Extract policy ID from native script
const policyId = PolicyUtils.policyIdFromNativeScript(policyScript)
```

**Available Functions:**
- `buildPolicyScriptFromPubkey(pubkeyScript): string` – Build policy script from public key
- `buildMintingPolicyScriptFromAddress(addressBech32: string): string` – Build minting policy from address
- `buildMintingPolicyScriptFromKeyHash(keyHash: string): string` – Build minting policy from key hash
- `policyIdFromNativeScript(nativeScript: string): string` – Extract policy ID from native script

## Metadata Utilities

Utilities for converting various data types to Cardano transaction metadata format.

### MetadataUtils

`MetadataUtils` provides a function to convert different types to Cardano transaction metadata.

```typescript
import { MetadataUtils } from '@hydra-sdk/core'

// Convert string to metadata
const stringMetadata = MetadataUtils.metadataObjToMetadatum('Hello World')

// Convert number to metadata
const numberMetadata = MetadataUtils.metadataObjToMetadatum(42)

// Convert bigint to metadata
const bigintMetadata = MetadataUtils.metadataObjToMetadatum(9007199254740991n)

// Convert bytes to metadata
const bytesMetadata = MetadataUtils.metadataObjToMetadatum(new Uint8Array([1, 2, 3, 4]))

// Convert array to metadata
const arrayMetadata = MetadataUtils.metadataObjToMetadatum(['item1', 42, new Uint8Array([5, 6])])

// Convert object to metadata map
const objectMetadata = MetadataUtils.metadataObjToMetadatum({ name: 'NFT Name', image: 'ipfs://...', attributes: ['trait1', 'trait2'] })

// Convert Map to metadata
const mapMetadata = MetadataUtils.metadataObjToMetadatum(new Map([['key1', 'value1'], ['key2', 42]]))
```

**Available Functions:**
- `metadataObjToMetadatum(metadata): CardanoWASM.TransactionMetadatum` – Convert various types to metadata

**Supported Types:**
- String, Number, BigInt, Uint8Array, Array, Object, Map

**Important Notes:**
- Maximum metadata `bytes` size is **64 bytes**
- Maximum metadata `text` size is **64 characters**
- Arrays and Maps are processed recursively, be mindful of total metadata size

## Time Utilities

Utilities for working with Cardano time slots and timestamps.

### TimeUtils

`TimeUtils` provides functions for slot and epoch calculations, and slot configuration.

```typescript
import { TimeUtils, SLOT_CONFIG_NETWORK } from '@hydra-sdk/core'

// Convert slot to Unix timestamp
const timestamp = TimeUtils.slotToBeginUnixTime(slot, SLOT_CONFIG_NETWORK.PREPROD)
// Convert Unix timestamp to slot
const slot = TimeUtils.unixTimeToEnclosingSlot(timestamp, SLOT_CONFIG_NETWORK.PREPROD)
// Resolve slot number from timestamp
const slotNo = TimeUtils.resolveSlotNo(Date.now())
// Resolve epoch number from timestamp
const epochNo = TimeUtils.resolveEpochNo(Date.now())
// Build Hydra slot config for a specific timestamp
const slotConfig = TimeUtils.buildHydraSlotConfig(Date.now())
```

**Available Functions:**
- `slotToBeginUnixTime(slot: number, slotConfig: SlotConfig): number` – Convert slot to Unix timestamp
- `unixTimeToEnclosingSlot(unixTime: number, slotConfig: SlotConfig): number` – Convert timestamp to slot
- `resolveSlotNo(unixTime: number): string` – Resolve slot number based on timestamp
- `resolveEpochNo(unixTime: number): number` – Resolve epoch number based on timestamp
- `buildHydraSlotConfig(unixTime: number): SlotConfig` – Build Hydra slot configuration for a specific timestamp

## Provider Utilities

Utilities for working with different blockchain data providers.

### ProviderUtils

The SDK supports multiple provider implementations:

- **BaseProvider** - Abstract base class for all providers
- **BlockfrostProvider** - Blockfrost API integration
- **OgmiosProvider** - Ogmios WebSocket integration

```typescript
import { ProviderUtils } from '@hydra-sdk/core'

// Create Blockfrost provider
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  projectId: 'your-project-id',
  network: 'preprod'
})

// Create Ogmios provider
const ogmiosProvider = new ProviderUtils.OgmiosProvider({
  url: 'ws://localhost:1337'
})

// Use provider methods
const utxos = await provider.getUtxos(address)
const protocolParams = await provider.getProtocolParameters()
```

**Provider Interface:**

All providers implement a common interface with methods for:
- UTxO queries
- Protocol parameter retrieval
- Transaction submission
- Address validation
- Asset information

## Examples

### Basic Utility Usage

```typescript
import { 
  ParserUtils,
  TimeUtils, 
  DatumUtils,
  PolicyUtils,
  SLOT_CONFIG_NETWORK
} from '@hydra-sdk/core'

// Data conversion
const hex = ParserUtils.stringToHex('Hello Cardano')
const bytes = ParserUtils.hexToBytes(hex)

// Time utilities
const currentSlot = TimeUtils.unixTimeToEnclosingSlot(Date.now(), SLOT_CONFIG_NETWORK.PREPROD)
const readableTime = new Date(TimeUtils.slotToBeginUnixTime(currentSlot, SLOT_CONFIG_NETWORK.PREPROD))

// Datum creation
const datum = DatumUtils.mkConstr(0, [
  DatumUtils.mkInt(42),
  DatumUtils.mkBytes(hex)
])

console.log('Current slot:', currentSlot)
console.log('Readable time:', readableTime.toLocaleString())
console.log('Datum hex:', datum.to_hex())
```
