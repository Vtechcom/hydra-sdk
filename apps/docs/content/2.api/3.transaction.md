# @hydra-sdk/transaction API Reference

The transaction package provides advanced tools for building, managing, and submitting Cardano transactions, including support for Plutus scripts, multi-asset transactions, staking operations, and Hydra Layer 2 integration.

## TxBuilder

The main class for building and managing Cardano transactions with comprehensive support for all Cardano features.

### Constructor

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'

// Basic transaction builder
const txBuilder = new TxBuilder()

// With custom protocol parameters
const txBuilder = new TxBuilder({
  params: {
    minFeeA: 44,
    minFeeB: 155381,
    maxTxSize: 16384
  }
})

// For Hydra transactions
const txBuilder = new TxBuilder({
  isHydra: true,
  params: protocolParams,
  verbose: true
})

// With custom fetcher and submitter
const txBuilder = new TxBuilder({
  fetcher: customFetcher,
  submitter: customSubmitter,
  verbose: true
})
```

### # Transaction Input Methods

### **`txIn(txHash, outputIndex, amount, address)`**
Add a transaction input:

```typescript
// Basic input
txBuilder.txIn(
  'a1b2c3d4e5f6...', // transaction hash
  0,                 // output index
  [{ unit: 'lovelace', quantity: '2000000' }], // amount (optional)
  'addr_test1...'    // address (optional)
)

// For script validation
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
  .txInDatumHash(datum)
  .txInEmptyRedeemer()
```

### **`txInScript(scriptCbor)`**
Attach a Plutus script to the last input:

```typescript
const scriptCbor = '590a4c590a49010000...'
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
```

### **`txInDatumHash(datum)`**
Add datum hash to script input:

```typescript
const datum = CardanoWASM.PlutusData.from_hex('d87980')
txBuilder.txIn(txHash, outputIndex)
  .txInDatumHash(datum)
```

### **`txInInlineDatum(inlineDatum)`**
Add inline datum to script input:

```typescript
const inlineDatum = CardanoWASM.PlutusData.from_hex('d87980')
txBuilder.txIn(txHash, outputIndex)
  .txInInlineDatum(inlineDatum)
```

### **`txInEmptyRedeemer()`**
Add an empty redeemer for script input:

```typescript
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
  .txInEmptyRedeemer()
```

### **`spendingPlutusScript(version)`**
Set Plutus script version for the last input:

```typescript
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
  .spendingPlutusScript('V3') // 'V1', 'V2', or 'V3'
```

### Simple ADA Transfer

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet } from '@hydra-sdk/core'

async function sendAda() {
  const wallet = new AppWallet({
    networkId: 0,
    key: { type: 'mnemonic', words: AppWallet.brew() }
  })

  const account = wallet.getAccount(0, 0)
  const utxos = await wallet.queryUtxos(account.baseAddressBech32)

  const txBuilder = new TxBuilder({ verbose: true })
  
  const tx = await txBuilder
    .selectUtxosFrom(utxos)
    .txOut('addr_test1qqr585tvlc7ylnqvz8pyqwauzrdu0mxag3m7q56grgmgu7sxu2hyfhlkwuxupa9d5085eunq2qywy7hvmvej456flknswgndm3', [
      { unit: 'lovelace', quantity: '2000000' }
    ])
    .changeAddress(account.baseAddressBech32)
    .complete()

  const signedTx = await wallet.signTx(tx.to_hex(), false, 0, 0)
  console.log('Signed transaction:', signedTx)
}
```

### Plutus Script Interaction

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { CardanoWASM } from '@hydra-sdk/core'

async function interactWithPlutusScript() {
  const scriptCbor = 'plutus_script_cbor'
  const scriptAddress = 'script_address'
  
  // Create datum
  const datum = CardanoWASM.PlutusData.new_map(
    CardanoWASM.PlutusMap.new()
  )

  // Create empty redeemer
  const redeemer = CardanoWASM.Redeemer.new(
    CardanoWASM.RedeemerTag.new_spend(),
    CardanoWASM.BigNum.from_str('0'),
    CardanoWASM.PlutusData.new_empty_constr_plutus_data(CardanoWASM.BigNum.zero()),
    CardanoWASM.ExUnits.new(
      CardanoWASM.BigNum.from_str('14000000'),
      CardanoWASM.BigNum.from_str('10000000000')
    )
  )

  const txBuilder = new TxBuilder({ verbose: true })
  
  const tx = await txBuilder
    .selectUtxosFrom(utxos)
    // Spend from script
    .txIn(scriptUtxoHash, scriptUtxoIndex)
    .txInScript(scriptCbor)
    .txInDatumHash(datum)
    .txInRedeemerValue(redeemer)
    // Add collateral
    .txInCollateral(collateralHash, 0, [{ unit: 'lovelace', quantity: '5000000' }], collateralAddress)
    // Outputs
    .txOut(recipientAddress, [{ unit: 'lovelace', quantity: '10000000' }])
    .changeAddress(changeAddress)
    .complete()

  return tx
}
```

### Hydra Transaction

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

async function createHydraTransaction() {
  // Get protocol parameters from Hydra Head
  const bridge = new HydraBridge({ url: 'ws://localhost:4001' })
  const connected = await bridge.connect()
  if (!connected) {
    throw new Error('Failed to connect to Hydra Head')
  }
  const protocolParams = await bridge.getProtocolParameters()
  const headUtxos = await bridge.queryAddressUTxO(senderAddress)

  // Build transaction for Hydra Head
  const txBuilder = new TxBuilder({
    isHydra: true,
    params: protocolParams,
    verbose: true
  })
  
  const tx = await txBuilder
    .setInputs(headUtxos)
    .txOut('<recipientAddress>', [
      { unit: 'lovelace', quantity: '1000000' }
    ])
    .changeAddress('<senderAddress>')
    .complete()

  const txId = deserializeTx(tx.to_hex()).transaction_hash().to_hex()
  const signedTx = await wallet.signTx(tx.to_hex(), false, 0, 0)

  // Submit to Hydra Head
  const result = await bridge.submitTxSync({
    type: 'Witnessed Tx ConwayEra',
    description: 'Ledger Cddl Format',
    cborHex: signedTx,
    txId
  })

  return result
}
```

## Best Practices

1. **UTxO Selection**: Use appropriate coin selection strategies for different use cases
2. **Fee Management**: Always calculate minimum fees and add appropriate buffer
3. **Script Validation**: Ensure proper datum, redeemer, and script attachment for Plutus scripts
4. **Collateral**: Include sufficient collateral for script transactions
5. **Metadata Standards**: Follow established metadata standards (CIP-25 for NFTs)
6. **Error Handling**: Implement comprehensive error handling for transaction building
7. **Testing**: Test transactions on testnets before mainnet deployment
8. **Resource Management**: Reset builders after use to free memory
