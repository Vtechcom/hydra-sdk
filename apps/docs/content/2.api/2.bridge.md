# @hydra-sdk/bridge API Reference

The bridge package provides complete Hydra Layer 2 integration with real-time event handling, Head lifecycle management, and transaction processing.

## HydraBridge

Main class for connecting to and managing Hydra Heads.

### Constructor

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

// Direct WebSocket connection
const bridge = new HydraBridge({
  url: 'ws://localhost:4001',
  verbose: true
})

// Using custom connector
const bridge = new HydraBridge({
  connector: customConnector,
  verbose: true
})
```

### # Connection Management

### **`connect()`**
Connect to the Hydra Node:

```typescript
await bridge.connect()
console.log('Connected to Hydra Node')
```

### **`disconnect()`**
Disconnect from the Hydra Node:

```typescript
await bridge.disconnect()
console.log('Disconnected from Hydra Node')
```

### **`connected()`**
Check connection status:

```typescript
const isConnected = bridge.connected()
console.log('Connection status:', isConnected)
```

### **`headInfo()`**

const info = await bridge.headInfo()

  headId: info.headId,

  isValid: result.isValid,

## Complete Examples

### Basic Hydra Head Management

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

async function manageHydraHead() {
  const bridge = new HydraBridge({
    url: 'ws://localhost:4001',
    verbose: true
  })

  // Set up event handlers before connecting
  bridge.events.on('onConnected', () => {
    console.log('Connected! Initializing Head...')
    bridge.commands.init()
  })

  bridge.events.on('onMessage', (payload) => {
    switch (payload.tag) {
      case 'HeadIsInitializing':
        console.log('Head initializing with', payload.parties.length, 'parties')
        break
      case 'HeadIsOpen':
        console.log('Head is open and ready for transactions!')
        break
      case 'TxValid':
        console.log('Transaction confirmed:', payload.transaction.txId)
        break
      case 'HeadIsClosed':
        console.log('Head closed, executing fanout...')
        bridge.commands.fanout()
        break
      case 'HeadIsFinalized':
        console.log('Head lifecycle complete')
        bridge.disconnect()
        break
    }
  })

  // Connect to start the process
  await bridge.connect()
}
```

### Transaction Processing in Hydra Head

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet, deserializeTx } from '@hydra-sdk/core'

async function processHydraTransactions() {
  const bridge = new HydraBridge({
    url: 'ws://localhost:4001',
    verbose: true
  })

  const wallet = new AppWallet({
    networkId: 0,
    key: {
      type: 'mnemonic',
      words: AppWallet.brew()
    }
  })

  bridge.events.on('onConnected', async () => {
    // Get protocol parameters for transaction building
    const protocolParams = await bridge.getProtocolParameters()
    
    // Create transaction builder configured for Hydra
    const txBuilder = new TxBuilder({
      isHydra: true,
      params: protocolParams
    })

    // Get account and UTxOs
    const account = wallet.getAccount(0, 0)
    const addressUtxos = await bridge.queryAddressUTxO(account.baseAddressBech32)

    if (addressUtxos.length === 0) {
      console.log('No UTxOs found for address')
      return
    }

    // Build and sign transaction
    const tx = await txBuilder
      .setInputs(addressUtxos)
      .addLovelaceOutput(account.baseAddressBech32, '1000000')
      .setChangeAddress(account.baseAddressBech32)
      .complete()

    const txId = deserializeTx(tx.to_hex()).transaction_hash().to_hex()
    const signedTx = await wallet.signTx(tx.to_hex(), false, 0, 0)

    // Submit to Hydra Head
    const result = await bridge.submitTxSync({
      type: 'Witnessed Tx ConwayEra',
      description: 'Ledger Cddl Format',
      cborHex: signedTx,
      txId
    }, { timeout: 30000 })

    console.log('Transaction successful:', result)
  })

  await bridge.connect()
}
```

### Full Head Lifecycle with Error Handling

```typescript
async function fullHeadLifecycleWithErrorHandling() {
  const bridge = new HydraBridge({
    url: 'ws://localhost:4001',
    verbose: true
  })

  let headState = 'idle'
  let reconnectAttempts = 0
  const maxReconnectAttempts = 5

  // Connection error handling
  bridge.events.on('onConnectError', async (error) => {
    console.error('Connection failed:', error)
    
    if (reconnectAttempts < maxReconnectAttempts) {
      reconnectAttempts++
      console.log(`Attempting to reconnect (${reconnectAttempts}/${maxReconnectAttempts})...`)
      
      await new Promise(resolve => setTimeout(resolve, 5000))
      await bridge.connect()
    } else {
      console.error('Max reconnection attempts reached')
    }
  })

  bridge.events.on('onConnected', () => {
    console.log('Connected, resetting reconnection counter')
    reconnectAttempts = 0
    
    if (headState === 'idle') {
      console.log('Starting head initialization...')
      bridge.commands.init()
    }
  })

  bridge.events.on('onMessage', async (payload) => {
    switch (payload.tag) {
      case 'Greetings':
        headState = payload.headStatus.toLowerCase()
        console.log('Current head status:', headState)
        break
        
      case 'HeadIsInitializing':
        headState = 'initializing'
        console.log('Head initializing with parties:', payload.parties.length)
        break
        
      case 'HeadIsOpen':
        headState = 'open'
        const utxoCount = Object.keys(payload.utxo).length
        console.log(`Head is open with ${utxoCount} UTxOs`)
        
        // Head is ready for transactions
        break
        
      case 'HeadIsClosed':
        headState = 'closed'
        console.log('Head closed, executing fanout...')
        bridge.commands.fanout()
        break
        
      case 'HeadIsFinalized':
        headState = 'finalized'
        console.log('Head lifecycle complete')
        await bridge.disconnect()
        break
        
      case 'TxInvalid':
        console.error('Transaction invalid:', {
          transaction: payload.transaction,
          reason: payload.validationError
        })
        break
        
      case 'CommandFailed':
        console.error('Command failed:', payload.clientInput)
        break
        
      case 'InvalidInput':
        console.error('Invalid input:', payload.reason)
        break
    }
  })

  await bridge.connect()
}
```

### Commit and Decommit Operations

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet } from '@hydra-sdk/core'

async function commitAndDecommitExample() {
  const bridge = new HydraBridge({
    url: 'ws://localhost:4001',
    verbose: true
  })

  const wallet = new AppWallet({
    networkId: 0,
    key: { type: 'mnemonic', words: AppWallet.brew() }
  })

  bridge.events.on('onMessage', async (payload) => {
    switch (payload.tag) {
      case 'HeadIsOpen':
        console.log('Head is open, can now commit UTxOs')
        
        // Example: Commit UTxOs to head
        const commitTxCbor = 'your_commit_transaction_cbor'
        const commitResult = await bridge.commit({
          cborHex: commitTxCbor,
          description: 'Initial commit'
        })
        console.log('Commit result:', commitResult)
        break
        
      case 'Committed':
        console.log('UTxO successfully committed:', payload.utxo)
        
        // Later, you can decommit UTxOs
        const decommitTxCbor = 'your_decommit_transaction_cbor'
        const decommitTxId = 'decommit_transaction_id'
        
        const decommitResult = await bridge.commands.decommit({
          cborHex: decommitTxCbor,
          txId: decommitTxId,
          timeout: 60000
        })
        console.log('Decommit result:', decommitResult)
        break
        
      case 'DecommitApproved':
        console.log('Decommit approved:', payload.decommitTxId)
        break
        
      case 'DecommitFinalized':
        console.log('Decommit finalized, UTxOs available on L1')
        break
    }
  })

  await bridge.connect()
}
```

## Best Practices

1. **Event Setup**: Always set up event handlers before calling `connect()`
2. **Error Handling**: Implement comprehensive error handling and reconnection logic
3. **State Management**: Track Head state to ensure valid operations
4. **Authentication**: Use proper JWT tokens for Hexcore connections
5. **Resource Cleanup**: Always call `disconnect()` when finished
6. **Transaction Validation**: Validate transactions before submission
7. **Timeout Configuration**: Set appropriate timeouts for operations
8. **Logging**: Enable verbose mode for debugging during development
