# @hydra-sdk/core API Reference

The core package provides essential Cardano wallet API including HD wallet management, transaction signing, network integration, and a comprehensive collection of utility functions.

## Overview

The core package includes:
- **AppWallet** - Main wallet class for HD wallet management
- **Account Management** - Account and address derivation
- **Transaction Signing** - Transaction signing and submission
- **Provider Integration** - Blockfrost and Ogmios providers
- **Utilities Collection** - Comprehensive utility functions for Cardano development

For detailed utility documentation, see [Utilities API Reference](/api/utilities).

## AppWallet

The main wallet class for managing Cardano wallets and accounts.

### Constructor

```typescript
import { AppWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'

// Create wallet with provider (Blockfrost or Ogmios)
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD, // or NETWORK_ID.MAINNET
  key: {
    type: 'mnemonic',
    words: ['word1', 'word2', ...] // 12, 15, or 24 words
  },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Create wallet from root key
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: {
    type: 'root',
    bech32: 'xprv1...' // Root private key in bech32 format
  }
})
```

### Static Methods

### **`brew(strength?)`**
Generate new mnemonic phrase:

```typescript
// Generate 24-word mnemonic (default)
const mnemonic24 = AppWallet.brew(256)

// Generate 12-word mnemonic
const mnemonic12 = AppWallet.brew(128)

// Generate 15-word mnemonic
const mnemonic15 = AppWallet.brew(160)

console.log('New mnemonic:', mnemonic24)
```

## Account Management

### **`getAccount(accountIndex?, keyIndex?)`**
Get account with derived keys and addresses:

```typescript
// Get first account (account 0, address 0)
const account = wallet.getAccount(0, 0)

console.log({
  // Address information
  baseAddressBech32: account.baseAddressBech32,
  enterpriseAddressBech32: account.enterpriseAddressBech32,
  rewardAddressBech32: account.rewardAddressBech32,
  
  // Key information
  paymentKey: account.paymentKey,
  stakeKey: account.stakeKey,
  
  // Indexes
  accountIndex: account.accountIndex,
  addressIndex: account.addressIndex
})

// Default to account 0, address 0
const defaultAccount = wallet.getAccount()
```

### **`getEnterpriseAddress(accountIndex?, keyIndex?)`**
Get enterprise address (payment only, no staking):

```typescript
const enterpriseAddr = wallet.getEnterpriseAddress(0, 0)
console.log('Enterprise Address:', enterpriseAddr)
```

### **`getPaymentAddress(accountIndex?, keyIndex?)`**
Get base address (payment + stake):

```typescript
const baseAddr = wallet.getPaymentAddress(0, 0)
console.log('Base Address:', baseAddr)
```

### **`getRewardAddress(accountIndex?, keyIndex?)`**
Get reward address (stake only):

```typescript
const rewardAddr = wallet.getRewardAddress(0, 0)
console.log('Reward Address:', rewardAddr)
```

### **`getNetworkId()`**
Get current network ID:

```typescript
const networkId = wallet.getNetworkId()
console.log('Network ID:', networkId) // 0 for testnet, 1 for mainnet
```

## Transaction Operations

### **`signTx(txCbor, partialSign?, accountIndex?, keyIndex?)`**
Sign a transaction:

```typescript
// Sign transaction completely
const signedTx = await wallet.signTx(
  unsignedTxCbor,
  false, // partialSign = false for complete signing
  0,     // accountIndex
  0      // keyIndex
)

// Partial signing (for multi-sig)
const partiallySignedTx = await wallet.signTx(
  unsignedTxCbor,
  true,  // partialSign = true
  0,
  0
)

console.log('Signed transaction:', signedTx)
```

### **`signData(address, payload, accountIndex?, keyIndex?)`**
Sign arbitrary data (CIP-8):

```typescript
const signature = await wallet.signData(
  'addr_test1...', // address
  'Hello World',   // payload to sign
  0,              // accountIndex
  0               // keyIndex
)

console.log('Data signature:', signature)
// Returns: { signature: string, key: string }
```

### **`signTxs(txCbors, partialSign?)`**
Sign multiple transactions:

```typescript
const signedTxs = await wallet.signTxs(
  [txCbor1, txCbor2, txCbor3],
  false // partialSign
)

console.log('Signed transactions:', signedTxs)
```

### **`submitTx(signedTxCbor)`**
Submit signed transaction to the blockchain:

```typescript
const txHash = await wallet.submitTx(signedTxCbor)
console.log('Transaction submitted! Hash:', txHash)
```

## Provider Integration

### **`queryUTxOs(address)`**
Query UTxOs for an address using the configured provider:

```typescript
const address = wallet.getAccount().baseAddressBech32
const utxos = await wallet.queryUTxOs(address)

console.log('UTxOs:', utxos)
// Returns: UTxO[]
```

### **`get fetcher()`**
Get the IFetcher instance from the provider:

```typescript
const fetcher = wallet.fetcher
// Use fetcher methods:
// - fetchAddressUTxOs(address)
// - fetchProtocolParameters()
// - etc.
```

### **`get submitter()`**
Get the ISubmitter instance from the provider:

```typescript
const submitter = wallet.submitter
// Use submitter methods:
// - submitTx(signedTxCbor)
```

## EmbeddedWallet

Lower-level wallet implementation used internally by AppWallet.

### **`generateMnemonic(strength?)`**
Tạo mnemonic phrase:

```typescript
import { EmbeddedWallet } from '@hydra-sdk/core'

const mnemonic = EmbeddedWallet.generateMnemonic(256)
console.log('Generated mnemonic:', mnemonic)
```

### **`mnemonicToPrivateKeyHex(words, password?)`**
Convert mnemonic to private key:

```typescript
const privateKeyHex = EmbeddedWallet.mnemonicToPrivateKeyHex(
  ['abandon', 'abandon', ...], // mnemonic words
  ''                           // optional password
)
console.log('Private key:', privateKeyHex)
```

### **`privateKeyHexToBech32(privateKeyHex)`**
Convert hex private key to bech32:

```typescript
const bech32Key = EmbeddedWallet.privateKeyHexToBech32(privateKeyHex)
console.log('Bech32 key:', bech32Key)
```

### **`privateKeyBech32ToPrivateKeyHex(bech32Key)`**
Convert bech32 private key to hex:

```typescript
const hexKey = EmbeddedWallet.privateKeyBech32ToPrivateKeyHex('xprv1...')
console.log('Hex key:', hexKey)
```

## CardanoCliWallet

Class for working with keys generated from Cardano CLI. Useful for server-side applications and scripts using cardano-cli.

### Constructor

```typescript
import { CardanoCliWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'

// Initialize with provider
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

// Create wallet from CLI keys (using cborHex from .skey and .vkey files)
const cliWallet = new CardanoCliWallet({
  networkId: NETWORK_ID.PREPROD,
  skey: '5820245120cdf333f8ea6910922b3f05bcbc0d5c8e8486ca94c020623d5cca822e04', // cborHex from .skey file
  vkey: '5820216f72947d1b97d56825c5f9f8a2e6f14234c02171853264f2f552a2685b25e0', // cborHex from .vkey file
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// The skey and vkey come from cardano-cli generated files:
// wallet-funds.skey:
// {
//   "type": "PaymentSigningKeyShelley_ed25519",
//   "description": "Payment Signing Key",
//   "cborHex": "5820245120cdf333f8ea6910922b3f05bcbc0d5c8e8486ca94c020623d5cca822e04"
// }
// wallet-funds.vkey:
// {
//   "type": "PaymentVerificationKeyShelley_ed25519",
//   "description": "Payment Verification Key",
//   "cborHex": "5820216f72947d1b97d56825c5f9f8a2e6f14234c02171853264f2f552a2685b25e0"
// }
```

### Use Case Example

```typescript
import { CardanoCliWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'
import { TxBuilder } from '@hydra-sdk/transaction'
import fs from 'fs'

// Read CLI keys from files
const skeyFile = JSON.parse(fs.readFileSync('./wallet-funds.skey', 'utf8'))
const vkeyFile = JSON.parse(fs.readFileSync('./wallet-funds.vkey', 'utf8'))

// Setup CLI wallet
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-api-key',
  network: 'preprod'
})

const cliWallet = new CardanoCliWallet({
  networkId: NETWORK_ID.PREPROD,
  skey: skeyFile.cborHex,
  vkey: vkeyFile.cborHex,
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Build and submit transaction
const address = cliWallet.getAddressBech32()
const utxos = await cliWallet.queryUTxOs(address)

const txBuilder = new TxBuilder()
const tx = await txBuilder
  .setInputs(utxos)
  .addOutput({
    address: 'addr_test1...',
    amount: [{ unit: 'lovelace', quantity: '1000000' }]
  })
  .changeAddress(address)
  .complete()

const signedTx = await cliWallet.signTx(tx.to_hex())
const txHash = await cliWallet.submitTx(signedTx)
console.log('Transaction hash:', txHash)
```
