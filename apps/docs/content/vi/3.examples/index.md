# Ví dụ

Chào mừng đến với phần ví dụ của tài liệu Hydra SDK. Tại đây bạn sẽ tìm thấy các mẫu code thực tế và use cases để giúp bạn bắt đầu với SDK.

## Tổng Quan

Các ví dụ được tổ chức thành nhiều danh mục:

1. **[Tạo Ví](/vi/examples/wallet-creation)** - Tạo và quản lý ví Cardano
2. **[Tích Hợp Hydra](/vi/examples/hydra-integration)** - Kết nối với Hydra Layer 2 và quản lý Hydra Heads
3. **[Xây Dựng Giao Dịch](/vi/examples/transaction-building)** - Xây dựng và submit transactions
4. **[Ứng Dụng Hoàn Chỉnh](/vi/examples/full-application)** - Các ứng dụng hoàn chỉnh với UI
5. **[Ứng Dụng React](/vi/examples/full-react-app)** - Ứng dụng Cardano dựa trên React
6. **[Ứng Dụng Vue.js](/vi/examples/full-vuejs-app)** - Ứng dụng Cardano dựa trên Vue.js
7. **[Ví Dụ Utilities](/vi/examples/utilities-examples)** - Ví dụ thực tế về utility functions
8. **[Ký Transaction](/vi/examples/transaction-signing)** - Các pattern ký transaction từ cơ bản đến nâng cao
