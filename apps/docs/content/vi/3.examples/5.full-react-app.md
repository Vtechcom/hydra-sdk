### Tùy Chọn 3: Tạo Từ Đầu

Thực hiện các bước sau để tạo dự án React + Vite mới với Hydra SDK từ đầu:

#### 1. Tạo dự án Vite mới

```bash
npm create vite@latest my-app -- --template react
cd ./my-app
```

#### 2. Cài đặt các package Hydra SDK

```bash
pnpm add @hydra-sdk/core @hydra-sdk/transaction @hydra-sdk/bridge
```

#### 3. Cài đặt các plugin Vite cần thiết (như dev dependencies)

```bash
pnpm add vite-plugin-wasm vite-plugin-top-level-await vite-plugin-node-polyfills -D
```

#### 4. Cấu hình Vite

Cập nhật file `vite.config.js`:

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

// https://vite.dev/config/
export default defineConfig({
  plugins: [
    react(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      }
    })
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm']
  }
})
```

#### 5. Cập nhật React component

Thay thế nội dung của `src/App.jsx` bằng:

```jsx
import { useState } from 'react'
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'
import './App.css'

function App() {
  // Tạo mnemonic phrase mới
  const [mnemonic, setMnemonic] = useState(AppWallet.brew())
  const [account, setAccount] = useState(null)

  const generateNewWallet = () => {
    const newMnemonic = AppWallet.brew()
    setMnemonic(newMnemonic)
    
    // Tạo wallet instance
    const wallet = new AppWallet({
      networkId: NETWORK_ID.PREPROD, // Sử dụng PREPROD để test
      key: {
        type: 'mnemonic',
        words: newMnemonic
      }
    })
    setAccount(wallet.getAccount())
  }

  return (
    <div className="App">
      <h1>React + Vite + Hydra SDK</h1>
      <div className="card">
        <button onClick={generateNewWallet}>
          Tạo Ví Mới
        </button>
        <div className="wallet-info">
          <h3>Địa Chỉ Ví:</h3>
          <p className="address">
            {account ? account.baseAddressBech32 : 'Nhấn tạo để tạo account mới'}
          </p>
          <h3>Cụm Từ Ghi Nhớ (Mnemonic):</h3>
          <p className="mnemonic">
            {account ? mnemonic.join(' ') : 'Nhấn tạo để tạo mnemonic'}
          </p>
        </div>
      </div>
    </div>
  )
}

export default App
```

## 📦 Dependencies

### Các Package Hydra SDK

- **@hydra-sdk/core** - Chức năng cốt lõi và utilities
- **@hydra-sdk/transaction** - Xây dựng và ký giao dịch
- **@hydra-sdk/bridge** - Bridge để tương tác với blockchain

### Vite Plugins (Dev Dependencies)

- **vite-plugin-wasm** - Hỗ trợ WebAssembly cho Hydra SDK
- **vite-plugin-top-level-await** - Hỗ trợ top-level await
- **vite-plugin-node-polyfills** - Node.js polyfills cho tương thích trình duyệt

## 🔧 Chi Tiết Cấu Hình

### Tại Sao Cần Các Plugin Này

1. **vite-plugin-wasm**: Hydra SDK sử dụng WebAssembly cho các thao tác mật mã
2. **vite-plugin-top-level-await**: Cho phép async/await ở module level
3. **vite-plugin-node-polyfills**: Cung cấp Node.js APIs như `Buffer` và `process` trong trình duyệt

### Các Tùy Chọn Cấu Hình Quan Trọng

```javascript
nodePolyfills({
  include: ['buffer'],  // Chỉ bao gồm buffer polyfill
  globals: {
    Buffer: true,       // Cần thiết cho các thao tác mật mã
    global: false,      // Tắt rõ ràng global polyfill
    process: false      // Tắt rõ ràng process polyfill
  }
})
```

```javascript
optimizeDeps: {
  exclude: ['@hydra-sdk/cardano-wasm']  // Loại trừ WASM khỏi optimization
}
```

## 🐛 Xử Lý Sự Cố

### Các Vấn Đề Thường Gặp

1. **WASM Loading Errors**
   - Đảm bảo `vite-plugin-wasm` được cài đặt và cấu hình
   - Kiểm tra hỗ trợ WebAssembly của trình duyệt

2. **Buffer/Process Not Defined**
   - Xác minh cấu hình `vite-plugin-node-polyfills`
   - Đảm bảo globals được thiết lập đúng

3. **Module Resolution Errors**
   - Kiểm tra tất cả package Hydra SDK đã được cài đặt
   - Xác minh cấu hình Vite đúng

4. **Build Errors**
   - Đảm bảo `@hydra-sdk/cardano-wasm` được loại trừ khỏi optimization
   - Kiểm tra tất cả plugin cần thiết có trong devDependencies
