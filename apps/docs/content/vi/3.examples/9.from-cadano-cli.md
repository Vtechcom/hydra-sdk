# Tích hợp từ Cardano-CLI

Học cách sử dụng key được tạo từ Cardano-CLI với Hydra SDK. Class `CardanoCliWallet` cho phép bạn sử dụng các CLI key hiện có trong ứng dụng Node.js để ký transaction và tương tác blockchain theo phong cách lập trình.

**Tài liệu tham khảo**: [Cardano-CLI Documentation](https://developers.cardano.org/docs/get-started/cardano-cli/basic-operations/get-started)

## Tạo key với Cardano-CLI

Tạo một cặp payment key sử dụng Cardano-CLI:

```bash
cardano-cli address key-gen \
  --verification-key-file payment.vkey \
  --signing-key-file payment.skey
```

Lệnh này sẽ tạo hai file:

**`payment.vkey`** (Verification Key):
```json
{
    "type": "PaymentVerificationKeyShelley_ed25519",
    "description": "Payment Verification Key",
    "cborHex": "5820832ba166c8ba8afda5b9d85dfe13dd8fffd460da79a2c3cf34e107216637985b"
}
```

**`payment.skey`** (Signing Key):
```json
{
    "type": "PaymentSigningKeyShelley_ed25519",
    "description": "Payment Signing Key",
    "cborHex": "5820bd09ad4f98cd103e059ab62d17a6a7d920b16d9f0eed3eb6b77d3ca8f61dc117"
}
```

::alert{type="warning"}
⚠️ **Cảnh báo bảo mật**: Không bao giờ chia sẻ signing key (`payment.skey`) hoặc commit vào version control.
::

## Xác minh key (Tùy chọn)

Xác minh key của bạn bằng cách build một address:

```bash
cardano-cli address build \
  --payment-verification-key-file payment.vkey \
  --testnet-magic 1 \
  --out-file payment.addr
```

**Kết quả** (`payment.addr`):
```
addr_test1vz5hhyn6ecl66a2ca3cwfnwu8ddnp24hakfq2k37rhk28ysk8g0wz
```

::alert{type="info"}
Đây là **enterprise address** (chỉ có payment key, không có staking key) tuân theo [CIP-19](https://cips.cardano.org/cips/cip19/).
::

## Sử dụng với Hydra SDK

### Thiết lập cơ bản

```ts
import { CardanoCliWallet, NETWORK_ID } from '@hydra-sdk/core';

// Trích xuất giá trị cborHex từ key file của bạn
const skey = '5820bd09ad4f98cd103e059ab62d17a6a7d920b16d9f0eed3eb6b77d3ca8f61dc117';
const vkey = '5820832ba166c8ba8afda5b9d85dfe13dd8fffd460da79a2c3cf34e107216637985b';

// Khởi tạo wallet
const wallet = new CardanoCliWallet({ 
    skey, 
    vkey, 
    networkId: NETWORK_ID.PREPROD 
});

// Lấy address ở định dạng Bech32
const address = wallet.getAddressBech32();
console.log('Wallet Address:', address);
// Output: addr_test1vz5hhyn6ecl66a2ca3cwfnwu8ddnp24hakfq2k37rhk28ysk8g0wz
```

### Ví dụ transaction

```ts
import { 
    CardanoCliWallet, 
    NETWORK_ID,
    ProviderUtils
} from '@hydra-sdk/core';
import { TxBuilder } from '@hydra-sdk/transaction';

// Khởi tạo wallet với CLI key
const wallet = new CardanoCliWallet({ 
    skey: '5820bd09ad4f98cd103e059ab62d17a6a7d920b16d9f0eed3eb6b77d3ca8f61dc117',
    vkey: '5820832ba166c8ba8afda5b9d85dfe13dd8fffd460da79a2c3cf34e107216637985b',
    networkId: NETWORK_ID.PREPROD 
});

// Thiết lập provider
const provider = new ProviderUtils.BlockfrostProvider({
    apiKey: 'your-blockfrost-project-id',
    network: 'preprod'
});

// Build transaction
const txBuilder = new TxBuilder({
    fetcher: provider.fetcher,
    submitter: provider.submitter
});
const unsignedTx = await txBuilder
    // ...
    .complete();

// Ký transaction
const signedTxCbor = await wallet.signTx(unsignedTx.to_hex());
console.log('Signed Transaction:', signedTxCbor);

```

## API Reference

### Constructor

```ts
new CardanoCliWallet(options: CardanoCliWalletConfig)
```

**Options**:
- `skey` (bắt buộc): CBOR hex của signing key (format: `5820...`)
- `vkey` (bắt buộc): CBOR hex của verification key (format: `5820...`)
- `networkId` (tùy chọn): `NETWORK_ID.MAINNET` (1) hoặc `NETWORK_ID.PREPROD` (0), mặc định là MAINNET
- `fetcher` (tùy chọn): Custom fetcher để query UTxO
- `submitter` (tùy chọn): Custom submitter để submit transaction

### Method

```ts
// Lấy address ở định dạng Bech32
getAddressBech32(): string

// Ký một transaction
signTx(unsignedTxHex: string, partialSign?: boolean): Promise<string>

// Lấy network ID
getNetworkId(): number

// Submit transaction (yêu cầu submitter trong constructor)
submitTx(tx: string): Promise<string>

// Query UTxO (yêu cầu fetcher trong constructor)
queryUTxOs(address: string): Promise<UTxO[]>
```

### Property

```ts
// Lấy payment signing key
paymentSKey: CardanoWASM.PrivateKey

// Lấy payment verification key
paymentVKey: CardanoWASM.PublicKey
```
