### Tùy Chọn 3: Tạo Từ Đầu

Thực hiện các bước sau để tạo dự án Vue 3 + TypeScript + Vite mới với Hydra SDK từ đầu:

#### 1. Tạo dự án Vue mới

```bash
npm create vue@latest my-vue-app
cd ./my-vue-app
```

Khi được hỏi, chọn:
- ✅ TypeScript
- ✅ Router (tùy chọn)
- ❌ Các tùy chọn khác (tùy nhu cầu)

#### 2. Cài đặt các package Hydra SDK

```bash
pnpm add @hydra-sdk/core @hydra-sdk/transaction @hydra-sdk/bridge
```

#### 3. Cài đặt các plugin Vite cần thiết (như dev dependencies)

```bash
pnpm add vite-plugin-wasm vite-plugin-top-level-await vite-plugin-node-polyfills -D
```

#### 4. Cấu hình Vite

Cập nhật file `vite.config.ts`:

```typescript
import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

// https://vite.dev/config/
export default defineConfig({
  plugins: [
    vue(),
    vueDevTools(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      },
    }),
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm'],
  },
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
})
```

#### 5. Tạo component Hydra SDK

Tạo `src/components/HydraSdkExample.vue`:

```vue
<script lang="ts" setup>
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'
import { ref } from 'vue'

const mnemonic = ref(AppWallet.brew())
const wallet = ref(
  new AppWallet({
    networkId: NETWORK_ID.PREPROD,
    key: {
      type: 'mnemonic',
      words: mnemonic.value,
    },
  }),
)
const account = ref(wallet.value.getAccount())

function generateNewWallet() {
  mnemonic.value = AppWallet.brew()
  wallet.value = new AppWallet({
    networkId: NETWORK_ID.PREPROD,
    key: {
      type: 'mnemonic',
      words: mnemonic.value,
    },
  })
  account.value = wallet.value.getAccount()
}
</script>

<template>
  <div class="hydra-sdk-example">
    <h2>Ví dụ Hydra SDK</h2>
    <button @click="generateNewWallet">Tạo Ví Mới</button>
    <h3>Cụm Từ Ghi Nhớ (Mnemonic)</h3>
    <p class="break-words">
      {{ mnemonic }}
    </p>
    <h3>Địa Chỉ Cơ Bản (Bech32)</h3>
    <p class="base-address">
      {{ account.baseAddressBech32 }}
    </p>
  </div>
</template>
```

### Các Package Hydra SDK

- **@hydra-sdk/transaction** - Xây dựng và ký giao dịch
- **@hydra-sdk/bridge** - Bridge để tương tác với blockchain

### Vue Dependencies

- **vue** - Vue.js 3 framework
- **vue-router** - Vue Router cho navigation

### Vite Plugins (Dev Dependencies)

- **@vitejs/plugin-vue** - Hỗ trợ Vue.js cho Vite
- **vite-plugin-vue-devtools** - Tích hợp Vue DevTools
- **vite-plugin-wasm** - Hỗ trợ WebAssembly cho Hydra SDK
- **vite-plugin-top-level-await** - Hỗ trợ top-level await
- **vite-plugin-node-polyfills** - Node.js polyfills cho tương thích trình duyệt

## 🔧 Chi Tiết Cấu Hình

### Tại Sao Cần Các Plugin Này

1. **@vitejs/plugin-vue**: Hỗ trợ Vue.js cốt lõi cho Vite
2. **vite-plugin-vue-devtools**: Nâng cao trải nghiệm phát triển với Vue DevTools
3. **vite-plugin-wasm**: Hydra SDK sử dụng WebAssembly cho các thao tác mật mã
4. **vite-plugin-top-level-await**: Cho phép async/await ở module level
5. **vite-plugin-node-polyfills**: Cung cấp Node.js APIs như `Buffer` và `process` trong trình duyệt

### Các Tùy Chọn Cấu Hình Quan Trọng

```typescript
nodePolyfills({
  include: ['buffer'],  // Chỉ bao gồm buffer polyfill
  globals: {
    Buffer: true,       // Cần thiết cho các thao tác mật mã
    global: false,      // Tắt rõ ràng global polyfill
    process: false      // Tắt rõ ràng process polyfill
  }
})
```

```typescript
optimizeDeps: {
  exclude: ['@hydra-sdk/cardano-wasm']  // Loại trừ WASM khỏi optimization
}
```

```typescript
resolve: {
  alias: {
    '@': fileURLToPath(new URL('./src', import.meta.url))  // Path alias cho imports
  }
```

## 🐛 Xử Lý Sự Cố

### Các Vấn Đề Thường Gặp

1. **WASM Loading Errors**
   - Đảm bảo `vite-plugin-wasm` được cài đặt và cấu hình
   - Kiểm tra hỗ trợ WebAssembly của trình duyệt

2. **Buffer/Process Not Defined**
   - Xác minh cấu hình `vite-plugin-node-polyfills`
   - Đảm bảo globals được thiết lập đúng

3. **TypeScript Compilation Errors**
   - Chạy `pnpm type-check` để xác định type issues
   - Đảm bảo tất cả Hydra SDK types được import đúng
   - Kiểm tra cấu hình TypeScript trong tsconfig files

4. **Module Resolution Errors**
   - Kiểm tra tất cả package Hydra SDK đã được cài đặt
   - Xác minh cấu hình Vite đúng
   - Đảm bảo path aliases được cấu hình đúng

5. **Build Errors**
   - Đảm bảo `@hydra-sdk/cardano-wasm` được loại trừ khỏi optimization
   - Kiểm tra tất cả plugin cần thiết có trong devDependencies
   - Xác minh TypeScript compilation pass
