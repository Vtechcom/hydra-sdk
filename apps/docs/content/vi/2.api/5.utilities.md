# @hydra-sdk/core – Utilities

Hydra SDK cung cấp bộ sưu tập toàn diện các hàm tiện ích để làm việc với dữ liệu blockchain Cardano, các hoạt động WASM và các tác vụ phát triển phổ biến.

## Tổng Quan

Các utilities được tổ chức thành nhiều danh mục:

- **[Keys Utilities](#keys-utilities)** - Tạo và quản lý khóa mật mã
- **[Data Parsing](#data-parsing)** - Chuyển đổi giữa các định dạng dữ liệu
- **[Datum Utilities](#datum-utilities)** - Làm việc với cấu trúc dữ liệu Plutus
- **[Redeemer Utilities](#redeemer-utilities)** - Xây dựng redeemer cho Plutus script
- **[Validation Utilities](#validation-utilities)** - Xác thực địa chỉ và output giao dịch
- **[Policy Utilities](#policy-utilities)** - Quản lý chính sách minting
- **[Metadata Utilities](#metadata-utilities)** - Chuyển đổi metadata giao dịch
- **[Time Utilities](#time-utilities)** - Tính toán slot và thời gian
- **[Provider Utilities](#provider-utilities)** - Trừu tượng hóa nhà cung cấp dữ liệu blockchain
- **[Cardano WASM Utilities](#cardano-wasm-utilities)** - Các hoạt động blockchain cấp thấp

## Keys Utilities :badge[1.1.5+]{variant="success" style="transform: translateY(-2px)"}

### **`KeysUtils.cardanoCliKeygen() → { sk: CardanoCLiSkey; vk: CardanoCLiVkey }`**

Tạo cặp khóa ed25519 tương thích với Cardano CLI.

Mô tả: Tạo khóa ký và xác minh tương thích với định dạng Cardano CLI.

**Example:**

```typescript
import { KeysUtils } from '@hydra-sdk/core'

const cardanoKeys = KeysUtils.cardanoCliKeygen()
console.log({
	skey: cardanoKeys.sk.cborHex, // PaymentSigningKeyShelley_ed25519
	vkey: cardanoKeys.vk.cborHex // PaymentVerificationKeyShelley_ed25519
})
```

**Returns:** `{ sk: CardanoCLiSkey; vk: CardanoCLiVkey }`

```typescript
{
  sk: CardanoCLiSkey,
  vk: CardanoCLiVkey,
}
```

### **`KeysUtils.mnemonicToCliKey(mnemonic: string[], accountIndex?: number, keyIndex?: number)`**

**→ `{ sk: CardanoCLiSkey; vk: CardanoCLiVkey }`** :badge[1.1.6+]{variant="success"}

Chuyển đổi cụm từ ghi nhớ BIP-39 thành cặp khóa tương thích với Cardano CLI.

Mô tả: Dẫn xuất khóa thanh toán từ cụm từ ghi nhớ sử dụng đường dẫn dẫn xuất BIP-44 (m/1852'/1815'/account'/0/keyIndex). Điều này cho phép bạn tạo khóa tương thích với ví Cardano và công cụ CLI.

**Parameters:**

- `mnemonic` (string[]): Từ ghi nhớ BIP-39 (12 hoặc 24 từ)
- `accountIndex` (number, optional): Chỉ số tài khoản trong đường dẫn dẫn xuất (mặc định: 0)
- `keyIndex` (number, optional): Chỉ số khóa trong đường dẫn dẫn xuất (mặc định: 0)

**Example:**

```typescript
import { KeysUtils, AppWallet } from '@hydra-sdk/core'

// Tạo cụm từ ghi nhớ ngẫu nhiên
const mnemonic = AppWallet.brew()

// Chuyển đổi sang khóa CLI với chỉ số mặc định
const keys = KeysUtils.mnemonicToCliKey(mnemonic)
console.log({
	skey: keys.sk.cborHex,
	vkey: keys.vk.cborHex
})

// Sử dụng chỉ số tài khoản cụ thể (cho nhiều tài khoản)
const account1Keys = KeysUtils.mnemonicToCliKey(mnemonic, 1)

// Sử dụng chỉ số khóa cụ thể (cho nhiều địa chỉ)
const addressKeys = KeysUtils.mnemonicToCliKey(mnemonic, 0, 5)
```

**Returns:** `{ sk: CardanoCLiSkey; vk: CardanoCLiVkey }`

```typescript
{
  sk: CardanoCLiSkey,  // PaymentSigningKeyShelley_ed25519
  vk: CardanoCLiVkey   // PaymentVerificationKeyShelley_ed25519
}
```

**Important Notes:**

- Sử dụng đường dẫn dẫn xuất BIP-44: `m/1852'/1815'/accountIndex'/0/keyIndex`
- Các giá trị `accountIndex` khác nhau tạo các tài khoản khác nhau từ cùng một cụm từ ghi nhớ
- Các giá trị `keyIndex` khác nhau tạo các địa chỉ thanh toán khác nhau cho cùng một tài khoản
- Khóa là xác định - cùng cụm từ ghi nhớ + chỉ số luôn tạo ra cùng khóa
- Tương thích với Cardano CLI và hầu hết các ví Cardano

## Data Parsing

### **`ParserUtils.bytesToHex(bytes: ArrayBuffer | Uint8Array | Buffer) → string`**

Chuyển đổi bytes thành chuỗi hex.

**Parameters:**

- `bytes` (ArrayBuffer | Uint8Array | Buffer): Dữ liệu bytes cần chuyển đổi

Chuỗi hex

## Redeemer Utilities :badge[1.4.0+]{variant="success" style="transform: translateY(-2px)"}

Xây dựng redeemer cho Plutus script. Import: `import { RedeemerUtils } from '@hydra-sdk/core'`.

### **`RedeemerUtils.mkRedeemer(data: PlutusData, options?: BuildRedeemerOptions) → Redeemer`**

Bọc Plutus data vào một `Redeemer`.

**Parameters:**

- `data` (PlutusData): Dữ liệu redeemer
- `options` (BuildRedeemerOptions, optional):
  - `tag` ('spend' | 'mint' | 'reward' | 'cert' | 'vote' | 'voting_proposal', không phân biệt hoa thường): Tag của redeemer. Mặc định: `'spend'`
  - `index` (string | number | bigint): Chỉ số redeemer. Mặc định: `0`
  - `exUnits` (`{ mem, steps }`): Ngân sách execution unit. Mặc định: `RedeemerUtils.DEFAULT_EX_UNITS`

**Example:**

```typescript
import { RedeemerUtils, DatumUtils } from '@hydra-sdk/core'

const data = DatumUtils.mkConstr(1, [])
const redeemer = RedeemerUtils.mkRedeemer(data, { tag: 'spend', index: 0 })
```

**Returns:** `Redeemer`

---

---

### **`RedeemerUtils.mkMintRedeemer(data: PlutusData, options?) → Redeemer`**

---

### **`RedeemerUtils.mkUnitRedeemer(options?) → Redeemer`**

**Example:**

```typescript

**Returns:** `Redeemer`

	new Uint8Array([1, 2, 3, 4])
)

// Chuyển đổi mảng
const arrayMetadata = MetadataUtils.metadataObjToMetadatum([
	'item1',
	42,
	new Uint8Array([5, 6])
])

// Chuyển đổi object thành map
const objectMetadata = MetadataUtils.metadataObjToMetadatum({
	name: 'NFT Name',
	image: 'ipfs://...',
	attributes: ['trait1', 'trait2']
})

// Chuyển đổi Map
const mapMetadata = MetadataUtils.metadataObjToMetadatum(
	new Map([
		['key1', 'value1'],
		['key2', 42]
	])
)
```

**Returns:** `TransactionMetadatum`
Metadata định dạng Cardano

**Important Notes:**

- Maximum metadata `bytes` size: **64 bytes**
- Maximum metadata `text` size: **64 characters**
- Arrays và Maps được xử lý đệ quy, chú ý đến kích thước metadata tổng

## Provider Utilities

### **`ProviderUtils.BlockfrostProvider(config: BlockfrostProviderConfig) → BlockfrostProvider`**

Tạo provider Blockfrost để truy vấn và gửi giao dịch đến Cardano blockchain.

Mô tả: BlockfrostProvider là wallet provider kết nối với Blockfrost API để fetch UTxOs và gửi giao dịch. Nó kế thừa BaseWalletProvider và cung cấp cả chức năng fetcher và submitter.

**Parameters:**

- `config` (BlockfrostProviderConfig):
  - `apiKey` (string): Blockfrost Project ID của bạn từ [Blockfrost Dashboard](https://blockfrost.io/)
  - `network` (BlockfrostSupportedNetworks): Mạng để kết nối ('mainnet', 'preprod', hoặc 'preview')
  - `apiVersion` (number, optional): Phiên bản Blockfrost API (mặc định: 0)
  - `baseURL` (string, optional): Ghi đè URL endpoint Blockfrost mặc định. Hữu ích cho các API tương thích Blockfrost như Demeter. <Badge type="tip" text="Mới trong v1.3.2" />
  - `cachingOptions` (object, optional): Cấu hình caching
    - `enabled` (boolean): Bật caching response (mặc định: false)
    - `maxSize` (number): Số lượng mục cache tối đa (mặc định: 100)
    - `ttl` (number): Thời gian tồn tại tính bằng milliseconds (mặc định: 300000 - 5 phút)

**Properties:**

- `fetcher` (IFetcher): Interface để fetch dữ liệu blockchain
  - `fetchAddressUTxOs(address: string, asset?: string): Promise<UTxO[]>` - Fetch UTxOs cho một địa chỉ, tùy chọn lọc theo asset
- `submitter` (ISubmitter): Interface để gửi giao dịch
  - `submitTx(txHex: string): Promise<string>` - Gửi giao dịch đã ký và trả về transaction hash

**Example:**

```typescript
import { ProviderUtils } from '@hydra-sdk/core'

// Cấu hình cơ bản
const provider = new ProviderUtils.BlockfrostProvider({
	apiKey: 'preprodXXXXXXXXXXXXXXXXXXXX',
	network: 'preprod'
})

// Với phiên bản API và caching
const providerWithCache = new ProviderUtils.BlockfrostProvider({
	apiKey: 'preprodXXXXXXXXXXXXXXXXXXXX',
	network: 'preprod',
	apiVersion: 0,
	cachingOptions: {
		enabled: true,
		maxSize: 200,
		ttl: 600000 // 10 phút
	}
})

// Fetch tất cả UTxOs cho một địa chỉ
const utxos = await provider.fetcher.fetchAddressUTxOs(
	'addr1qx2fxv2umyhttkxyxp8x0dlpdt3k6cwng5pxj3jhsydzer...'
)

// Fetch UTxOs chứa asset cụ thể
const assetUtxos = await provider.fetcher.fetchAddressUTxOs(
	'addr1qx2fxv2umyhttkxyxp8x0dlpdt3k6cwng5pxj3jhsydzer...',
	'lovelace' // hoặc policy_id + asset_name
)

// Gửi giao dịch đã ký
const txHash = await provider.submitter.submitTx(signedTxHex)
console.log('Giao dịch đã gửi:', txHash)
```

**Returns:** `BlockfrostProvider`
Provider instance
