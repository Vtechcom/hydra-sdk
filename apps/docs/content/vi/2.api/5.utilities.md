# Tiện ích

Hydra SDK cung cấp bộ sưu tập toàn diện các hàm tiện ích để hỗ trợ làm việc với dữ liệu blockchain Cardano, các hoạt động WASM và các nhiệm vụ phát triển phổ biến.

## Tổng quan

Các tiện ích được tổ chức thành nhiều danh mục:

- **[Keys Utilities](#keys-utilities)** - Tạo và quản lý khóa
- **[Cardano WASM Utilities](#cardano-wasm-utilities)** - Các hoạt động blockchain cấp thấp
- **[Data Parsing](#data-parsing)** - Chuyển đổi giữa các định dạng dữ liệu khác nhau
- **[Datum Utilities](#datum-utilities)** - Làm việc với cấu trúc dữ liệu Plutus
- **[Policy Utilities](#policy-utilities)** - Quản lý chính sách minting
- **[Metadata Utilities](#metadata-utilities)** - Chuyển đổi metadata giao dịch
- **[Time Utilities](#time-utilities)** - Tính toán thời gian và slot
- **[Provider Utilities](#provider-utilities)** - Trừu tượng hóa nhà cung cấp dữ liệu blockchain

## Sử dụng

Tất cả các tiện ích được xuất dưới dạng các module namespace để tổ chức tốt hơn:

```typescript
import {
  Serializer,
  Deserializer,
  Resolver,
  Converter,
  BuildKeys,
  ParserUtils,
  TimeUtils,
  DatumUtils,
  PolicyUtils,
  MetadataUtils,
  ProviderUtils,
  CostModels,
  KeysUtils,
  SLOT_CONFIG_NETWORK
} from '@hydra-sdk/core'
```

## Keys Utilities (v1.1.5+)
Các tiện ích để tạo và quản lý khóa mã hóa.

### KeysUtils

`KeysUtils` cung cấp các hàm tạo khóa và chuyển đổi tương thích với Cardano CLI và Hydra.

```typescript
import { KeysUtils } from '@hydra-sdk/core'

// Tạo cặp khóa ed25519 tương thích với Cardano CLI
const cardanoKeys = KeysUtils.cardanoCliKeygen()
// cardanoKeys.sk: PaymentSigningKeyShelley_ed25519
// cardanoKeys.vk: PaymentVerificationKeyShelley_ed25519

// Tạo cặp khóa ed25519 tương thích với Hydra
const hydraKeys = KeysUtils.hydraCliKeygen()
// hydraKeys.sk: HydraSigningKey_ed25519
// hydraKeys.vk: HydraVerificationKey_ed25519

// Tạo verification key từ signing key
const vkey = KeysUtils.genVkey(cardanoKeys.sk)
```

**Các hàm có sẵn:**
- `cardanoCliKeygen()` – Tạo cặp khóa ed25519 tương thích với Cardano CLI
- `hydraCliKeygen()` – Tạo cặp khóa ed25519 tương thích với Hydra
- `genVkey(skey)` – Tạo verification key từ signing key

**Các kiểu dữ liệu:**
- `CardanoCLiSkey`: 
  ```js
  { 
    type: 'PaymentSigningKeyShelley_ed25519', 
    description: 'Payment Signing Key', 
    cborHex: '5820...' 
  }
  ```
- `CardanoCLiVkey`: 
  ```js
  { 
    type: 'PaymentVerificationKeyShelley_ed25519', 
    description: 'Payment Verification Key', 
    cborHex: '5820...' 
  }
  ```
- `HydraCliSkey`: 
  ```js
  { 
    type: 'HydraSigningKey_ed25519', 
    description: 'Hydra Signing Key', 
    cborHex: '5820...' 
  }
  ```
- `HydraCliVkey`: 
  ```js
  { 
    type: 'HydraVerificationKey_ed25519', 
    description: 'Hydra Verification Key', 
    cborHex: '5820...' 
  }
  ```

## Cardano WASM Utilities

### Serializer

Các tiện ích để serialize các cấu trúc dữ liệu Cardano sang nhiều định dạng khác nhau.

```typescript
// Ví dụ sử dụng

```

### Deserializer

Các tiện ích để deserialize dữ liệu Cardano từ nhiều định dạng khác nhau.

```typescript
// Ví dụ sử dụng
```

### Resolver

Các tiện ích để resolve địa chỉ Cardano, khóa và các định danh blockchain khác.

```typescript
// Ví dụ sử dụng

```

### Converter

Các tiện ích để chuyển đổi giữa các định dạng dữ liệu Cardano khác nhau.

```typescript
// Ví dụ sử dụng

```

```typescript
// Ví dụ sử dụng

```

## Data Parsing

Các tiện ích parser để chuyển đổi giữa các định dạng dữ liệu khác nhau.

### ParserUtils

`ParserUtils` cung cấp các hàm chuyển đổi giữa bytes, hex và chuỗi UTF-8.

```typescript
import { ParserUtils } from '@hydra-sdk/core'

// Chuyển bytes sang chuỗi hex
const hex = ParserUtils.bytesToHex(bytes)
// Chuyển chuỗi hex sang bytes
const bytes = ParserUtils.hexToBytes('deadbeef')
// Chuyển chuỗi UTF-8 sang hex
const hexString = ParserUtils.stringToHex('Hello World')
// Chuyển chuỗi hex sang chuỗi UTF-8
const str = ParserUtils.hexToString(hexString)
// Chuyển chuỗi hoặc hex sang bytes
const bytes2 = ParserUtils.toBytes('Hello World')
// Chuyển UTF-8 sang hex (bí danh)
const hex2 = ParserUtils.fromUTF8('Hello World')
// Chuyển hex sang chuỗi UTF-8 (bí danh)
const str2 = ParserUtils.toUTF8(hexString)
```

**Các hàm có sẵn:**
- `bytesToHex(bytes: ArrayBuffer | Uint8Array | Buffer): string` – Chuyển bytes sang chuỗi hex
- `hexToBytes(hex: string): Buffer` – Chuyển chuỗi hex sang bytes
- `stringToHex(str: string): string` – Chuyển chuỗi UTF-8 sang hex
- `hexToString(hex: string): string` – Chuyển chuỗi hex sang chuỗi UTF-8
- `toBytes(strOrHex: string): Uint8Array` – Chuyển chuỗi hoặc hex sang bytes
- `fromUTF8(str: string): string` – Chuyển chuỗi UTF-8 sang chuỗi hex
- `toUTF8(hex: string): string` – Chuyển chuỗi hex sang chuỗi UTF-8

## Datum Utilities

Các tiện ích để làm việc với cấu trúc dữ liệu Plutus và datum.

### DatumUtils

`DatumUtils` cung cấp các hàm tạo PlutusData cơ bản và bộ sưu tập.

```typescript
import { DatumUtils } from '@hydra-sdk/core'

// Tạo datum số nguyên
const intDatum = DatumUtils.mkInt(42)
// Tạo datum bytes
const bytesDatum = DatumUtils.mkBytes('deadbeef')
// Tạo datum constructor
const constrDatum = DatumUtils.mkConstr(0, [intDatum, bytesDatum])
// Tạo datum map
const mapDatum = DatumUtils.mkMap([[intDatum, bytesDatum]])
```

**Các hàm có sẵn:**
- `mkInt(n: string | number | bigint): PlutusData` – Tạo datum số nguyên
- `mkBytes(hex: string): PlutusData` – Tạo datum bytes từ chuỗi hex
- `mkConstr(alt: number, fields: PlutusData[]): PlutusData` – Tạo datum constructor
- `mkMap(entries: Array<[PlutusData, PlutusMapValues]>): PlutusData` – Tạo datum map

## Policy Utilities

Các tiện ích để làm việc với chính sách minting và native script.

### PolicyUtils

`PolicyUtils` cung cấp các hàm xây dựng policy script và trích xuất policy ID.

```typescript
import { PolicyUtils } from '@hydra-sdk/core'

// Xây dựng policy script từ public key
const policyScript = PolicyUtils.buildPolicyScriptFromPubkey({ type: 'sig', keyHash: 'abc123...' })
// Xây dựng minting policy script từ address
const mintingScript = PolicyUtils.buildMintingPolicyScriptFromAddress('addr1qx2fxv2umyhttkxyxp8x0dlpdt3k6cwng5pxj3jhsydzer3jcu5d8ps7zex2k2xt3uqxgjqnnj83ws8lhrn648jjxtwq2ytjqp')
// Xây dựng minting policy script từ key hash
const mintingScript2 = PolicyUtils.buildMintingPolicyScriptFromKeyHash('abc123...')
// Trích xuất policy ID từ native script
const policyId = PolicyUtils.policyIdFromNativeScript(policyScript)
```

**Các hàm có sẵn:**
- `buildPolicyScriptFromPubkey(pubkeyScript): string` – Xây dựng policy script từ public key
- `buildMintingPolicyScriptFromAddress(addressBech32: string): string` – Xây dựng minting policy từ address
- `buildMintingPolicyScriptFromKeyHash(keyHash: string): string` – Xây dựng minting policy từ key hash
- `policyIdFromNativeScript(nativeScript: string): string` – Trích xuất policy ID từ native script

## Metadata Utilities

Các tiện ích để chuyển đổi các kiểu dữ liệu khác nhau sang định dạng metadata giao dịch Cardano.

### MetadataUtils

`MetadataUtils` cung cấp hàm chuyển đổi các kiểu khác nhau sang metadata giao dịch Cardano.

```typescript
import { MetadataUtils } from '@hydra-sdk/core'

// Chuyển chuỗi sang metadata
const stringMetadata = MetadataUtils.metadataObjToMetadatum('Hello World')

// Chuyển số sang metadata
const numberMetadata = MetadataUtils.metadataObjToMetadatum(42)

// Chuyển bigint sang metadata
const bigintMetadata = MetadataUtils.metadataObjToMetadatum(9007199254740991n)

// Chuyển bytes sang metadata
const bytesMetadata = MetadataUtils.metadataObjToMetadatum(new Uint8Array([1, 2, 3, 4]))

// Chuyển mảng sang metadata
const arrayMetadata = MetadataUtils.metadataObjToMetadatum(['item1', 42, new Uint8Array([5, 6])])

// Chuyển object sang metadata map
const objectMetadata = MetadataUtils.metadataObjToMetadatum({ name: 'NFT Name', image: 'ipfs://...', attributes: ['trait1', 'trait2'] })

// Chuyển Map sang metadata
const mapMetadata = MetadataUtils.metadataObjToMetadatum(new Map([['key1', 'value1'], ['key2', 42]]))
```

**Các hàm có sẵn:**
- `metadataObjToMetadatum(metadata): CardanoWASM.TransactionMetadatum` – Chuyển các kiểu sang metadata

**Các kiểu được hỗ trợ:**
- String, Number, BigInt, Uint8Array, Array, Object, Map

**Lưu ý quan trọng:**
- Kích thước tối đa của metadata `bytes` là **64 bytes**
- Kích thước tối đa của metadata `text` là **64 ký tự**
- Mảng và Map được xử lý đệ quy, hãy chú ý đến kích thước metadata tổng thể

## Time Utilities

Các tiện ích để làm việc với slot thời gian và timestamp Cardano.

### TimeUtils

`TimeUtils` cung cấp các hàm tính toán slot và epoch, cũng như cấu hình slot.

```typescript
import { TimeUtils, SLOT_CONFIG_NETWORK } from '@hydra-sdk/core'

// Chuyển slot sang Unix timestamp
const timestamp = TimeUtils.slotToBeginUnixTime(slot, SLOT_CONFIG_NETWORK.PREPROD)
// Chuyển Unix timestamp sang slot
const slot = TimeUtils.unixTimeToEnclosingSlot(timestamp, SLOT_CONFIG_NETWORK.PREPROD)
// Resolve slot number từ timestamp
const slotNo = TimeUtils.resolveSlotNo(Date.now())
// Resolve epoch number từ timestamp
const epochNo = TimeUtils.resolveEpochNo(Date.now())
// Xây dựng Hydra slot config cho timestamp cụ thể
const slotConfig = TimeUtils.buildHydraSlotConfig(Date.now())
```

**Các hàm có sẵn:**
- `slotToBeginUnixTime(slot: number, slotConfig: SlotConfig): number` – Chuyển slot sang Unix timestamp
- `unixTimeToEnclosingSlot(unixTime: number, slotConfig: SlotConfig): number` – Chuyển timestamp sang slot
- `resolveSlotNo(unixTime: number): string` – Resolve slot number dựa trên timestamp
- `resolveEpochNo(unixTime: number): number` – Resolve epoch number dựa trên timestamp
- `buildHydraSlotConfig(unixTime: number): SlotConfig` – Xây dựng cấu hình slot Hydra cho timestamp cụ thể

## Provider Utilities

Các tiện ích để làm việc với các nhà cung cấp dữ liệu blockchain khác nhau.

### ProviderUtils

SDK hỗ trợ nhiều implementation provider:

- **BaseProvider** - Lớp trừu tượng cơ sở cho tất cả provider
- **BlockfrostProvider** - Tích hợp Blockfrost API
- **OgmiosProvider** - Tích hợp Ogmios WebSocket

```typescript
import { ProviderUtils } from '@hydra-sdk/core'

// Tạo Blockfrost provider
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  projectId: 'your-project-id',
  network: 'preprod'
})

// Tạo Ogmios provider
const ogmiosProvider = new ProviderUtils.OgmiosProvider({
  url: 'ws://localhost:1337'
})

// Sử dụng phương thức provider
const utxos = await provider.getUtxos(address)
const protocolParams = await provider.getProtocolParameters()
```

**Giao diện Provider:**

Tất cả provider implement giao diện chung với các phương thức cho:
- Truy vấn UTxO
- Lấy protocol parameter
- Submit giao dịch
- Validate địa chỉ
- Thông tin asset

## Ví dụ

### Sử dụng tiện ích cơ bản

```typescript
import { 
  ParserUtils,
  TimeUtils, 
  DatumUtils,
  PolicyUtils,
  SLOT_CONFIG_NETWORK
} from '@hydra-sdk/core'

// Chuyển đổi dữ liệu
const hex = ParserUtils.stringToHex('Hello Cardano')
const bytes = ParserUtils.hexToBytes(hex)

// Tiện ích thời gian
const currentSlot = TimeUtils.unixTimeToEnclosingSlot(Date.now(), SLOT_CONFIG_NETWORK.PREPROD)
const readableTime = new Date(TimeUtils.slotToBeginUnixTime(currentSlot, SLOT_CONFIG_NETWORK.PREPROD))

// Tạo datum
const datum = DatumUtils.mkConstr(0, [
  DatumUtils.mkInt(42),
  DatumUtils.mkBytes(hex)
])

console.log('Current slot:', currentSlot)
console.log('Readable time:', readableTime.toLocaleString())
console.log('Datum hex:', datum.to_hex())
```
