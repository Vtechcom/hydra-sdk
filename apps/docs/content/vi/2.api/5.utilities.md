# Utilities API Reference

Hydra SDK cung cấp một bộ sưu tập toàn diện các utility functions để giúp bạn làm việc với dữ liệu blockchain Cardano, các thao tác WASM, và các tác vụ phát triển thông thường.

## Tổng quan

Các utilities được tổ chức thành nhiều categories:

- **[Cardano WASM Utilities](#cardano-wasm-utilities)** - Các thao tác blockchain cấp thấp
- **[Data Parsing](#data-parsing)** - Chuyển đổi giữa các định dạng dữ liệu
- **[Datum Utilities](#datum-utilities)** - Làm việc với cấu trúc dữ liệu Plutus
- **[Policy Utilities](#policy-utilities)** - Quản lý minting policy
- **[Metadata Utilities](#metadata-utilities)** - Chuyển đổi transaction metadata
- **[Time Utilities](#time-utilities)** - Tính toán thời gian và slot
- **[Provider Utilities](#provider-utilities)** - Abstractions của blockchain data provider
- **[Cost Models](#cost-models)** - Plutus cost models

## Import và Sử dụng

Tất cả utilities được export dưới dạng namespaced modules để tổ chức tốt hơn:

```typescript
import {
  Serializer,
  Deserializer,
  Resolver,
  Converter,
  BuildKeys,
  ParserUtils,
  TimeUtils,
  DatumUtils,
  PolicyUtils,
  MetadataUtils,
  ProviderUtils,
  SLOT_CONFIG_NETWORK
} from '@hydra-sdk/core'
```

## Utilities sử dụng Cardano WASM

### Serializer

Utilities để serialize các cấu trúc dữ liệu Cardano sang các định dạng khác nhau.

```typescript
// Ví dụ sử dụng
const serializedTx = Serializer.serializeTransaction(transaction)
```

### Deserializer

Utilities để deserialize dữ liệu Cardano từ các định dạng khác nhau.

```typescript
// Ví dụ sử dụng
const transaction = Deserializer.deserializeTransaction(serializedData)
```

### Resolver

Utilities để resolve các địa chỉ Cardano, keys, và các identifier blockchain khác.

```typescript
// Ví dụ sử dụng
const address = Resolver.resolveAddress(bech32Address)
```

### Converter

Utilities để chuyển đổi giữa các định dạng dữ liệu Cardano khác nhau.

```typescript
// Ví dụ sử dụng
const hex = Converter.bytesToHex(bytes)
const bytes = Converter.hexToBytes(hex)
```

### BuildKeys

Utilities để xây dựng và derive các cryptographic keys.

```typescript
// Ví dụ sử dụng
const keys = BuildKeys.deriveKeys(rootKey, derivationPath)
```

Parser utilities để chuyển đổi giữa các định dạng dữ liệu khác nhau.

### ParserUtils

```typescript
import { ParserUtils } from '@hydra-sdk/core'

// Chuyển đổi bytes sang hex string
const hex = ParserUtils.bytesToHex(bytes)

// Chuyển đổi hex string sang bytes
const bytes = ParserUtils.hexToBytes('deadbeef')

// Chuyển đổi UTF-8 string sang hex
const hexString = ParserUtils.stringToHex('Xin Chào Thế Giới')
```

**Các Functions Có Sẵn:**

- `bytesToHex(bytes: ArrayBuffer | Uint8Array | Buffer): string` - Chuyển bytes sang hex string
- `hexToBytes(hex: string): Buffer` - Chuyển hex string sang bytes
- `stringToHex(str: string): string` - Chuyển UTF-8 string sang hex

## Datum Utilities

Utilities để làm việc với cấu trúc dữ liệu Plutus và datums.

### DatumUtils

```typescript
import { DatumUtils } from '@hydra-sdk/core'

// Tạo integer datum
const intDatum = DatumUtils.mkInt(42)

// Tạo bytes datum
const bytesDatum = DatumUtils.mkBytes('deadbeef')

// Tạo constructor datum
const constrDatum = DatumUtils.mkConstr(0, [intDatum, bytesDatum])

// Tạo map datum
const mapDatum = DatumUtils.mkMap([
  [keyDatum, valueDatum]
])
```

**Các Functions Có Sẵn:**

- `mkInt(n: string | number | bigint): PlutusData` - Tạo integer datum
- `mkBytes(hex: string): PlutusData` - Tạo bytes datum từ hex string
- `mkConstr(alt: number, fields: PlutusData[]): PlutusData` - Tạo constructor datum
- `mkMap(entries: Array<[PlutusData, PlutusMapValues]>): PlutusData` - Tạo map datum

### DatumSchema

`DatumSchema` cung cấp các schema constants để chuyển đổi giữa JSON và Plutus data:

```typescript
import { DatumUtils } from '@hydra-sdk/core'
import { CardanoWASM } from '@hydra-sdk/cardano-wasm'

// Tạo datum từ JSON với schema
const datum = CardanoWASM.PlutusData.from_json(
  '{"constructor": 0, "fields": [{"int": 42}]}',
  DatumUtils.DatumSchema.Detailed
)

// Chuyển đổi datum sang JSON với schema
const jsonData = datum.to_json(DatumUtils.DatumSchema.Detailed)

// Schema constants có sẵn
const basicSchema = DatumUtils.DatumSchema.Basic     // ScriptDataJsonNoSchema
const detailedSchema = DatumUtils.DatumSchema.Detailed // ScriptDataJsonDetailedSchema
```

**Schema Types:**
- `DatumUtils.DatumSchema.Basic` - Định dạng đơn giản, không hỗ trợ đầy đủ Plutus datums
- `DatumUtils.DatumSchema.Detailed` - Định dạng chi tiết, hỗ trợ gần như tất cả Plutus datums

## Metadata Utilities

Utilities để chuyển đổi các loại dữ liệu khác nhau sang định dạng transaction metadata của Cardano.

### MetadataUtils

```typescript
import { MetadataUtils } from '@hydra-sdk/core'

// Convert string thành metadata
const stringMetadata = MetadataUtils.metadataObjToMetadatum('Hello World')

// Convert number thành metadata
const numberMetadata = MetadataUtils.metadataObjToMetadatum(42)

// Convert bigint thành metadata
const bigintMetadata = MetadataUtils.metadataObjToMetadatum(9007199254740991n)

// Convert bytes thành metadata
const bytesMetadata = MetadataUtils.metadataObjToMetadatum(
  new Uint8Array([1, 2, 3, 4])
)

// Convert array thành metadata
const arrayMetadata = MetadataUtils.metadataObjToMetadatum([
  'item1',
  42,
  new Uint8Array([5, 6])
])

// Convert object thành metadata map
const objectMetadata = MetadataUtils.metadataObjToMetadatum({
  name: 'NFT Name',
  image: 'ipfs://...',
  attributes: ['trait1', 'trait2']
})

// Convert Map thành metadata
const mapMetadata = MetadataUtils.metadataObjToMetadatum(
  new Map([
    ['key1', 'value1'],
    ['key2', 42]
  ])
)

// Cấu trúc lồng nhau phức tạp
const complexMetadata = MetadataUtils.metadataObjToMetadatum({
  metadata: {
    name: 'My NFT',
    description: 'A great NFT',
    image: 'ipfs://QmHash',
    attributes: [
      { trait_type: 'Background', value: 'Blue' },
      { trait_type: 'Eyes', value: 'Green' }
    ],
    files: [
      {
        name: 'image.png',
        mediaType: 'image/png',
        src: 'ipfs://QmHash'
      }
    ]
  }
})
```

**Các Functions Có Sẵn:**

- `metadataObjToMetadatum(metadata): CardanoWASM.TransactionMetadatum` - Convert các kiểu dữ liệu thành metadata

**Các Loại Được Hỗ Trợ:**

- **String** - Convert thành text metadata (tối đa 64 ký tự)
- **Number** - Convert thành integer metadata
- **BigInt** - Convert thành integer metadata
- **Uint8Array** - Convert thành bytes metadata (tối đa 64 bytes)
- **Array** - Convert thành metadata list (xử lý đệ quy các phần tử)
- **Object** - Convert thành metadata map (xử lý đệ quy các properties)
- **Map** - Convert thành metadata map (xử lý đệ quy các entries)

**Lưu Ý Quan Trọng:**

::alert{type="warning"}
**Giới Hạn Kích Thước**:
- Kích thước tối đa của metadata `bytes` là **64 bytes**
- Kích thước tối đa của metadata `text` là **64 ký tự**
- Arrays và Maps được xử lý đệ quy, cần lưu ý tổng kích thước metadata
::

## Time Utilities

Utilities để làm việc với time slots và timestamps của Cardano.

### TimeUtils

```typescript
import { TimeUtils, SLOT_CONFIG_NETWORK } from '@hydra-sdk/core'

// Chuyển đổi slot sang Unix timestamp
const timestamp = TimeUtils.slotToBeginUnixTime(slot, SLOT_CONFIG_NETWORK.PREPROD)

// Chuyển đổi Unix timestamp sang slot  
const slot = TimeUtils.unixTimeToEnclosingSlot(timestamp, SLOT_CONFIG_NETWORK.PREPROD)

// Lấy slot number hiện tại (sử dụng timestamp hiện tại)
const currentSlot = TimeUtils.unixTimeToEnclosingSlot(Date.now(), SLOT_CONFIG_NETWORK.PREPROD)

// Lấy slot cho timestamp cụ thể
const futureSlot = TimeUtils.unixTimeToEnclosingSlot(Date.now() + 3600000, SLOT_CONFIG_NETWORK.PREPROD)
```

**Các Functions Có Sẵn:**

- `slotToBeginUnixTime(slot: number, slotConfig: SlotConfig): number` - Chuyển slot sang Unix timestamp
- `unixTimeToEnclosingSlot(unixTime: number, slotConfig: SlotConfig): number` - Chuyển timestamp sang slot

**Cấu Hình Network:**

Sử dụng `SLOT_CONFIG_NETWORK` cho các cấu hình slot theo network:
- `SLOT_CONFIG_NETWORK.MAINNET` - Cấu hình Mainnet
- `SLOT_CONFIG_NETWORK.PREPROD` - Cấu hình Preprod testnet  
- `SLOT_CONFIG_NETWORK.PREVIEW` - Cấu hình Preview testnet

## Provider Utilities

Utilities để làm việc với các blockchain data providers khác nhau.

### ProviderUtils

SDK hỗ trợ nhiều provider implementations:

- **BaseProvider** - Abstract base class cho tất cả providers
- **BlockfrostProvider** - Tích hợp Blockfrost API
- **OgmiosProvider** - Tích hợp Ogmios WebSocket

```typescript
import { ProviderUtils } from '@hydra-sdk/core'

// Tạo Blockfrost provider
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  projectId: 'your-project-id',
  network: 'preprod'
})

// Tạo Ogmios provider
const ogmiosProvider = new ProviderUtils.OgmiosProvider({
  url: 'ws://localhost:1337'
})

// Sử dụng provider methods
const utxos = await provider.getUtxos(address)
const protocolParams = await provider.getProtocolParameters()
```

**Provider Interface:**

Tất cả providers đều implement một interface chung với methods để:
- UTxO queries
- Protocol parameter retrieval
- Transaction submission
- Address validation
- Asset information

### Time Slot Calculations

```typescript
import { TimeUtils, SLOT_CONFIG_NETWORK } from '@hydra-sdk/core'

// Tính toán validity range cho transaction
const now = Date.now()
const oneHourLater = now + 3600000

// Convert sang slots
const currentSlot = TimeUtils.unixTimeToEnclosingSlot(
  now,
  SLOT_CONFIG_NETWORK.PREPROD
)

const futureSlot = TimeUtils.unixTimeToEnclosingSlot(
  oneHourLater,
  SLOT_CONFIG_NETWORK.PREPROD
)

// Sử dụng với TxBuilder
txBuilder
  .invalidBefore(currentSlot)
  .invalidAfter(futureSlot)

console.log('Transaction valid từ slot:', currentSlot)
console.log('Transaction valid đến slot:', futureSlot)
console.log('Thời gian còn lại:', (futureSlot - currentSlot), 'slots')

// Convert slot về thời gian để hiển thị
const readableTime = new Date(
  TimeUtils.slotToBeginUnixTime(futureSlot, SLOT_CONFIG_NETWORK.PREPROD)
)
console.log('Hết hạn lúc:', readableTime.toLocaleString('vi-VN'))
```

### Data Conversion Pipeline

```typescript
import { ParserUtils, DatumUtils, MetadataUtils } from '@hydra-sdk/core'

// Chuỗi xử lý dữ liệu
const originalText = 'Xin chào Cardano!'

// 1. String -> Hex
const hexString = ParserUtils.stringToHex(originalText)
console.log('Hex:', hexString)

// 2. Hex -> Bytes datum
const bytesDatum = DatumUtils.mkBytes(hexString)
console.log('Datum hex:', bytesDatum.to_hex())

// 3. Create metadata
const metadata = MetadataUtils.metadataObjToMetadatum({
  msg: originalText,
  timestamp: Date.now(),
  data: Array.from(ParserUtils.hexToBytes(hexString))
})

// 4. Sử dụng trong transaction
txBuilder
  .txOut(recipientAddress, amount)
  .txOutInlineDatumValue(bytesDatum)
  .metadataValue('674', metadata) // CIP-20 message
```

## Best Practices

### 1. Data Validation

```typescript
// ✅ Validate hex strings trước khi convert
function validateHex(hex: string): boolean {
  return /^[0-9a-fA-F]*$/.test(hex) && hex.length % 2 === 0
}

const hex = '48656c6c6f'
if (validateHex(hex)) {
  const bytes = ParserUtils.hexToBytes(hex)
  // Process bytes...
}
```

### 2. Metadata Size Limits

```typescript
// ✅ Kiểm tra size trước khi tạo metadata
function checkMetadataSize(obj: any): boolean {
  const json = JSON.stringify(obj)
  const size = new TextEncoder().encode(json).length
  return size <= 16384 // Max 16KB per transaction
}

const metadata = { name: 'NFT', description: '...' }
if (checkMetadataSize(metadata)) {
  txBuilder.metadataValue('721', metadata)
}
```

### 3. Time Slot Safety Margins

```typescript
// ✅ Thêm safety margin cho validity ranges
const currentSlot = TimeUtils.unixTimeToEnclosingSlot(
  Date.now(),
  SLOT_CONFIG_NETWORK.PREPROD
)

// Thêm 5 slots buffer (khoảng 5 seconds)
const safeStartSlot = currentSlot + 5
const safeEndSlot = currentSlot + 1000 // 1000 slots ~ 16 minutes

txBuilder
  .invalidBefore(safeStartSlot)
  .invalidAfter(safeEndSlot)
```

### 4. Provider Error Handling

```typescript
// ✅ Xử lý provider errors properly
async function queryWithRetry(
  provider: any,
  address: string,
  maxRetries = 3
) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await provider.fetcher.fetchAddressUTxOs(address)
    } catch (error) {
      if (i === maxRetries - 1) throw error
      await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)))
    }
  }
}
```

### 5. Datum Schema Selection

```typescript
// ✅ Sử dụng Detailed schema cho complex datums
import { CardanoWASM } from '@hydra-sdk/cardano-wasm'
import { DatumUtils } from '@hydra-sdk/core'

// Cho simple datums
const simpleDatum = CardanoWASM.PlutusData.from_json(
  '{"int": 42}',
  DatumUtils.DatumSchema.Basic
)

// Cho complex datums với constructors
const complexDatum = CardanoWASM.PlutusData.from_json(
  '{"constructor": 0, "fields": [{"int": 42}, {"bytes": "deadbeef"}]}',
  DatumUtils.DatumSchema.Detailed
)
```

## Performance Tips

### 1. Reuse Provider Instances

```typescript
// ✅ Tạo provider instance một lần và reuse
const provider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-api-key',
  network: 'preprod'
})

// Reuse cho nhiều wallets
const wallet1 = new AppWallet({ 
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: mnemonic1 },
  fetcher: provider.fetcher,
  submitter: provider.submitter
})

const wallet2 = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: mnemonic2 },
  fetcher: provider.fetcher,
  submitter: provider.submitter
})
```

### 2. Cache Protocol Parameters

```typescript
// ✅ Cache protocol params để giảm API calls
let cachedParams: any = null
let cacheTime = 0
const CACHE_DURATION = 300000 // 5 minutes

async function getProtocolParams(provider: any) {
  const now = Date.now()
  if (!cachedParams || now - cacheTime > CACHE_DURATION) {
    cachedParams = await provider.fetcher.fetchProtocolParameters()
    cacheTime = now
  }
  return cachedParams
}
```

### 3. Batch UTxO Queries

```typescript
// ✅ Query nhiều addresses cùng lúc nếu có thể
async function queryMultipleAddresses(
  provider: any,
  addresses: string[]
) {
  return Promise.all(
    addresses.map(addr => provider.fetcher.fetchAddressUTxOs(addr))
  )
}
```

## Common Pitfalls

### ❌ Incorrect Hex Encoding

```typescript
// ❌ Sai
const hex = Buffer.from('hello').toString() // 'hello' không phải hex

// ✅ Đúng
const hex = Buffer.from('hello').toString('hex') // '68656c6c6f'
```

### ❌ Wrong Slot Configuration

```typescript
// ❌ Sai - dùng mainnet config cho preprod
const slot = TimeUtils.unixTimeToEnclosingSlot(
  Date.now(),
  SLOT_CONFIG_NETWORK.MAINNET // Network không đúng!
)

// ✅ Đúng
const slot = TimeUtils.unixTimeToEnclosingSlot(
  Date.now(),
  SLOT_CONFIG_NETWORK.PREPROD
)
```

### ❌ Metadata Too Large

```typescript
// ❌ Sai - metadata quá lớn
const largeMetadata = {
  description: 'a'.repeat(100000) // Quá 64 chars per field
}

// ✅ Đúng - chia nhỏ hoặc giới hạn size
const validMetadata = {
  description: description.substring(0, 64)
}
```
