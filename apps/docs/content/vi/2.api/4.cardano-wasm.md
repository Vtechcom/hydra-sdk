# @hydra-sdk/cardano-wasm — API Reference

Cung cấp đầy đủ binding WASM cho các thao tác Cardano nâng cao: build giao dịch, tiện ích mật mã (crypto), metadata, và hỗ trợ đầy đủ giao thức Cardano.

## CardanoWASM

### Import

```ts
import { CardanoWASM } from '@hydra-sdk/cardano-wasm'
const { min_fee, Transaction, Address, Value, BigNum, PlutusData } = CardanoWASM
```

### Hàm thường dùng

- `min_fee(tx, linear_fee)` — Tính phí tối thiểu
- `calculate_ex_units_ceil_cost(ex_units, ex_unit_prices)` — Tính chi phí ex-units
- `min_script_fee(tx, ex_unit_prices)` — Phí tối thiểu cho script
- `min_ref_script_fee(total_ref_scripts_size, ref_script_coins_per_byte)` — Phí tối thiểu cho reference script
- `min_ada_for_output(output, data_cost)` — Min ADA cho output

### Plutus Data

- `encode_json_str_to_plutus_datum(json, schema)` — JSON -> Plutus datum
- `decode_plutus_datum_to_json_str(datum, schema)` — Datum -> JSON
- `hash_plutus_data(plutus_data)`
- `hash_script_data(redeemers, cost_models, datums?)`

### Metadata

- `encode_json_str_to_metadatum(json, schema)` — JSON -> Metadata
- `decode_metadatum_to_json_str(metadatum, schema)` — Metadata -> JSON
- `encode_arbitrary_bytes_as_metadatum(bytes)` / `decode_arbitrary_bytes_from_metadatum(metadata)`

### Witness

- `make_vkey_witness(tx_body_hash, sk)`
- `make_daedalus_bootstrap_witness(...)`
- `make_icarus_bootstrap_witness(...)`

### Khác

- `hash_auxiliary_data(auxiliary_data)`
- `get_implicit_input(txbody, pool_deposit, key_deposit)`
- `get_deposit(txbody, pool_deposit, key_deposit)`
- Mã hóa/giải mã script, Value, Address, v.v.
