# @hydra-sdk/core API Reference

Package core cung cấp API ví Cardano thiết yếu bao gồm quản lý HD wallet, ký giao dịch, tích hợp network và bộ sưu tập các hàm tiện ích toàn diện.

## Tổng quan

Package core bao gồm:
- **AppWallet** - Class ví chính để quản lý HD wallet
- **Quản lý Account** - Tạo và quản lý account và address
- **Ký giao dịch** - Ký và gửi transaction
- **Tích hợp Provider** - Blockfrost và Ogmios providers
- **Bộ sưu tập Utilities** - Các hàm tiện ích toàn diện cho phát triển Cardano

Để xem tài liệu utility chi tiết, xem [Utilities API Reference](/vi/api/utilities).

## AppWallet

Class ví chính để quản lý ví và account Cardano.

### Constructor

```typescript
import { AppWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'

// Tạo ví với provider (Blockfrost hoặc Ogmios)
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD, // hoặc NETWORK_ID.MAINNET
  key: {
    type: 'mnemonic',
    words: ['word1', 'word2', ...] // 12, 15, hoặc 24 từ
  },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Tạo ví từ root key
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: {
    type: 'root',
    bech32: 'xprv1...' // Root private key ở định dạng bech32
  }
})
```

### Static Methods

### **`brew(strength?)`**
Tạo mnemonic phrase mới:

```typescript
// Tạo mnemonic 24 từ (mặc định)
const mnemonic24 = AppWallet.brew(256)

// Tạo mnemonic 12 từ
const mnemonic12 = AppWallet.brew(128)

// Tạo mnemonic 15 từ
const mnemonic15 = AppWallet.brew(160)

console.log('Mnemonic mới:', mnemonic24)
```

## Quản lý Account

### **`getAccount(accountIndex?, keyIndex?)`**
Lấy account với các key và address đã được tạo:

```typescript
// Lấy account đầu tiên (account 0, address 0)
const account = wallet.getAccount(0, 0)

console.log({
  // Thông tin Address
  baseAddressBech32: account.baseAddressBech32,
  enterpriseAddressBech32: account.enterpriseAddressBech32,
  rewardAddressBech32: account.rewardAddressBech32,
  
  // Thông tin Key
  paymentKey: account.paymentKey,
  stakeKey: account.stakeKey,
  
  // Indexes
  accountIndex: account.accountIndex,
  addressIndex: account.addressIndex
})

// Mặc định là account 0, address 0
const defaultAccount = wallet.getAccount()
```

### **`getEnterpriseAddress(accountIndex?, keyIndex?)`**
Lấy enterprise address (chỉ payment, không có staking):

```typescript
const enterpriseAddr = wallet.getEnterpriseAddress(0, 0)
console.log('Enterprise Address:', enterpriseAddr)
```

### **`getPaymentAddress(accountIndex?, keyIndex?)`**
Lấy base address (payment + stake):

```typescript
const baseAddr = wallet.getPaymentAddress(0, 0)
console.log('Base Address:', baseAddr)
```

### **`getRewardAddress(accountIndex?, keyIndex?)`**
Lấy reward address (chỉ stake):

```typescript
const rewardAddr = wallet.getRewardAddress(0, 0)
console.log('Reward Address:', rewardAddr)
```

### **`getNetworkId()`**
Lấy network ID hiện tại:

```typescript
const networkId = wallet.getNetworkId()
console.log('Network ID:', networkId) // 0 cho testnet, 1 cho mainnet
```

## Các thao tác với Transaction

### **`signTx(txCbor, partialSign?, accountIndex?, keyIndex?)`**
Ký một transaction:

```typescript
// Ký transaction hoàn chỉnh
const signedTx = await wallet.signTx(
  unsignedTxCbor,
  false, // partialSign = false để ký hoàn chỉnh
  0,     // accountIndex
  0      // keyIndex
)

// Ký một phần (cho multi-sig)
const partiallySignedTx = await wallet.signTx(
  unsignedTxCbor,
  true,  // partialSign = true
  0,
  0
)

console.log('Transaction đã ký:', signedTx)
```

### **`signData(address, payload, accountIndex?, keyIndex?)`**
Ký dữ liệu tùy ý (CIP-8):

```typescript
const signature = await wallet.signData(
  'addr_test1...', // address
  'Hello World',   // payload cần ký
  0,              // accountIndex
  0               // keyIndex
)

console.log('Data signature:', signature)
// Trả về: { signature: string, key: string }
```

### **`signTxs(txCbors, partialSign?)`**
Ký nhiều transactions:

```typescript
const signedTxs = await wallet.signTxs(
  [txCbor1, txCbor2, txCbor3],
  false // partialSign
)

console.log('Transactions đã ký:', signedTxs)
```

### **`submitTx(signedTxCbor)`**
Gửi transaction đã ký lên blockchain:

```typescript
const txHash = await wallet.submitTx(signedTxCbor)
console.log('Transaction đã gửi! Hash:', txHash)
```

## Tích hợp Provider

### **`queryUTxOs(address)`**
Truy vấn UTxOs cho một address sử dụng provider đã cấu hình:

```typescript
const address = wallet.getAccount().baseAddressBech32
const utxos = await wallet.queryUTxOs(address)

console.log('UTxOs:', utxos)
// Trả về: UTxO[]
```

### **`get fetcher()`**
Lấy instance IFetcher từ provider:

```typescript
const fetcher = wallet.fetcher
// Sử dụng các phương thức fetcher:
// - fetchAddressUTxOs(address)
// - fetchProtocolParameters()
// - v.v.
```

### **`get submitter()`**
Lấy instance ISubmitter từ provider:

```typescript
const submitter = wallet.submitter
// Sử dụng các phương thức submitter:
// - submitTx(signedTxCbor)
```

## EmbeddedWallet

Implementation wallet cấp thấp được sử dụng nội bộ bởi AppWallet.

### **`generateMnemonic(strength?)`**
Tạo mnemonic phrase:

```typescript
import { EmbeddedWallet } from '@hydra-sdk/core'

const mnemonic = EmbeddedWallet.generateMnemonic(256)
console.log('Mnemonic đã tạo:', mnemonic)
```

### **`mnemonicToPrivateKeyHex(words, password?)`**
Chuyển đổi mnemonic sang private key:

```typescript
const privateKeyHex = EmbeddedWallet.mnemonicToPrivateKeyHex(
  ['abandon', 'abandon', ...], // các từ mnemonic
  ''                           // password tùy chọn
)
console.log('Private key:', privateKeyHex)
```

### **`privateKeyHexToBech32(privateKeyHex)`**
Chuyển đổi hex private key sang bech32:

```typescript
const bech32Key = EmbeddedWallet.privateKeyHexToBech32(privateKeyHex)
console.log('Bech32 key:', bech32Key)
```

### **`privateKeyBech32ToPrivateKeyHex(bech32Key)`**
Chuyển đổi bech32 private key sang hex:

```typescript
const hexKey = EmbeddedWallet.privateKeyBech32ToPrivateKeyHex('xprv1...')
console.log('Hex key:', hexKey)
```

## CardanoCliWallet

Class ví để làm việc với các key được tạo từ Cardano CLI. Hữu ích cho các ứng dụng server-side và scripts sử dụng cardano-cli.

### Constructor

```typescript
import { CardanoCliWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'

// Khởi tạo với provider
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

// Tạo wallet từ CLI keys (sử dụng cborHex từ các file .skey và .vkey)
const cliWallet = new CardanoCliWallet({
  networkId: NETWORK_ID.PREPROD,
  skey: '5820245120cdf333f8ea6910922b3f05bcbc0d5c8e8486ca94c020623d5cca822e04', // cborHex từ file .skey
  vkey: '5820216f72947d1b97d56825c5f9f8a2e6f14234c02171853264f2f552a2685b25e0', // cborHex từ file .vkey
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// skey và vkey lấy từ các file được tạo bởi cardano-cli:
// wallet-funds.skey:
// {
//   "type": "PaymentSigningKeyShelley_ed25519",
//   "description": "Payment Signing Key",
//   "cborHex": "5820245120cdf333f8ea6910922b3f05bcbc0d5c8e8486ca94c020623d5cca822e04"
// }
// wallet-funds.vkey:
// {
//   "type": "PaymentVerificationKeyShelley_ed25519",
//   "description": "Payment Verification Key",
//   "cborHex": "5820216f72947d1b97d56825c5f9f8a2e6f14234c02171853264f2f552a2685b25e0"
// }
```

### Ví dụ Use Case

```typescript
import { CardanoCliWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'
import { TxBuilder } from '@hydra-sdk/transaction'
import fs from 'fs'

// Đọc CLI keys từ các file
const skeyFile = JSON.parse(fs.readFileSync('./wallet-funds.skey', 'utf8'))
const vkeyFile = JSON.parse(fs.readFileSync('./wallet-funds.vkey', 'utf8'))

// Thiết lập CLI wallet
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-api-key',
  network: 'preprod'
})

const cliWallet = new CardanoCliWallet({
  networkId: NETWORK_ID.PREPROD,
  skey: skeyFile.cborHex,
  vkey: vkeyFile.cborHex,
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Xây dựng và gửi transaction
const address = cliWallet.getAddressBech32()
const utxos = await cliWallet.queryUTxOs(address)

const txBuilder = new TxBuilder()
const tx = await txBuilder
  .setInputs(utxos)
  .addOutput({
    address: 'addr_test1...',
    amount: [{ unit: 'lovelace', quantity: '1000000' }]
  })
  .changeAddress(address)
  .complete()

const signedTx = await cliWallet.signTx(tx.to_hex())
const txHash = await cliWallet.submitTx(signedTx)
console.log('Transaction hash:', txHash)
```
