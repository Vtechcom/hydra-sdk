## AppWallet

### **`AppWallet.brew(strength?: number) → string[]`**

Tạo mới một cụm từ mnemonic ngẫu nhiên cho ví Cardano mới.

**Parameters:**
- `strength?` (number): Độ mạnh của mnemonic (128 = 12 từ, 160 = 15 từ, 256 = 24 từ). Mặc định: 256 (24 từ)

**Example:**
```typescript
import { AppWallet } from '@hydra-sdk/core'

// Tạo mnemonic 24 từ (mặc định)
const mnemonic24 = AppWallet.brew(256)

// Tạo mnemonic 12 từ
const mnemonic12 = AppWallet.brew(128)

// Tạo mnemonic 15 từ
const mnemonic15 = AppWallet.brew(160)

console.log('Mnemonic mới:', mnemonic24)
// => ['abandon', 'abandon', ..., 'zone']
```

**Returns:** `string[]`  
Mảng các từ mnemonic

### **`AppWallet.getAccount(accountIndex?: number, keyIndex?: number) → Account`**

Lấy thông tin tài khoản với các khóa và địa chỉ đã được sinh ra.

**Parameters:**
- `accountIndex?` (number): Chỉ mục tài khoản (theo BIP-44). Mặc định: 0
- `keyIndex?` (number): Chỉ mục địa chỉ. Mặc định: 0

**Example:**
```typescript
import { AppWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'

const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: ['word1', 'word2', ...] },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Lấy tài khoản đầu tiên (account 0, address 0)
const account = wallet.getAccount(0, 0)

console.log({
  // Thông tin địa chỉ
  baseAddressBech32: account.baseAddressBech32,
  enterpriseAddressBech32: account.enterpriseAddressBech32,
  rewardAddressBech32: account.rewardAddressBech32,
  
  // Thông tin khóa
  paymentKey: account.paymentKey,
  stakeKey: account.stakeKey,
  
  // Chỉ mục
  accountIndex: account.accountIndex,
  addressIndex: account.addressIndex
})

// Mặc định: tài khoản 0, địa chỉ 0
const defaultAccount = wallet.getAccount()
```

**Returns:** `Account`
- `baseAddressBech32`: Địa chỉ cơ sở (thanh toán + staking)
- `enterpriseAddressBech32`: Địa chỉ doanh nghiệp (chỉ thanh toán)
- `rewardAddressBech32`: Địa chỉ phần thưởng (chỉ staking)
- `paymentKey`: Khóa thanh toán
- `stakeKey`: Khóa staking
- `accountIndex`: Chỉ mục tài khoản
- `addressIndex`: Chỉ mục địa chỉ

### **`AppWallet.signTx(txCbor: string, partialSign?: boolean, accountIndex?: number, keyIndex?: number) → Promise<string>`**

Ký một giao dịch Cardano. Hỗ trợ ký hoàn toàn hoặc ký một phần (multi-sig).

**Parameters:**
- `txCbor` (string): Giao dịch dưới dạng CBOR hex
- `partialSign?` (boolean): Nếu true, ký một phần. Mặc định: false
- `accountIndex?` (number): Chỉ mục tài khoản. Mặc định: 0
- `keyIndex?` (number): Chỉ mục địa chỉ. Mặc định: 0

**Example:**
```typescript
// Ký hoàn toàn
const signedTx = await wallet.signTx(unsignedTxCbor, false, 0, 0)

// Ký một phần (multi-sig)
const partialSigned = await wallet.signTx(unsignedTxCbor, true, 0, 0)

console.log('Giao dịch đã ký:', signedTx)
```

**Returns:** `Promise<string>`  
Giao dịch đã ký dưới dạng CBOR hex

### **`AppWallet.signData(address: string, payload: string, accountIndex?: number, keyIndex?: number) → Promise<{ signature: string; key: string }>`**

Ký dữ liệu tùy ý theo CIP-8 (Cardano Improvement Proposal).

> **Không được triển khai trên `AppWallet`.** Việc gọi `AppWallet.signData()` sẽ ném ra lỗi `[AppWallet] signData() is not implemented.` Chỉ `EmbeddedWallet.signData()` mới thực sự ký dữ liệu — nó có cùng signature và trả về `{ signature, key }`.

**Parameters:**
- `address` (string): Địa chỉ Cardano (bech32)
- `payload` (string): Dữ liệu cần ký
- `accountIndex?` (number): Chỉ mục tài khoản. Mặc định: 0
- `keyIndex?` (number): Chỉ mục địa chỉ. Mặc định: 0

**Example:**
```typescript
import { EmbeddedWallet } from '@hydra-sdk/core'

// AppWallet.signData() throws — use EmbeddedWallet.signData() instead
const signature = await embeddedWallet.signData(
  'addr_test1qz2fxv2umyhttkxyxp8x0...',
  'Hello World',
  0,
  0
)

console.log('Chữ ký dữ liệu:', signature)
// => { signature: '...', key: '...' }
```

**Returns:** `Promise<{ signature: string; key: string }>`
- `signature`: Chữ ký dưới dạng hex
- `key`: Khóa công khai dưới dạng hex

### **`DemeterProvider`** <Badge type="tip" text="Mới trong v1.3.2" />

Provider cho các endpoint được host tương thích Blockfrost của [Demeter](https://demeter.run). Kế thừa `BlockfrostProvider`, nên nó cung cấp cùng giao diện `fetcher`/`submitter`. Việc xác thực được nhúng vào subdomain của endpoint qua `authToken`.

**Constructor:**
```typescript
import { ProviderUtils } from '@hydra-sdk/core'

const demeterProvider = new ProviderUtils.DemeterProvider({
  authToken: 'blockfrost102lx3ckhzvkjjh7677g',
  network: 'preprod' // 'mainnet' | 'preprod' | 'preview'
})

// Same fetcher / submitter interface as BlockfrostProvider
const utxos = await demeterProvider.fetcher.fetchAddressUTxOs(address)

// Use with wallet
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: mnemonic },
  fetcher: demeterProvider.fetcher,
  submitter: demeterProvider.submitter
})
```

Endpoint được xây dựng theo dạng `https://{authToken}.cardano-{network}.blockfrost-m1.demeter.run/api/v{apiVersion ?? 0}`.

### **`convertUTxOObjectToUTxOWithOptions(utxoObject: UTxOObject, options?: ConvertOptions) → UTxO[]`** <Badge type="tip" text="Mới trong v1.3.0" />

Tương tự `convertUTxOObjectToUTxO` nhưng nhận thêm một đối tượng tùy chọn để tinh chỉnh bộ nhớ cache giải mã datum nội bộ.

**Tham số:**
- `utxoObject` (UTxOObject): Đối tượng UTxO từ snapshot
- `options?`:
  - `maxDatumCacheSize?` (number): Số lượng tối đa các mục `PlutusData` đã giải mã được lưu vào cache. `0` vô hiệu hóa cache. Mặc định: `1024`

**Tại sao quan trọng:** Khi xử lý snapshot lớn (hàng nghìn UTxO) có chứa inline datums lặp lại, cache giúp tránh các lần gọi WASM giải mã dư thừa. Chính sách loại bỏ LRU giữ cho mức sử dụng bộ nhớ có giới hạn.

**Ví dụ:**
```typescript
import { Converter } from '@hydra-sdk/core'

// Mặc định — cache tối đa 1024 mục datum
const utxos = Converter.convertUTxOObjectToUTxOWithOptions(snapshotUtxo)

// Cache lớn hơn cho snapshot với nhiều inline datum độc nhất
const utxos = Converter.convertUTxOObjectToUTxOWithOptions(snapshotUtxo, {
	maxDatumCacheSize: 4096
})

// Vô hiệu hóa cache hoàn toàn
const utxos = Converter.convertUTxOObjectToUTxOWithOptions(snapshotUtxo, {
	maxDatumCacheSize: 0
})
```

**Returns:** `UTxO[]`

---
