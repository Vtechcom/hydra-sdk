## HydraBridge

Class chính để kết nối và quản lý Hydra Heads.

### **`HydraBridge.constructor(options: HydraBridgeOptions) → HydraBridge`**

Khởi tạo một Hydra Bridge mới.

**Parameters:**

- `options` (HydraBridgeOptions):
  - `url?`: WebSocket URL (ví dụ: `'ws://localhost:4001'`, `'wss://gateway/path?X-Api-Key=...'`)
  - `connector?`: Custom connector instance
  - `verbose?`: Bật chế độ verbose logging (mặc định: false)
  - `history?`: Bật nhận lịch sử node đầy đủ (mặc định: false)
  - `noSnapshotUtxo?`: Vô hiệu hóa hiển thị snapshot UTxO (mặc định: false)
  - `address?`: Lọc transaction outputs theo địa chỉ cụ thể
  - `autoReconnect?`: Tự động kết nối lại khi WebSocket bị ngắt (mặc định: false)
  - `reconnectInterval?`: Khoảng thời gian giữa các lần thử kết nối lại (milliseconds, mặc định: 3000)
  - `maxReconnectAttempts?`: Số lần thử kết nối lại tối đa; 0 = không giới hạn (mặc định: 0)

**Example:**

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

// Kết nối trực tiếp WebSocket
const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	verbose: true
})

// Với các tùy chọn nâng cao
const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	verbose: true,
	history: true,
	noSnapshotUtxo: false,
	address: 'addr_test1...'
})

// Kết nối Hydra Hub với API key
const bridge = new HydraBridge({
	url: 'wss://hydra-hub.example.com?X-Api-Key=your_api_key_here',
	verbose: true
})

// Sử dụng custom connector
const bridge = new HydraBridge({
	connector: customConnector,
	verbose: true
})

// Với tự động kết nối lại
const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	autoReconnect: true,
	reconnectInterval: 3000,      // thử lại mỗi 3 giây
	maxReconnectAttempts: 10      // bỏ cuộc sau 10 lần thử (0 = không giới hạn)
})
```

**Returns:** `HydraBridge`
Instance HydraBridge mới

## Thuộc tính

### **`HydraBridge.slotZeroTimestamp: number | null`**

Unix timestamp (ms) của slot 0, được suy ra từ trường `currentSlot` của tin nhắn `Greetings` (hydra-node v1.3.0+). Sử dụng để chuyển đổi slot ↔ thời gian bên trong Hydra Head. Giá trị `null` cho đến khi nhận được `Greetings` đầu tiên.

```typescript
bridge.events.on('onMessage', payload => {
	if (payload.tag === 'Greetings' && bridge.slotZeroTimestamp !== null) {
		console.log('Slot-zero epoch:', bridge.slotZeroTimestamp)
	}
})
```

---

### **`HydraBridge.lastSnapshotNumber: number`**

Số snapshot cao nhất đã được áp dụng vào bộ nhớ cache. Giá trị `-1` cho đến khi snapshot đầu tiên đến. Đặt lại thành `-1` mỗi lần kết nối lại để cache được nạp lại đúng cách.

```typescript
console.log('Snapshot hiện tại:', bridge.lastSnapshotNumber)
```

### **`HydraBridge.getAddressBalance(address: string) → Map<string, bigint> | null`**

Tra cứu số dư O(1) từ bộ nhớ cache được tính toán sẵn. Được xây dựng lại tự động mỗi khi có sự kiện snapshot — không cần I/O cho mỗi lần gọi.

- Trả về `null` khi khởi động nguội (cache chưa được nạp) — người dùng nên gọi `querySnapshotUtxo()` trước.
- Trả về `Map` rỗng khi địa chỉ nằm trong Head nhưng không có UTxO nào.
- Khóa là đơn vị tài sản (`'lovelace'`, `'policyId+assetName'`); giá trị là `bigint`.

**Tham số:**

- `address` (string): Địa chỉ Cardano (bech32)

**Ví dụ:**

```typescript
const balance = bridge.getAddressBalance(account.baseAddressBech32)

if (balance === null) {
	console.log('Cache chưa được nạp — chờ Greetings hoặc gọi querySnapshotUtxo()')
} else {
	const lovelace = balance.get('lovelace') ?? 0n
	console.log('Số dư ADA:', Number(lovelace) / 1_000_000)

	for (const [unit, qty] of balance) {
		if (unit !== 'lovelace') console.log(unit, qty.toString())
	}
}
```

**Returns:** `Map<string, bigint> | null`

### **`HydraBridge.submitTx(transaction: Transaction, callback: SubmitTxCallback, options?: SubmitOptions) → void`**

Gửi giao dịch sử dụng callback theo kiểu error-first của Node.js. Không chặn — trả về ngay lập tức.

**Tham số:**

- `transaction` (Transaction): Giao dịch cần gửi
- `callback` `(error: SubmitTxError | null, result: SubmitTxResult | null) => void`: Được gọi một lần khi giao dịch được xác nhận, bị từ chối hoặc hết thời gian chờ
- `options?` (SubmitOptions): `{ timeout?: number }` — mặc định 30 000ms

**Ví dụ:**

```typescript
bridge.submitTx(
	{ type: 'Witnessed Tx ConwayEra', description: '', cborHex: signedTxCbor, txId },
	(error, result) => {
		if (error) {
			console.error('Gửi thất bại:', error.reason)
			return
		}
		console.log('Đã xác nhận trong snapshot:', result!.result?.snapshot?.number)
	},
	{ timeout: 30000 }
)
```

**Returns:** `void`

### **Head Lifecycle Events**

```typescript
bridge.events.on('onMessage', payload => {
	console.log('Nhận tin nhắn:', payload.tag, payload.timestamp)

	switch (payload.tag) {
		case 'Greetings':
			console.log('Lời chào từ Head:', {
				headStatus: payload.headStatus,
				headId: payload.hydraHeadId,
				// Các trường v1.3.0
				currentSlot: payload.currentSlot,
				chainSyncedStatus: payload.chainSyncedStatus,
				nodeVersion: payload.hydraNodeVersion
			})
			// slotZeroTimestamp được tự động suy ra khi currentSlot có mặt
			console.log('Slot-zero timestamp:', bridge.slotZeroTimestamp)
			break

		case 'HeadIsInitializing':
			console.log('Head đang khởi tạo với các bên:', payload.parties)
			break

		case 'HeadIsOpen':
			console.log('Head đã mở và sẵn sàng cho giao dịch!')
			break

		case 'HeadIsClosed':
			console.log('Head đã đóng, thực hiện fanout...')
			break

		case 'HeadIsFinalized':
			console.log('Vòng đời Head hoàn thành')
			break

		case 'TxValid':
			console.log('Giao dịch hợp lệ:', payload.transaction)
			break

		case 'TxInvalid':
			console.log('Giao dịch không hợp lệ:', {
				transaction: payload.transaction,
				error: payload.validationError
			})
			break

		case 'SnapshotConfirmed':
			console.log('Snapshot đã xác nhận')
			break

		case 'Committed':
			console.log('UTxO đã commit:', payload.utxo)
			break

		case 'DecommitApproved':
			console.log('Decommit đã phê duyệt:', payload.decommitTxId)
			break

		case 'DecommitFinalized':
			console.log('Decommit đã hoàn thành')
			break

		case 'CommandFailed':
			console.error('Lệnh thất bại:', payload.clientInput)
			break
	}
})
```

## Complete Examples

### Quản lý Head cơ bản

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

async function manageHydraHead() {
	const bridge = new HydraBridge({
		url: 'ws://localhost:4001',
		verbose: true
	})

	// Thiết lập handlers trước khi kết nối
	bridge.events.on('onConnected', () => {
		console.log('Đã kết nối! Đang khởi tạo Head...')
		bridge.commands.init()
	})

	bridge.events.on('onMessage', payload => {
		switch (payload.tag) {
			case 'HeadIsInitializing':
				console.log('Head đang khởi tạo với', payload.parties.length, 'bên')
				break
			case 'HeadIsOpen':
				console.log('Head đã mở và sẵn sàng cho giao dịch!')
				break
			case 'TxValid':
				console.log('Giao dịch đã xác nhận:', payload.transaction.txId)
				break
			case 'HeadIsClosed':
				console.log('Head đã đóng, thực hiện fanout...')
				bridge.commands.fanout()
				break
			case 'HeadIsFinalized':
				console.log('Vòng đời Head hoàn thành')
				bridge.disconnect()
				break
		}
	})

	// Kết nối để bắt đầu quy trình
	await bridge.connect()
}
```

### Xử lý giao dịch trong Hydra Head

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet } from '@hydra-sdk/core'

async function processHydraTransactions() {
	const bridge = new HydraBridge({
		url: 'ws://localhost:4001',
		verbose: true
	})

	const wallet = new AppWallet({
		networkId: 0,
		key: { type: 'mnemonic', words: AppWallet.brew() }
	})

	bridge.events.on('onConnected', async () => {
		// Lấy tham số giao thức
		const protocolParams = await bridge.getProtocolParameters()

		// Tạo transaction builder
		const txBuilder = new TxBuilder({
			isHydra: true,
			params: protocolParams
		})

		// Lấy tài khoản và UTxOs
		const account = wallet.getAccount(0, 0)
		const addressUtxos = await bridge.queryAddressUTxO(account.baseAddressBech32)

		if (addressUtxos.length === 0) {
			console.log('Không tìm thấy UTxOs cho địa chỉ')
			return
		}

		// Xây dựng và ký giao dịch
		const tx = await txBuilder
			.setInputs(addressUtxos)
			.txOut(account.baseAddressBech32, [
				{ unit: 'lovelace', quantity: '1000000' }
			])
			.changeAddress(account.baseAddressBech32)
			.complete()

		const signedTx = await wallet.signTx(tx.to_hex(), false, 0, 0)

		// Gửi tới Hydra Head
		const result = await bridge.submitTxSync(
			{
				type: 'Witnessed Tx ConwayEra',
				description: 'Ledger Cddl Format',
				cborHex: signedTx,
				txId: tx.id
			},
			{ timeout: 30000 }
		)

		console.log('Giao dịch thành công:', result)
	})

	await bridge.connect()
}
```

## Best Practices

1. **Event Setup**: Luôn thiết lập event handlers trước khi gọi `connect()`
2. **Đọc số dư**: Ưu tiên dùng `getAddressBalance()` (O(1), không I/O) thay vì `queryAddressUTxO()` khi chỉ cần số lượng — cache được cập nhật tự động mỗi khi có `SnapshotConfirmed`
3. **Auto-reconnect**: Sử dụng `autoReconnect: true` trong môi trường production; `disconnect()` hủy vòng lặp kết nối lại một cách an toàn
4. **Callback vs Promise**: Dùng `submitTx` (callback) khi cần gửi không chặn; dùng `submitTxSync` (Promise) khi cần `await` xác nhận trước khi tiếp tục
5. **Authentication**:
   - Với Hydra Hub: Truyền API key trong URL query params (`?X-Api-Key=your_key`)
   - Với Hexcore: Sử dụng JWT tokens trong Socket.IO auth options
6. **Resource Cleanup**: Luôn gọi `disconnect()` khi hoàn thành
7. **Số học slot**: Sử dụng `bridge.slotZeroTimestamp` + `TimeUtils` từ `@hydra-sdk/core` để chuyển đổi slot ↔ thời gian bên trong Head
8. **Timeout Configuration**: Đặt timeout phù hợp cho `submitTxSync` / `submitTx` (mặc định 30 000ms)
9. **Logging**: Bật `verbose: true` để debug trong quá trình phát triển
