# @hydra-sdk/bridge API Reference

Bridge package cung cấp tích hợp Hydra Layer 2 hoàn chỉnh với xử lý sự kiện thời gian thực, quản lý vòng đời Head, và xử lý transaction.

## HydraBridge

Class chính để kết nối và quản lý Hydra Heads.

### Constructor

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

// Kết nối WebSocket trực tiếp
const bridge = new HydraBridge({
  url: 'ws://localhost:4001',
  verbose: true
})

// Sử dụng custom connector
const bridge = new HydraBridge({
  connector: customConnector,
  verbose: true
})
```

### # Quản lý Kết nối

### **`connect()`**
Kết nối tới Hydra Node:

```typescript
await bridge.connect()
console.log('Đã kết nối tới Hydra Node')
```

### **`disconnect()`**
Ngắt kết nối khỏi Hydra Node:

```typescript
await bridge.disconnect()
console.log('Đã ngắt kết nối khỏi Hydra Node')
```

### **`connected()`**
Kiểm tra trạng thái kết nối:

```typescript
const isConnected = bridge.connected()
console.log('Trạng thái kết nối:', isConnected)
```

### # Thông tin Head

### **`headInfo()`**
Lấy thông tin head hiện tại:

```typescript
const info = await bridge.headInfo()
console.log({
  headId: info.headId,
  headStatus: info.headStatus,
  vkey: info.vkey
})
```

### # Tham số Protocol

### **`getProtocolParameters()`**
Lấy tham số protocol Cardano:

```typescript
const protocolParams = await bridge.getProtocolParameters()
console.log('Tham số protocol:', {
  minFeeA: protocolParams.min_fee_a,
  minFeeB: protocolParams.min_fee_b,
  maxTxSize: protocolParams.max_tx_size,
  keyDeposit: protocolParams.key_deposit,
  poolDeposit: protocolParams.pool_deposit
})
```

### # Quản lý UTxO

### **`querySnapshotUtxo()`**
Truy vấn UTxOs snapshot hiện tại:

```typescript
const utxoObject = await bridge.querySnapshotUtxo()
console.log('Snapshot UTxO:', utxoObject)
```

### **`snapshotUtxoArray()`**
Lấy mảng UTxO từ snapshot:

```typescript
const utxoArray = bridge.snapshotUtxoArray()
console.log('Mảng UTxO:', utxoArray)
```

### **`queryAddressUTxO(address)`**
Truy vấn UTxOs cho địa chỉ cụ thể:

```typescript
const account = wallet.getAccount(0, 0)
const addressUtxos = await bridge.queryAddressUTxO(account.baseAddressBech32)
console.log('UTxOs của địa chỉ:', addressUtxos)
```

### **`addressesInHead()`**
Lấy tất cả địa chỉ trong head hiện tại:

```typescript
const addresses = await bridge.addressesInHead()
console.log('Các địa chỉ trong Head:', addresses)
```

### # Thao tác Transaction

### **`submitTxSync(transaction, options)`**
Gửi transaction và đợi xác nhận:

```typescript
const result = await bridge.submitTxSync({
  type: 'Witnessed Tx ConwayEra',
  description: 'Ledger Cddl Format',
  cborHex: signedTxCbor,
  txId: transactionId
}, { timeout: 30000 })

console.log('Kết quả transaction:', {
  txId: result.txId,
  isValid: result.isValid,
  isConfirmed: result.isConfirmed
})
```

### **`commit(data)`**
Commit UTxOs vào head:

```typescript
const result = await bridge.commit({
  cborHex: commitTxCbor,
  description: 'Commit transaction'
})
console.log('Kết quả commit:', result)
```

### **`submitCardanoTransaction(data)`**
Gửi transaction tới mạng Cardano:

```typescript
const result = await bridge.submitCardanoTransaction({
  cborHex: txCbor,
  description: 'Cardano transaction'
})
console.log('Transaction Cardano đã gửi:', result)
```

### # Lệnh (Commands)

Thực thi các lệnh Hydra Head thông qua object `commands`:

### **`commands.init()`**
Khởi tạo Hydra Head mới:

```typescript
bridge.commands.init()
```

### **`commands.close()`**
Đóng Hydra Head:

```typescript
bridge.commands.close()
```

### **`commands.abort()`**
Hủy bỏ quá trình khởi tạo Head:

```typescript
bridge.commands.abort()
```

### **`commands.fanout()`**
Thực hiện fanout sau khi đóng Head:

```typescript
bridge.commands.fanout()
```

### **`commands.contest()`**
Tranh chấp việc đóng Head:

```typescript
bridge.commands.contest()
```

### **`commands.recover(recoverTxId)`**
Khôi phục từ transaction cụ thể:

```typescript
bridge.commands.recover('tx_hash_here')
```

### **`commands.newTx(cborHex, description, callback)`**
Gửi transaction mới tới Head:

```typescript
bridge.commands.newTx(
  signedTxCbor,
  'Payment transaction',
  () => console.log('Transaction đã gửi tới Head')
)
```

### **`commands.decommit(payload)`**
Decommit UTxOs từ head:

```typescript
const result = await bridge.commands.decommit({
  cborHex: decommitTxCbor,
  txId: transactionId,
  timeout: 30000
})
console.log('Kết quả decommit:', result)
```

### **`commands.initSync(retry, interval)`**
Khởi tạo head với logic retry:

```typescript
const result = await bridge.commands.initSync(3, 20000)
console.log('Head đã khởi tạo:', result)
```

## HexcoreConnector

Connector nâng cao cho tích hợp Hexcore API với xác thực Socket.IO.

### Constructor

```typescript
import { HexcoreConnector } from '@hydra-sdk/bridge'

const connector = new HexcoreConnector({
  socketIoUrl: 'wss://api.hexcore.io/hydra',
  socketIoOptions: {
    auth: {
      token: 'your_jwt_token'
    },
    transports: ['websocket'],
    timeout: 20000
  },
  namespace: 'hydra' // tùy chọn, mặc định là 'hydra'
})
```

### Sử dụng với HydraBridge

```typescript
const bridge = new HydraBridge({
  connector: connector,
  verbose: true
})

await bridge.connect()
```

### # Xử lý Sự kiện

Bridge cung cấp xử lý sự kiện toàn diện thông qua thuộc tính `events`:

### **Sự kiện Kết nối**

```typescript
bridge.events.on('onConnected', () => {
  console.log('Đã kết nối tới Hydra Node')
})

bridge.events.on('onDisconnected', () => {
  console.log('Đã ngắt kết nối khỏi Hydra Node')
})

bridge.events.on('onConnectError', (error) => {
  console.error('Lỗi kết nối:', error)
})

bridge.events.on('onError', (error) => {
  console.error('Lỗi:', error)
})
```

### **Sự kiện Message**

```typescript
bridge.events.on('onMessage', (payload) => {
  switch (payload.tag) {
    case 'Greetings':
      console.log('Nhận được lời chào từ Hydra Node')
      break
      
    case 'HeadIsInitializing':
      console.log('Head đang khởi tạo:', payload)
      break
      
    case 'HeadIsOpen':
      console.log('Head đã mở:', payload)
      break
      
    case 'HeadIsClosed':
      console.log('Head đã đóng:', payload)
      break
      
    case 'HeadIsFinalized':
      console.log('Head đã hoàn tất:', payload)
      break
      
    case 'TxValid':
      console.log('Transaction hợp lệ:', payload)
      break
      
    case 'TxInvalid':
      console.log('Transaction không hợp lệ:', payload)
      break
      
    case 'SnapshotConfirmed':
      console.log('Snapshot đã xác nhận:', payload)
      break
      
    case 'Committed':
      console.log('UTxO đã commit:', payload)
      break
      
    case 'DecommitRequested':
      console.log('Decommit đã được yêu cầu:', payload)
      break
      
    case 'DecommitApproved':
      console.log('Decommit đã được chấp thuận:', payload)
      break
      
    case 'DecommitFinalized':
      console.log('Decommit đã hoàn tất:', payload)
      break
      
    case 'PeerConnected':
      console.log('Peer đã kết nối:', payload)
      break
      
    case 'PeerDisconnected':
      console.log('Peer đã ngắt kết nối:', payload)
      break
      
    case 'CommandFailed':
      console.error('Lệnh thất bại:', payload)
      break
      
    case 'InvalidInput':
      console.error('Input không hợp lệ:', payload)
      break
  }
})
```

## Ví dụ Use Case Hoàn chỉnh

### Khởi tạo và Quản lý Head

```typescript
import { HydraBridge, WebsocketConnector } from '@hydra-sdk/bridge'
import { AppWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'
import { TxBuilder } from '@hydra-sdk/transaction'

// Thiết lập wallet
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: {
    type: 'mnemonic',
    words: ['your', 'mnemonic', 'words', '...']
  },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Kết nối tới Hydra Node
const bridge = new HydraBridge({
  url: 'ws://localhost:4001',
  verbose: true
})

await bridge.connect()

// Lắng nghe sự kiện
bridge.events.on('onMessage', (payload) => {
  console.log('Received message:', payload.tag)
})

// Khởi tạo Head
bridge.commands.init()

// Đợi Head mở
await new Promise((resolve) => {
  bridge.events.on('onMessage', (payload) => {
    if (payload.tag === 'HeadIsOpen') {
      console.log('Head is now open!')
      resolve(true)
    }
  })
})
```

### Gửi Transaction trong Head

```typescript
// Lấy UTxOs từ Head
const account = wallet.getAccount(0, 0)
const utxos = await bridge.queryAddressUTxO(account.baseAddressBech32)

// Lấy protocol parameters từ Head
const params = await bridge.getProtocolParameters()

// Xây dựng transaction
const txBuilder = new TxBuilder({ params })
const tx = await txBuilder
  .setInputs(utxos)
  .addOutput({
    address: 'addr_test1...',
    amount: [{ unit: 'lovelace', quantity: '5000000' }]
  })
  .changeAddress(account.baseAddressBech32)
  .complete()

// Ký transaction
const signedTx = await wallet.signTx(tx.to_hex())

// Gửi tới Head và đợi xác nhận
const result = await bridge.submitTxSync({
  type: 'Witnessed Tx ConwayEra',
  description: 'Payment in Head',
  cborHex: signedTx,
  txId: tx.hash().to_hex()
}, { timeout: 30000 })

console.log('Transaction confirmed:', result.isConfirmed)
```

### Decommit UTxOs từ Head

```typescript
// Xây dựng decommit transaction
const decommitTx = await txBuilder
  .setInputs(utxos)
  .addOutput({
    address: account.baseAddressBech32,
    amount: [{ unit: 'lovelace', quantity: '3000000' }]
  })
  .changeAddress(account.baseAddressBech32)
  .complete()

const signedDecommitTx = await wallet.signTx(decommitTx.to_hex())

// Thực hiện decommit
const decommitResult = await bridge.commands.decommit({
  cborHex: signedDecommitTx,
  txId: decommitTx.hash().to_hex(),
  timeout: 60000
})

console.log('Decommit approved:', decommitResult)
```

### Đóng Head

```typescript
// Đóng Head
bridge.commands.close()

// Đợi Head đóng
await new Promise((resolve) => {
  bridge.events.on('onMessage', (payload) => {
    if (payload.tag === 'HeadIsClosed') {
      console.log('Head is now closed')
      resolve(true)
    }
  })
})

// Fanout funds
bridge.commands.fanout()

// Đợi finalization
await new Promise((resolve) => {
  bridge.events.on('onMessage', (payload) => {
    if (payload.tag === 'HeadIsFinalized') {
      console.log('Head is finalized, funds returned to L1')
      resolve(true)
    }
  })
})

await bridge.disconnect()
```

## Xử lý Lỗi Best Practices

```typescript
// Thiết lập xử lý lỗi toàn diện
function setupErrorHandling(bridge: HydraBridge) {
  // Lỗi kết nối
  bridge.events.on('onConnectError', (error) => {
    console.error('Kết nối thất bại:', error)
    // Implement exponential backoff reconnection
  })

  // Lỗi chung
  bridge.events.on('onError', (error) => {
    console.error('Lỗi Bridge:', error)
    // Log tới error tracking service
  })

  // Lỗi validation transaction
  bridge.events.on('onMessage', (payload) => {
    if (payload.tag === 'TxInvalid') {
      console.error('Validation transaction thất bại:', {
        txId: payload.transaction.txId,
        error: payload.validationError,
        utxo: payload.utxo
      })
      // Xử lý logic retry transaction
    }
    
    if (payload.tag === 'CommandFailed') {
      console.error('Lệnh Hydra thất bại:', {
        command: payload.clientInput,
        timestamp: payload.timestamp
      })
      // Xử lý retry lệnh hoặc fallback
    }
  })
}
```

## Best Practices

1. **Thiết lập Event**: Luôn thiết lập event handlers trước khi gọi `connect()`
2. **Xử lý Lỗi**: Implement xử lý lỗi toàn diện và logic reconnection
3. **Quản lý State**: Theo dõi trạng thái Head để đảm bảo các thao tác hợp lệ
4. **Xác thực**: Sử dụng JWT tokens phù hợp cho kết nối Hexcore
5. **Dọn dẹp Resource**: Luôn gọi `disconnect()` khi hoàn tất
6. **Validation Transaction**: Validate transactions trước khi submit
7. **Cấu hình Timeout**: Đặt timeout phù hợp cho các thao tác
8. **Logging**: Bật verbose mode để debug trong quá trình phát triển
