## TxBuilder

Lớp chính để xây dựng và quản lý giao dịch Cardano với hỗ trợ toàn diện cho tất cả các tính năng Cardano.

### **`TxBuilder.constructor(options?: TxBuilderOptions) → TxBuilder`**

Khởi tạo một transaction builder mới.

**Parameters:**
- `options?` (TxBuilderOptions): Tuỳ chọn cấu hình
  - `fetcher?`: Custom fetcher
  - `submitter?`: Custom submitter
  - `isHydra?`: Cho phép tạo giao dịch cho Hydra Head
  - `params?`: Tham số giao thức tùy chỉnh
  - `verbose?`: Bật chế độ verbose
  - `errorLogger?`: Chế độ strict/testing — ném lỗi thay vì tiếp tục khi việc xây dựng giao dịch gặp vấn đề (mặc định: false; không khuyến nghị cho production)

**Example:**
```typescript
import { TxBuilder } from '@hydra-sdk/transaction'

// Tạo builder cơ bản
const txBuilder = new TxBuilder()

// Với tham số giao thức tùy chỉnh
const txBuilder = new TxBuilder({
  params: {
    minFeeA: 44,
    minFeeB: 155381,
    maxTxSize: 16384
  }
})

// Cho Hydra transactions
const txBuilder = new TxBuilder({
  isHydra: true,
  params: protocolParams,
  verbose: true
})
```

**Returns:** `TxBuilder`  
Một instance TxBuilder mới

### **`TxBuilder.setInputs(utxos: UTxO[], options?: { strategy: CoinSelectionStrategy }) → TxBuilder`**

Cung cấp các UTxO mà builder có thể chi tiêu và chọn coin-selection strategy. Builder sẽ chọn UTxO nào trong số này để tiêu thụ khi hoàn thành giao dịch. Đây là điểm truy cập công khai cho coin selection.

**Parameters:**
- `utxos` (UTxO[]): Danh sách UTxOs khả dụng
- `options?` (`{ strategy: CoinSelectionStrategy }`): Tuỳ chọn coin-selection. Mặc định: `{ strategy: 'LargestFirstMultiAsset' }`
  - `LargestFirst`: Chọn coins lớn nhất trước
  - `RandomImprove`: Random selection với improvement
  - `LargestFirstMultiAsset`: Multi-asset friendly (mặc định)
  - `RandomImproveMultiAsset`: Multi-asset friendly random

**Example:**
```typescript
const utxos = await wallet.queryUtxos()

// Default strategy (LargestFirstMultiAsset)
const tx1 = await txBuilder.setInputs(utxos).complete()

// Specific strategy
const tx2 = await txBuilder.setInputs(utxos, { strategy: 'RandomImprove' }).complete()

// Restrict selection to specific UTxOs
const specificUtxos = utxos.filter(utxo =>
  utxo.output.amount.some(asset => asset.unit !== 'lovelace')
)
const tx3 = await txBuilder.setInputs(specificUtxos).complete()
```

**Returns:** `TxBuilder`  
Trả về chính builder để chain methods

### **`TxBuilder.txIn(txHash: string, outputIndex: number, amount?: Asset[], address?: string) → TxBuilder`**

Thêm input giao dịch.

**Parameters:**
- `txHash` (string): Hash giao dịch
- `outputIndex` (number): Chỉ mục output
- `amount?` (Asset[]): Số lượng assets (tuỳ chọn)
- `address?` (string): Địa chỉ (tuỳ chọn)

**Example:**
```typescript
txBuilder.txIn(
  'a1b2c3d4e5f6...',
  0,
  [{ unit: 'lovelace', quantity: '2000000' }],
  'addr_test1...'
)
```

**Returns:** `TxBuilder`

### **`TxBuilder.calculateFee() → BigNum`**

Tính phí tối thiểu.

> **Note:** Trong bản phát hành hiện tại, phương thức này là một stub — nó luôn trả về `CardanoWASM.BigNum.zero()`. Phí được tính nội bộ trong quá trình `complete()`; đừng dựa vào `calculateFee()` để ước tính phí thực tế lúc này.

**Example:**
```typescript
const minFee = txBuilder.calculateFee()
console.log('Phí tối thiểu:', minFee.to_str()) // currently always '0'
```

**Returns:** `BigNum`  
Phí tối thiểu (hiện tại luôn là `0`)

## Utility Functions

### Building datums

Package `@hydra-sdk/transaction` chỉ export tx-builder và các helper redeemer-builder — **không có** export `buildDatum`. Khi cần dựng `PlutusData` cho một datum, hãy dùng `DatumUtils` từ `@hydra-sdk/core`.

**Example:**
```typescript
import { DatumUtils } from '@hydra-sdk/core'

// Constr(0, [Int(42), Bytes('a1b2')])
const datum = DatumUtils.mkConstr(0, [
  DatumUtils.mkInt(42),
  DatumUtils.mkBytes('a1b2')
])
```

**Returns:** `PlutusData`

---

### **`buildRedeemer(jsValue: Record<string, string>, options?) → Redeemer`**

Xây dựng redeemer cho một Plutus script. `jsValue` là **bắt buộc** — mỗi giá trị được mã hóa thành một trường `bytes` của redeemer `Constr(0, …)`. Gọi mà không có đối số sẽ ném lỗi.

**Parameters:**
- `jsValue` (`Record<string, string>`): Các giá trị cần mã hóa thành trường redeemer
- `options?`: `{ tag?: 'SPEND' | 'MINT' | 'REWARD' | 'CERT' | 'VOTE' | 'VOTING_PROPOSAL'; index?: number | string; exUnits?: { mem: string; steps: string } }` (tag mặc định `'SPEND'`, index mặc định `0`)

**Example:**
```typescript
import { buildRedeemer } from '@hydra-sdk/transaction'

const redeemer = buildRedeemer({ action: 'claim' }, { tag: 'SPEND', index: 0 })
```

> Trong hầu hết trường hợp, hãy ưu tiên `emptyRedeemer(...)` (bên dưới) hoặc `RedeemerUtils.mkRedeemer(...)` từ `@hydra-sdk/core`, vốn dựng redeemer trực tiếp từ `PlutusData`.

**Returns:** `Redeemer`

---

### **`emptyRedeemer() → Redeemer`**

Tạo empty redeemer.

**Example:**
```typescript
import { emptyRedeemer } from '@hydra-sdk/transaction'

const redeemer = emptyRedeemer()
```

**Returns:** `Redeemer`

### **`MetadataUtils.metadataObjToMetadatum(obj: any) → TransactionMetadatum`**

Chuyển đổi một object metadata sang `TransactionMetadatum`. Helper này nằm trong `@hydra-sdk/core` dưới namespace `MetadataUtils` — nó **không** được export từ `@hydra-sdk/transaction`.

**Parameters:**
- `obj` (any): Object metadata

**Example:**
```typescript
import { MetadataUtils } from '@hydra-sdk/core'

const metadata = MetadataUtils.metadataObjToMetadatum({
  '1': 'Hello',
  '2': 12345
})
```

**Returns:** `TransactionMetadatum`

## Types and Interfaces

### TxBuilderOptions

```typescript
interface TxBuilderOptions {
  fetcher?: IFetcher
  submitter?: ISubmitter
  isHydra?: boolean
  params?: Partial<Protocol>
  verbose?: boolean
  /**
   * Strict/testing mode: throw instead of continuing when tx building hits an
   * issue (e.g. coin selection fails). Default: false. Not for production use.
   */
  errorLogger?: boolean
}
```

### CoinSelectionStrategy

```typescript
type CoinSelectionStrategy =
  | 'LargestFirst'
  | 'RandomImprove'
  | 'LargestFirstMultiAsset'
  | 'RandomImproveMultiAsset'
```

> **Note:** `TxBuilderOptions` và `CoinSelectionStrategy` là các kiểu nội bộ — chúng **không** được re-export từ `@hydra-sdk/transaction`. Các cấu trúc được trình bày ở đây chỉ để tham khảo; hãy truyền object/string literal trực tiếp cho constructor và cho `setInputs`.

### Asset

```typescript
interface Asset {
  unit: string      // 'lovelace' or 'policyId.assetName'
  quantity: string  // Số lượng dưới dạng string
}
```

## Complete Examples

### Gửi ADA Đơn Giản

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet } from '@hydra-sdk/core'

async function sendAda() {
  const wallet = new AppWallet({
    networkId: 0,
    key: { type: 'mnemonic', words: AppWallet.brew() }
  })

  const account = wallet.getAccount(0, 0)
  const utxos = await wallet.queryUtxos(account.baseAddressBech32)

  const tx = await new TxBuilder()
    .setInputs(utxos)
    .txOut('addr_test1qqr585tvlc7ylnqvz8pyqwauzrdu0mxag3m7q56grgmgu7sxu2hyfhlkwuxupa9d5085eunq2qywy7hvmvej456flknswgndm3', [
      { unit: 'lovelace', quantity: '2000000' }
    ])
    .changeAddress(account.baseAddressBech32)
    .complete()

  const signedTx = await wallet.signTx(tx.to_hex(), false, 0, 0)
  console.log('Giao dịch đã ký:', signedTx)
}
```

### Plutus Script Interaction

```typescript
async function interactWithPlutusScript() {
  const scriptCbor = 'plutus_script_cbor'
  const datum = CardanoWASM.PlutusData.new_map(
    CardanoWASM.PlutusMap.new()
  )

  const tx = await new TxBuilder()
    .setInputs(utxos)
    .txIn(scriptUtxoHash, scriptUtxoIndex)
    .txInScript(scriptCbor)
    .txInDatumHash(datum)
    .txInEmptyRedeemer()
    .txInCollateral(collateralHash, 0, [{ unit: 'lovelace', quantity: '5000000' }], collateralAddress)
    .txOut(recipientAddress, [{ unit: 'lovelace', quantity: '10000000' }])
    .changeAddress(changeAddress)
    .complete()

  return tx
}
```
