# @hydra-sdk/transaction API Reference

Transaction package cung cấp công cụ nâng cao để xây dựng, quản lý, và gửi Cardano transactions, bao gồm hỗ trợ Plutus scripts, multi-asset transactions, staking operations, và tích hợp Hydra Layer 2.

## TxBuilder

Class chính để xây dựng và quản lý Cardano transactions với hỗ trợ toàn diện cho tất cả tính năng Cardano.

### Constructor

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'

// Transaction builder cơ bản
const txBuilder = new TxBuilder()

// Với custom protocol parameters
const txBuilder = new TxBuilder({
  params: {
    minFeeA: 44,
    minFeeB: 155381,
    maxTxSize: 16384
  }
})

// Cho Hydra transactions
const txBuilder = new TxBuilder({
  isHydra: true,
  params: protocolParams,
  verbose: true
})

// Với custom fetcher và submitter
const txBuilder = new TxBuilder({
  fetcher: customFetcher,
  submitter: customSubmitter,
  verbose: true
})
```

### # Transaction Input Methods

### **`txIn(txHash, outputIndex, amount, address)`**
Thêm transaction input:

```typescript
// Input cơ bản
txBuilder.txIn(
  'a1b2c3d4e5f6...', // transaction hash
  0,                 // output index
  [{ unit: 'lovelace', quantity: '2000000' }], // amount (tùy chọn)
  'addr_test1...'    // address (tùy chọn)
)

// Cho script validation
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
  .txInDatumHash(datum)
  .txInEmptyRedeemer()
```

### **`txInScript(scriptCbor)`**
Đính kèm Plutus script vào input cuối cùng:

```typescript
const scriptCbor = '590a4c590a49010000...'
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
```

### **`txInDatumHash(datum)`**
Thêm datum hash vào script input:

```typescript
const datum = CardanoWASM.PlutusData.from_hex('d87980')
txBuilder.txIn(txHash, outputIndex)
  .txInDatumHash(datum)
```

### **`txInInlineDatum(inlineDatum)`**
Thêm inline datum vào script input:

```typescript
const inlineDatum = CardanoWASM.PlutusData.from_hex('d87980')
txBuilder.txIn(txHash, outputIndex)
  .txInInlineDatum(inlineDatum)
```

### **`txInEmptyRedeemer()`**
Thêm empty redeemer cho script input:

```typescript
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
  .txInEmptyRedeemer()
```

### **`spendingPlutusScript(version)`**
Đặt phiên bản Plutus script cho input cuối cùng:

```typescript
txBuilder.txIn(txHash, outputIndex)
  .txInScript(scriptCbor)
  .spendingPlutusScript('V3') // 'V1', 'V2', hoặc 'V3'
```

### # Transaction Output Methods

### **`txOut(address, amount)`**
Thêm transaction output:

```typescript
// Output chỉ có ADA
txBuilder.txOut('addr_test1...', [
  { unit: 'lovelace', quantity: '2000000' }
])

// Multi-asset output
txBuilder.txOut('addr_test1...', [
  { unit: 'lovelace', quantity: '2000000' },
  { unit: 'policyId.assetName', quantity: '100' }
])
```

### **`txOutInlineDatumValue(inlineDatum)`**
Thêm inline datum vào output cuối cùng:

```typescript
const datum = CardanoWASM.PlutusData.from_hex('d87980')
txBuilder.txOut('addr_test1...', amount)
  .txOutInlineDatumValue(datum)
```

### **`txOutDatumHashValue(datum)`**
Thêm datum hash vào output cuối cùng:

```typescript
const datum = CardanoWASM.PlutusData.from_hex('d87980')
txBuilder.txOut('addr_test1...', amount)
  .txOutDatumHashValue(datum)
```

### **`txOutReferenceScript(scriptCbor, version)`**
Thêm reference script vào output cuối cùng:

```typescript
txBuilder.txOut('addr_test1...', amount)
  .txOutReferenceScript(scriptCbor, 'V3')
```

### # UTxO Selection Methods

### **`selectUtxosFrom(utxos, strategy)`**
Chọn UTxOs sử dụng coin selection strategy:

```typescript
const utxos = await wallet.queryUTxOs(address)

// Strategy mặc định (LargestFirstMultiAsset)
txBuilder.selectUtxosFrom(utxos)

// Strategy cụ thể
txBuilder.selectUtxosFrom(utxos, 'RandomImprove')
```

**Strategies có sẵn:**
- `'LargestFirst'` - Chọn UTxO lớn nhất trước (chỉ lovelace)
- `'RandomImprove'` - Random selection với improvement (chỉ lovelace)
- `'LargestFirstMultiAsset'` - Cho multi-asset (mặc định)
- `'RandomImproveMultiAsset'` - Random selection cho multi-asset

### **`setInputs(utxos)`**
Đặt UTxOs cụ thể làm inputs:

```typescript
const specificUtxos = utxos.filter(utxo => 
  utxo.output.amount.some(asset => asset.unit !== 'lovelace')
)
txBuilder.setInputs(specificUtxos)
```

### # Minting Methods

### **`mint(quantity, policyId, assetName)`**
Mint hoặc burn assets:

```typescript
// Mint tokens
txBuilder.mint('1000', policyId, 'TokenName')

// Burn tokens (số lượng âm)
txBuilder.mint('-500', policyId, 'TokenName')
```

### **`mintingScript(scriptCbor)`**
Đính kèm minting script vào thao tác mint cuối cùng:

```typescript
txBuilder.mint('1000', policyId, 'TokenName')
  .mintingScript(mintingScriptCbor)
```

### **`mintRedeemerValue(redeemer)`**
Thêm redeemer cho minting operation:

```typescript
const redeemer = CardanoWASM.Redeemer.new(
  CardanoWASM.RedeemerTag.new_mint(),
  CardanoWASM.BigNum.from_str('0'),
  CardanoWASM.PlutusData.from_hex('d87980'),
  CardanoWASM.ExUnits.new(
    CardanoWASM.BigNum.from_str('7000000'),
    CardanoWASM.BigNum.from_str('3000000000')
  )
)

txBuilder.mint('1000', policyId, 'TokenName')
  .mintingScript(mintingScriptCbor)
  .mintRedeemerValue(redeemer)
```

### **`mintPlutusScript(version)`**
Đặt phiên bản Plutus cho minting script:

```typescript
txBuilder.mintPlutusScript('V3')
  .mint('1000', policyId, 'TokenName')
  .mintingScript(mintingScriptCbor)
```

### # Metadata Methods

### **`metadataValue(label, value)`**
Thêm metadata vào transaction:

```typescript

  [policyId]: {
    [assetName]: {
      name: 'My NFT',
      image: 'ipfs://...',
      description: 'NFT description'
    }
  }
})

// CIP-20 message metadata

  msg: ['Hello', 'World', 'from', 'Cardano']
})
```


### **`invalidAfter(slot)`**

```typescript

```

### # Required Signers

### **`requiredSignerHash(pubKeyHash)`**

### # Fee and Change Methods

### **`calculateFee()`**
Tính toán minimum fee:

```typescript
const minFee = txBuilder.calculateFee()
console.log('Minimum fee:', minFee.to_str())
```

### **`setFee(fee)`**
Đặt fee cụ thể:

```typescript
txBuilder.setFee(CardanoWASM.BigNum.from_str('200000'))
```

### **`changeAddress(address)`**
Đặt change address:

```typescript
txBuilder.changeAddress('addr_test1...')
```

### # Build and Reset Methods

### **`complete()`**
Xây dựng và hoàn thành transaction:

```typescript
const transaction = await txBuilder.complete()

console.log('Transaction CBOR:', transaction.to_hex())
console.log('Transaction hash:', transaction.hash().to_hex())
```

### **`reset()`**
Reset transaction builder về trạng thái ban đầu:

```typescript
txBuilder.reset()
```

### **`updateProtocolParams(params)`**
Cập nhật protocol parameters:

```typescript
txBuilder.updateProtocolParams({
  minFeeA: 44,
  minFeeB: 155381,
  maxTxSize: 16384
})
```

## Ví dụ Use Case Hoàn chỉnh

### Simple Payment Transaction

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'

// Thiết lập wallet và provider
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-api-key',
  network: 'preprod'
})

const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: mnemonic },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Lấy address và UTxOs
const account = wallet.getAccount(0, 0)
const utxos = await wallet.queryUTxOs(account.baseAddressBech32)

// Xây dựng transaction
const txBuilder = new TxBuilder()
const tx = await txBuilder
  .setInputs(utxos)
  .addOutput({
    address: 'addr_test1...',
    amount: [{ unit: 'lovelace', quantity: '2000000' }]
  })
  .changeAddress(account.baseAddressBech32)
  .complete()

// Ký và gửi
const signedTx = await wallet.signTx(tx.to_hex())
const txHash = await wallet.submitTx(signedTx)
console.log('Transaction hash:', txHash)
```

### Multi-Asset Transaction

```typescript
// Gửi ADA và tokens
const tx = await txBuilder
```

### NFT Minting with Metadata

```typescript
import { CardanoWASM } from '@hydra-sdk/cardano-wasm'
import { DatumUtils } from '@hydra-sdk/core'

// Tạo minting policy
const policyId = 'your_policy_id'
const assetName = 'MyNFT'

// Xây dựng mint transaction với metadata
const tx = await txBuilder
  .setInputs(utxos)
  .mintPlutusScript('V3')
  .mint('1', policyId, assetName)
  .mintingScript(mintingScriptCbor)
  .mintRedeemerValue(redeemer)
  .addOutput({
    address: account.baseAddressBech32,
    amount: [
      { unit: 'lovelace', quantity: '2000000' },
      { unit: `${policyId}.${assetName}`, quantity: '1' }
    ]
  })
  .metadataValue('721', {
    [policyId]: {
      [assetName]: {
        name: 'My NFT',
        image: 'ipfs://QmXxxx...',
        description: 'This is my NFT',
        mediaType: 'image/png'
      }
    }
  })
  .changeAddress(account.baseAddressBech32)
  .complete()
```

### Smart Contract Interaction

```typescript
// Lock funds tại script address với datum
const lockDatum = DatumUtils.inline({
  constructor: 0,
  fields: [
    { int: 42 },
    { bytes: Buffer.from('hello').toString('hex') }
  ]
})

const lockTx = await txBuilder
  .setInputs(utxos)
  .txOut(scriptAddress, [{ unit: 'lovelace', quantity: '5000000' }])
  .txOutInlineDatumValue(lockDatum)
  .changeAddress(account.baseAddressBech32)
  .complete()

// Unlock funds từ script
const scriptUtxos = await wallet.queryUTxOs(scriptAddress)
const utxoToUnlock = scriptUtxos[0]

const unlockRedeemer = CardanoWASM.Redeemer.new(
  CardanoWASM.RedeemerTag.new_spend(),
  CardanoWASM.BigNum.from_str('0'),
  CardanoWASM.PlutusData.from_hex('d87980'), // redeemer data
  CardanoWASM.ExUnits.new(
    CardanoWASM.BigNum.from_str('7000000'),
    CardanoWASM.BigNum.from_str('3000000000')
  )
)

const unlockTx = await txBuilder
  .setInputs(utxos) // Collateral UTxOs
  .txIn(utxoToUnlock.input.txHash, utxoToUnlock.input.outputIndex)
  .txInScript(validatorScriptCbor)
  .txInInlineDatum(lockDatum)
  .txInRedeemerValue(unlockRedeemer)
  .spendingPlutusScript('V3')
  .txInCollateral(collateralTxHash, 0, collateralAmount, account.baseAddressBech32)
  .addOutput({
    address: account.baseAddressBech32,
    amount: utxoToUnlock.output.amount
  })
  .changeAddress(account.baseAddressBech32)
  .complete()
```

```typescript
  .complete()
```

## Utility Functions

### buildRedeemer

Build redeemer cho Plutus scripts:

```typescript
import { buildRedeemer } from '@hydra-sdk/transaction'

const redeemer = buildRedeemer(
  {
    constructor: '0',
    fields: [
      { int: '42' },
      { bytes: 'deadbeef' }
    ]
  },
  {
    tag: 'spend',
    index: 0,
    exUnits: {
      mem: '7000000',
      steps: '3000000000'
    }
  }
)
```

### emptyRedeemer

Tạo empty redeemer:

```typescript
import { emptyRedeemer } from '@hydra-sdk/transaction'

const redeemer = emptyRedeemer({
  tag: 'spend',
  index: 0,
  type: 'constr',
  exUnits: {
    mem: '7000000',
    steps: '3000000000'
  }
})
```

### datumBuilder

Xây dựng PlutusData cho datum:

```typescript
import { datumBuilder } from '@hydra-sdk/transaction'

// Integer datum
const intDatum = datumBuilder.int(42)

// Bytes datum
const bytesDatum = datumBuilder.bytes('deadbeef')

// Constructor datum
const constrDatum = datumBuilder.constr(0, [
  datumBuilder.int(42),
  datumBuilder.bytes('hello')
])

// List datum
const listDatum = datumBuilder.list([
  datumBuilder.int(1),
  datumBuilder.int(2),
  datumBuilder.int(3)
])

// Map datum
const mapDatum = datumBuilder.map([
  [datumBuilder.bytes('key1'), datumBuilder.int(100)],
  [datumBuilder.bytes('key2'), datumBuilder.int(200)]
])
```

## Best Practices

1. **UTxO Selection**: Sử dụng `selectUtxosFrom()` với strategy phù hợp cho coin selection tự động
2. **Protocol Parameters**: Luôn cung cấp protocol parameters mới nhất cho fee calculation chính xác
3. **Collateral**: Đặt collateral phù hợp (5-10 ADA) cho Plutus script transactions
4. **Execution Units**: Ước tính execution units cẩn thận để tránh script failures
5. **Datum Format**: Sử dụng inline datums khi có thể để giảm transaction size
6. **Metadata**: Tuân thủ CIP standards khi thêm metadata (CIP-25 cho NFTs, CIP-20 cho messages)
7. **Testing**: Test transactions trên testnet trước khi deploy lên mainnet
8. **Error Handling**: Luôn xử lý errors và validate transaction trước khi submit
9. **Fee Estimation**: Sử dụng `calculateFee()` để ước tính fees chính xác
10. **Change Address**: Luôn đặt change address để nhận ADA dư

## Common Pitfalls

### Insufficient Min UTxO

```typescript
// ❌ Sai - Output quá nhỏ
txBuilder.addOutput({
  address: 'addr_test1...',
  amount: [{ unit: 'lovelace', quantity: '1000000' }] // Có thể nhỏ hơn min UTxO
})

// ✅ Đúng - Tính toán min UTxO cho assets
const minAda = txBuilder.minAdaForAssets([
  { unit: 'lovelace', quantity: '0' },
  { unit: `${policyId}.${assetName}`, quantity: '100' }
])

txBuilder.addOutput({
  address: 'addr_test1...',
  amount: [
    { unit: 'lovelace', quantity: minAda.to_str() },
    { unit: `${policyId}.${assetName}`, quantity: '100' }
  ]
})
```

### Missing Collateral for Scripts

```typescript
// ❌ Sai - Không có collateral cho Plutus script
txBuilder.txIn(scriptUtxo.input.txHash, scriptUtxo.input.outputIndex)
  .txInScript(scriptCbor)
  .complete() // Sẽ fail!

// ✅ Đúng - Thêm collateral
txBuilder.txInCollateral(collateralTxHash, 0, collateralAmount, address)
  .txIn(scriptUtxo.input.txHash, scriptUtxo.input.outputIndex)
  .txInScript(scriptCbor)
  .complete()
```

### Incorrect Execution Units

```typescript
// ❌ Sai - Execution units quá thấp
const redeemer = CardanoWASM.Redeemer.new(
  CardanoWASM.RedeemerTag.new_spend(),
  CardanoWASM.BigNum.from_str('0'),
  data,
  CardanoWASM.ExUnits.new(
    CardanoWASM.BigNum.from_str('100'),      // Quá thấp!
    CardanoWASM.BigNum.from_str('1000')      // Quá thấp!
  )
)

// ✅ Đúng - Execution units đủ lớn
const redeemer = CardanoWASM.Redeemer.new(
  CardanoWASM.RedeemerTag.new_spend(),
  CardanoWASM.BigNum.from_str('0'),
  data,
  CardanoWASM.ExUnits.new(
    CardanoWASM.BigNum.from_str('7000000'),      // Đủ memory
    CardanoWASM.BigNum.from_str('3000000000')    // Đủ steps
  )
)
```
