# Khởi Động Nhanh

Hướng dẫn này sẽ dẫn bạn qua việc tạo ứng dụng ví Cardano đầu tiên bằng Hydra SDK. Chỉ trong vài phút, bạn sẽ có một ví hoạt động có thể tạo account, xây dựng transaction và kết nối với Hydra Layer 2.

## Bước 1: Cài Đặt

Cài đặt các package thiết yếu:

```bash
npm install @hydra-sdk/cardano-wasm @hydra-sdk/core @hydra-sdk/bridge @hydra-sdk/transaction
```

## Bước 2: Tạo Ví Đầu Tiên Của Bạn

Tạo một instance ví mới với core package:

```typescript
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

// Tạo mnemonic phrase mới
const mnemonic = AppWallet.brew()
console.log('Mnemonic được tạo:', mnemonic.join(' '))

// Tạo instance ví
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD, // Sử dụng PREPROD để test
  key: {
    type: 'mnemonic',
    words: mnemonic
  }
})

// Lấy account đầu tiên
const account = wallet.getAccount(0, 0)
console.log('Địa chỉ ví:', account.baseAddressBech32)
```

### Khôi Phục Ví Hiện Có

Để khôi phục ví từ mnemonic có sẵn:

```typescript
const existingMnemonic = 'mnemonic phrase hiện có của bạn ở đây'.split(' ')

const restoredWallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: {
    type: 'mnemonic',
    words: existingMnemonic
  }
})
```

## Bước 3: Truy vấn UTxOs và xây dựng giao dịch

Đầu tiên, truy vấn UTxOs từ địa chỉ ví của bạn, sau đó sử dụng transaction builder:

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { ProviderUtils } from '@hydra-sdk/core'

// Khởi tạo provider (Blockfrost hoặc Ogmios)
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

// Thiết lập provider cho wallet
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: {
    type: 'mnemonic',
    words: mnemonic
  },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// Lấy địa chỉ ví
const account = wallet.getAccount(0, 0)
const walletAddress = account.baseAddressBech32

// Truy vấn UTxOs từ ví
const utxos = await wallet.queryUTxOs(walletAddress)
console.log('UTxOs có sẵn:', utxos.length)

// Xây dựng một transaction chuyển ADA đơn giản
const recipientAddress = 'addr_test1...' // Địa chỉ người nhận
const amountToSend = '1000000' // 1 ADA tính bằng lovelace

try {
  // Khởi tạo transaction builder
  const txBuilder = new TxBuilder()
  
  const tx = await txBuilder
    .setInputs(utxos) // Sử dụng UTxOs đã truy vấn làm inputs
    .addOutput({
      address: recipientAddress,
      amount: [{ unit: 'lovelace', quantity: amountToSend }]
    })
    .changeAddress(walletAddress) // Tiền thừa trả về người gửi
    .complete()

  console.log('Transaction đã được xây dựng:', tx.to_hex())

  // Ký transaction
  const signedTx = await wallet.signTx(tx.to_hex())
  console.log('Transaction đã được ký')

  // Gửi transaction
  const txHash = await wallet.submitTx(signedTx)
  console.log('Transaction đã được gửi! Hash:', txHash)

} catch (error) {
  console.error('Transaction thất bại:', error)
}
```

### Ví dụ transaction nâng cao

Xây dựng transaction với nhiều outputs và native tokens:

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'

const txBuilder = new TxBuilder()

// Truy vấn UTxOs
const utxos = await wallet.queryUTxOs(walletAddress)

const tx = await txBuilder
  .setInputs(utxos)
  // Gửi ADA cho người nhận thứ nhất
  .addOutput({
    address: 'addr_test1qr...',
    amount: [{ unit: 'lovelace', quantity: '2000000' }]
  })
  // Gửi ADA + Native Token cho người nhận thứ hai
  .addOutput({
    address: 'addr_test1qs...',
    amount: [
      { unit: 'lovelace', quantity: '1500000' },
      { unit: 'policyId.assetName', quantity: '100' }
    ]
  })
  .changeAddress(walletAddress)
  .complete()

const signedTx = await wallet.signTx(tx.to_hex())
const txHash = await wallet.submitTx(signedTx)
console.log('Transaction hash:', txHash)
```

## Bước 4: Kết Nối Với Hydra Layer 2

Tạo Hydra Bridge để kết nối với Hydra Head cho các transaction Layer 2 nhanh chóng:

```typescript
import { HydraBridge, HydraPayload } from '@hydra-sdk/bridge'

// Tạo instance Hydra Bridge
const bridge = new HydraBridge({
  url: 'ws://localhost:4001', // URL WebSocket Hydra Node của bạn
})

// Lắng nghe các event kết nối
bridge.events.on('onConnected', () => {
  console.log('Đã kết nối với Hydra Head!')
})

bridge.events.on('onMessage', (payload: HydraPayload) => {
    console.log('>>> / onMessage:', payload)
})

// Kết nối đến Hydra Node
await bridge.connect()
```

## Kết Nối Với Hydra Layer 2 Sử Dụng HexcoreConnector

Tạo Hydra Bridge để kết nối với Hydra Head sử dụng HexcoreConnector:

```typescript
import { HydraBridge, HexcoreConnector } from '@hydra-sdk/bridge'

const hexcoreConnector = new HexcoreConnector({
    socketIoUrl: 'wss://example.hexcore.io.vn/hydra',
    socketIoOptions: {
        auth: {
            token: 'your_auth_token'
        }
    }
})
// Tạo instance Hydra Bridge
const bridge = new HydraBridge({
  connector: hexcoreConnector
})

// Lắng nghe các event kết nối
bridge.events.on('onConnected', () => {
  console.log('Đã kết nối với Hydra Head!')
})

bridge.events.on('onMessage', (payload: HydraPayload) => {
    console.log('>>> / onMessage:', payload)
})

// Kết nối đến Hydra Node
await bridge.connect()
```
