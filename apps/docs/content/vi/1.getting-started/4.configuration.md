# Cấu Hình

Hydra SDK tận dụng WebAssembly (WASM) để thực hiện các thao tác Cardano hiệu suất cao. Hướng dẫn này bao gồm cách cấu hình build tool và môi trường của bạn để đạt hiệu suất tối ưu.

- **[Ví Dụ React + Vite](/vi/examples/full-react-app)** - Thiết lập ứng dụng React hoàn chỉnh
- **[Ví Dụ Vue.js + TypeScript](/vi/examples/full-vuejs-app)** - Thiết lập ứng dụng Vue.js hoàn chỉnh
- **[Repository Ví Dụ](https://github.com/Vtechcom/hydra-sdk-examples)** - Tất cả ví dụ trên GitHub

## Nuxt 3

Đối với các dự án Nuxt.js, cấu hình `nuxt.config.ts` của bạn:

```typescript
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineNuxtConfig({
	ssr: false, // Tắt SSR cho các ứng dụng ví

	vite: {
		plugins: [
			wasm(),
			topLevelAwait(),
			nodePolyfills({
				include: ['buffer'],
				globals: {
					Buffer: true,
					global: false,
					process: false
				}
			})
		],
		optimizeDeps: {
			exclude: ['@hydra-sdk/cardano-wasm']
		}
	}
})
```

## Vue.js với Vite

Cấu hình `vite.config.js` của bạn cho các dự án Vue:

💡 **Xem [ví dụ Vue.js hoàn chỉnh](/vi/examples/full-vuejs-app) để có thiết lập hoạt động đầy đủ.**

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

		vue(),

		exclude: ['@hydra-sdk/cardano-wasm']
```


## Cấu Hình Next.js

Cấu hình Next.js trong `next.config.js` của bạn:

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
	webpack: (config, { isServer }) => {
		if (!isServer) {
			config.experiments = {
				...config.experiments,
				asyncWebAssembly: true,
				topLevelAwait: true
			}

			config.resolve.fallback = {
				...config.resolve.fallback,
				crypto: false,
				stream: false,
				util: false,
				buffer: require.resolve('buffer')
			}
		}

		return config
	},

	// Tắt static optimization cho các trang ví
	experimental: {
		esmExternals: 'loose'
	}
}

module.exports = nextConfig
```

Đối với Next.js 13+ với app directory, cũng tạo một file `globals.d.ts`:

```typescript
declare global {
	var Buffer: typeof import('buffer').Buffer
}

export {}
```
