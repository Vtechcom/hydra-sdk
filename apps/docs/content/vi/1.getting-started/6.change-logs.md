# Nhật Ký Thay Đổi

## Phiên Bản 1.3.1 (Mới Nhất) - 18 Tháng 3, 2026

### 🐛 Bug Fixes — `@hydra-sdk/bridge`

- **Crash khi `headStatus` là `Idle`**: Khi head chưa được mở (`Idle`), message `Greetings` không có trường `snapshotUtxo`. Việc truy cập trường này gây ra lỗi `undefined` và làm hỏng quá trình khởi tạo cache. Handler hiện đã kiểm tra trường này trước khi gọi `updateSnapshot`.

### 🛠️ Trải Nghiệm Developer — `@hydra-sdk/bridge`

- **Verbose log màu với Chalk**: Toàn bộ `console.log/warn/error` trong `HydraBridge` được thay bằng ba helper (`log`, `warn`, `err`) sử dụng `chalk`:
  - Tag `[⚡ HydraBridge]` luôn in **cyan đậm**
  - Sự kiện thành công (kết nối, cache seed) dùng **xanh lá**
  - Cảnh báo (reconnect, snapshot sai thứ tự) dùng **vàng**
  - Lỗi và ngắt kết nối dùng **đỏ**
  - Giá trị ít quan trọng (txId, slot timestamp) dùng **xám**
- **Xóa debug dump**: Hai câu `console.log('>>> / bridge.ts:...')` còn sót lại đã được xóa.

### 📦 Package Được Cập Nhật

- `@hydra-sdk/bridge@1.3.1`

## Phiên Bản 1.3.0 - 16 Tháng 3, 2026

### 🚀 Tính Năng Mới — `@hydra-sdk/bridge`

- **Tương thích hydra-node v1.3.0**: Message `Greetings` được mở rộng với 4 trường tùy chọn mới: `currentSlot`, `chainSyncedStatus`, `env`, `networkInfo`
- **Slot-Zero Timestamp**: `HydraBridge.slotZeroTimestamp` — tự động tính từ `Greetings.currentSlot`, dùng cho việc chuyển đổi slot ↔ thời gian bên trong Hydra Head
- **`submitTx` callback API**: API kiểu Node.js error-first callback, bổ sung bên cạnh `submitTxSync`:
  ```typescript
  bridge.submitTx(tx, (error, result) => { ... }, { timeout: 30000 })
  ```
- **Sửa `/head` API**: Kiểu `HydraHeadInfo` được viết lại để khớp với cấu trúc response thực tế của hydra-node v1.3.0
- **Auto-reconnect**: Ba option mới trong `InitHydraBridgeOptions` — `autoReconnect`, `reconnectInterval` (mặc định 3000ms), `maxReconnectAttempts` (0 = không giới hạn)

### ⚡ Hiệu Năng — `@hydra-sdk/bridge`

- **Balance O(1)**: `balanceCache: Map<address, Map<assetUnit, bigint>>` — rebuild một lần mỗi snapshot, đọc O(1) không I/O
- **UTxO O(1)**: `addressUtxoIndex: Map<address, UTxOObject>` — `queryAddressUTxO()` và `addressesInHead()` không còn scan toàn bộ UTxO mỗi lần gọi
- **`getAddressBalance(address)`**: API mới cho phép đọc số dư tức thì. Trả về `null` khi cache chưa được khởi tạo (cold start)
- **Greetings seeds cache**: Không cần HTTP call khi kết nối lần đầu — `snapshotUtxo` từ message `Greetings` seed index trực tiếp
- **Sửa race condition HTTP fallback**: Response HTTP chậm không thể ghi đè dữ liệu WebSocket mới hơn

### ⚡ Hiệu Năng — `@hydra-sdk/core`

- **`convertUTxOObjectToUTxOWithOptions`**: Export mới nhận `{ maxDatumCacheSize?: number }` — datum cache được giới hạn kích thước (mặc định 1024) với LRU eviction
- **Tối ưu converter**: `reduce` → `for` loop trong `convertUTxOToUTxOObject`; `for...in` thay `Object.entries()` để tránh alloc array trung gian
- **Script benchmark**: `scripts/bench-converter.ts` — CLI đo throughput converter với tham số tùy chỉnh

### 🐛 Bug Fixes — `@hydra-sdk/bridge`

- **`submitTxSync` variable shadowing**: Biến `tx` bên trong che khuất `tx` tham số ngoài — luôn trả về transaction đầu tiên thay vì transaction đúng
- **`newTx` hardcoded description**: Ghi đè description của caller bằng `'Ledger Cddl Format'`; giờ truyền thẳng qua
- **URL builder default port**: `buildUrl` sinh ra `https://host:443/path` khi không có port; default port nay được lọc bỏ

### 🛠️ Tái Cấu Trúc Nội Bộ

- **Utility `awaitHydraMessage`** (`src/utils/await-hydra-message.ts`): Thay thế pattern cleanup thủ công lặp lại. `submitTxSync`, `decommit`, `initHydraHead` đều được refactor dùng utility này

### 📦 Package Được Cập Nhật

- `@hydra-sdk/core@1.3.0`
- `@hydra-sdk/bridge@1.3.0`

### Configuration Được Khuyến Nghị (v1.0.13+)
Để đạt hiệu suất tối ưu, chúng tôi khuyến khích cập nhật cấu hình Vite của bạn:

**Thiết Lập Được Khuyến Nghị:**
```javascript
nodePolyfills({
  include: ['buffer'],  // ✅ Chỉ include buffer polyfill
  globals: {
    Buffer: true,       // ✅ Cần thiết cho các thao tác mật mã
    global: false,      // ✅ Tắt để có hiệu suất tốt hơn
    process: false      // ✅ Tắt để có hiệu suất tốt hơn
  }
})
```

**Thiết Lập Legacy (vẫn được hỗ trợ):**
```javascript
nodePolyfills({
  globals: {
    Buffer: true,
    global: true,    // ⚠️ Không khuyến khích nhưng vẫn hoạt động
    process: true    // ⚠️ Không khuyến khích nhưng vẫn hoạt động
  }
})
```

- **v1.1.0**: Thay đổi lớn TimeUtils API - `resolveSlotNo()` deprecated, sử dụng `unixTimeToEnclosingSlot()` với `SLOT_CONFIG_NETWORK`

- **v1.1.0**: Serializer import - sử dụng namespace export `Serializer.serializeAssetUnit()` thay vì direct import
- **v1.0.14**: Thêm tính năng mint/burn token với cấu trúc DatumUtils và PolicyUtils mới
