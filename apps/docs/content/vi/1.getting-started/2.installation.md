# Cài Đặt

Hydra SDK được phát hành dưới dạng các package riêng biệt trên NPM, cho phép bạn chỉ cài đặt những gì cần thiết cho dự án của mình.

## Yêu Cầu Hệ Thống

Trước khi cài đặt SDK, hãy đảm bảo hệ thống của bạn đáp ứng các yêu cầu sau:

- **Node.js**: >= 18.20.0
- **npm**: >= 8.0.0 (hoặc **pnpm** >= 8.0.0, **yarn** >= 1.22.0)
- **TypeScript**: >= 5.0.0 (tùy chọn nhưng được khuyến nghị)

## Core Packages

### Cài Đặt Từng Package Riêng Lẻ

Chỉ cài đặt những package bạn cần:

```bash
# Chức năng ví cốt lõi | Binding Cardano WASM
npm install @hydra-sdk/cardano-wasm @hydra-sdk/core

# Tích hợp Hydra Layer 2  
npm install @hydra-sdk/bridge

# Tiện ích xây dựng transaction
npm install @hydra-sdk/transaction

```

### Cài Đặt Bundle Hoàn Chỉnh

Đối với hầu hết các dự án, hãy cài đặt các core package cùng nhau:

```bash
# Cài đặt tất cả các package thiết yếu
npm install @hydra-sdk/cardano-wasm @hydra-sdk/core @hydra-sdk/bridge @hydra-sdk/transaction
```
