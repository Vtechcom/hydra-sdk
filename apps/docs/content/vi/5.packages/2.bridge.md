# @hydra-sdk/bridge — Tổng quan

Tích hợp Hydra L2 hoàn chỉnh: kết nối WebSocket, xử lý sự kiện, lệnh (commands) quản lý vòng đời Head, và xử lý giao dịch — tương thích với hydra-node v1.3.0+.

## Tính năng chính

- **Tương thích hydra-node v1.3.0** — Các trường mở rộng của `Greetings`, API `/head`, `slotZeroTimestamp`
- **Đọc số dư & UTxO O(1)** — Bộ nhớ cache snapshot được tính toán trước; không cần I/O cho mỗi lần đọc số dư
- **API gửi giao dịch kép** — `submitTxSync` (Promise) và `submitTx` (callback error-first)
- **Tự động kết nối lại** — Khoảng thời gian và số lần thử tối đa có thể cấu hình; hủy an toàn khi `disconnect()`
- **Hỗ trợ 5 định dạng URL** — `ws://`, `wss://`, `http://`, `https://`, gateway với `?X-Api-Key=`

## Cài đặt

```bash
npm install @hydra-sdk/bridge
```

## Ví dụ ngắn

```ts
import { HydraBridge } from '@hydra-sdk/bridge'

const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	verbose: true,
	autoReconnect: true
})

bridge.events.on('onConnected', () => bridge.commands.init())
bridge.events.on('onMessage', payload => {
	if (payload.tag === 'HeadIsOpen') {
		// Đọc số dư O(1) từ bộ nhớ cache
		const balance = bridge.getAddressBalance('addr_test1...')
		console.log('ADA:', balance?.get('lovelace'))
	}
})
bridge.connect()
```
