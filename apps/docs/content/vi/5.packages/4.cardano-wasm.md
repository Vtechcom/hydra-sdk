# @hydra-sdk/cardano-wasm — Tổng quan

Cung cấp binding WASM toàn diện cho thao tác Cardano: Value/Address/Tx/Script, metadata, hashing, witness, v.v.

## Cài đặt

```bash
npm install @hydra-sdk/cardano-wasm
```

## Gợi ý

- Dùng `vite-plugin-wasm` và `vite-plugin-top-level-await` khi chạy trên trình duyệt
- Loại trừ `@hydra-sdk/cardano-wasm` khỏi optimizeDeps
