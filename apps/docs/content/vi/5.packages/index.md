# Packages

Chào mừng đến phần Packages của Hydra SDK. Tại đây là thông tin của từng package: cài đặt, cách dùng, và API.

## Tổng quan

Hydra SDK gồm 4 package chính:

1. [@hydra-sdk/core](/vi/api/core) - Chức năng ví cốt lõi
2. [@hydra-sdk/bridge](/vi/api/bridge) - Tích hợp Hydra Layer 2
3. [@hydra-sdk/transaction](/vi/api/transaction) - Tiện ích build giao dịch
4. [@hydra-sdk/cardano-wasm](/vi/api/cardano-wasm) - WASM bindings cho Cardano
