# @hydra-sdk/core — Tổng quan

Cung cấp chức năng ví Cardano: quản lý HD wallet, ký giao dịch, tích hợp mạng, util serialization, key utilities, và chuyển đổi UTxO hiệu suất cao.

## Có gì mới trong v1.3.0

- **`convertUTxOObjectToUTxOWithOptions`** — bộ nhớ cache giải mã datum có giới hạn (LRU, kích thước có thể cấu hình) cho việc xử lý snapshot lớn
- **Tối ưu hóa Converter** — vòng lặp `for` thay thế chuỗi `reduce`/`filter`; không cấp phát mảng trung gian
- **Script benchmark** — `scripts/bench-converter.ts` để đo thông lượng dưới tải

## Cài đặt

```bash
npm install @hydra-sdk/core
```

## Cấu hình mạng

```ts
enum NETWORK_ID {
	TESTNET = 0,
	MAINNET = 1,
	PREPROD = 0
}

const wallet = new AppWallet({
	networkId: NETWORK_ID.MAINNET,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
```

## Ví dụ nhanh

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

const wallet = new AppWallet({
	networkId: NETWORK_ID.PREPROD,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
const account = wallet.getAccount(0, 0)
console.log('Base:', account.baseAddressBech32)
```
