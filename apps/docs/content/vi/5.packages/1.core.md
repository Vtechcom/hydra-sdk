# @hydra-sdk/core — Tổng quan

Cung cấp chức năng ví Cardano: quản lý HD wallet, ký giao dịch, tích hợp mạng, util serialization, key utilities, và chuyển đổi UTxO hiệu suất cao.

## Có gì mới trong v1.4.0

- **Namespace `RedeemerUtils` (mới)** — `mkRedeemer`, `mkSpendRedeemer`, `mkMintRedeemer`, `mkUnitRedeemer`, `mkExUnits`, `mkRedeemerTag` và `DEFAULT_EX_UNITS` để xây dựng redeemer Plutus trực tiếp từ `PlutusData`
- **Các encoder `DatumUtils` mới** — `mkBool`, `mkOption`, `mkBytesList`, `mkIntList`, `mkOutputRef`, `mkAddress`, `parseAddress` (cùng với `mkList`, đã thêm ở v1.3.2)
- **Tổ chức lại validation/address** — `ValidationUtils.isValidTxOutput` mới; `AddressUtils` giờ sở hữu `isValidAddress` và `getPubkeyHashFromAddress`. Namespace `ValidatorUtils` cũ đã **deprecated** (chỉ giữ lại như một re-export để tương thích ngược)
- **`Deserializer.deserializeAmountsFromTx(cborHex)`** — trả về tất cả các khoản output trên một giao dịch, gộp theo unit
- **Protocol v11 parameters** — `DEFAULT_PROTOCOL_PARAMETERS` được cập nhật (`minPoolCost = 170000000`)
- **Sửa memory-leak của Resolver** — `resolveTxHash` giờ giải phóng `FixedTransaction` bên dưới

## Cài đặt

```bash
npm install @hydra-sdk/core
```

## Cấu hình mạng

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

// NETWORK_ID is a Record<Network, number> — NOT an enum.
// Keys are 'MAINNET' | 'PREPROD' | 'PREVIEW' (there is no TESTNET):
//   NETWORK_ID = { MAINNET: 1, PREPROD: 0, PREVIEW: 0 }

const wallet = new AppWallet({
	networkId: NETWORK_ID.MAINNET, // 1
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
```

## Ví dụ nhanh

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

const wallet = new AppWallet({
	networkId: NETWORK_ID.PREPROD,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
const account = wallet.getAccount(0, 0)
console.log('Base:', account.baseAddressBech32)
```
