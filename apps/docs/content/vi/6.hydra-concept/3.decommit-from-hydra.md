# Decommit từ Hydra

Decommit là quá trình rút UTxOs từ một Hydra Head đang hoạt động về Cardano Layer 1. Điều này cho phép bạn thoát khỏi môi trường Layer 2 và làm cho assets của bạn khả dụng trên main chain.

## Hiểu Về Decommit

### Decommit là gì?

**Decommit** là operation loại bỏ UTxOs khỏi Hydra Head và trả chúng về Layer 1 trong khi head vẫn mở. Hãy nghĩ về nó như việc rút tiền từ làn đường nhanh về con đường chính.

```
┌─────────────────────────────────────────┐
│         Hydra Head (Layer 2)            │
│                                         │
│  UTxOs của bạn: [UTxO1, UTxO2, UTxO3]   │
│                                         │
└──────────────┬──────────────────────────┘
               │
               │ DECOMMIT
               │ (Loại bỏ khỏi Head, trả về L1)
               │
┌──────────────▼──────────────────────────┐
│         Cardano Layer 1                 │
│                                         │
│  Khả dụng: [UTxO1, UTxO2, UTxO3]        │
│  Trở lại trên main chain                │
│                                         │
└─────────────────────────────────────────┘
```
