# Decommit từ Hydra

Decommit là quá trình rút UTxOs từ một Hydra Head đang hoạt động về Cardano Layer 1. Điều này cho phép bạn thoát khỏi môi trường Layer 2 và làm cho assets của bạn khả dụng trên main chain.

## Hiểu Về Decommit

### Decommit là gì?

**Decommit** là operation loại bỏ UTxOs khỏi Hydra Head và trả chúng về Layer 1 trong khi head vẫn mở. Hãy nghĩ về nó như việc rút tiền từ làn đường nhanh về con đường chính.

```
┌─────────────────────────────────────────┐
│         Hydra Head (Layer 2)            │
│                                         │
│  UTxOs của bạn: [UTxO1, UTxO2, UTxO3]   │
│                                         │
└──────────────┬──────────────────────────┘
               │
               │ DECOMMIT
               │ (Loại bỏ khỏi Head, trả về L1)
               │
┌──────────────▼──────────────────────────┐
│         Cardano Layer 1                 │
│                                         │
│  Khả dụng: [UTxO1, UTxO2, UTxO3]        │
│  Trở lại trên main chain                │
│                                         │
└─────────────────────────────────────────┘
```


## Quy trình decommit

### Khi nào cần decommit?
Bạn nên decommit khi muốn rút tài sản khỏi Hydra Head mà không cần đóng Head hoàn toàn. Ví dụ: chuyển tài sản về ví Layer 1 hoặc rút một phần để sử dụng trên mainnet Cardano.

### Các bước thực hiện decommit
1. Kết nối tới Hydra node qua Hydra Bridge.
2. Truy vấn UTxO hiện có trong Hydra Head.
3. Xây dựng transaction decommit với UTxO bạn muốn rút.
4. Ký transaction bằng ví của bạn.
5. Gửi transaction decommit tới Hydra node.
6. Theo dõi trạng thái snapshot và xác nhận UTxO đã về Layer 1.

```ts
// nodejs-playground/src/hydra/decommit.ts
import { TxBuilder } from '@hydra-sdk/transaction'
import { HydraBridge } from '@hydra-sdk/bridge'
import { wallet, walletAddress } from './common'
import { Resolver } from '@hydra-sdk/core'

async function main() {
	const bridge = new HydraBridge({
		url: 'ws://localhost:4001'
	})
	const connected = await bridge.connect()
	if (!connected) {
		throw new Error('Failed to connect to Hydra node')
	}
	console.log('>>> Connected to Hydra node')

	const utxoObj = await bridge.querySnapshotUtxo()

	const addrUtxos = await bridge.queryAddressUTxO(walletAddress)
	const txBuilder = new TxBuilder({
		isHydra: true,
		params: {
			minFeeA: 0,
			minFeeB: 0
		}
	})
	const tx = await txBuilder
		.setInputs([
			addrUtxos[0] // utxo to decommit
		])
		.addOutput({
			address: walletAddress,
			amount: [{ unit: 'lovelace', quantity: String(2_000_000) }]
		})
		.changeAddress(walletAddress)
		.complete()

	const signedCbor = await wallet.signTx(tx.to_hex())
	const txId = Resolver.resolveTxHash(signedCbor)

	const rs = await bridge.decommit({
		cborHex: signedCbor,
		txId,
		timeout: 30000
	})
	console.log('>>> Submit tx result:', rs)
}
main()
```

### Lưu ý & best practices
- Chỉ decommit khi thực sự cần thiết để tránh phí Layer 1 không cần thiết.
- Kiểm tra kỹ UTxO trước khi decommit để tránh mất tài sản do nhầm lẫn.
- Theo dõi trạng thái snapshot sau khi decommit để đảm bảo UTxO đã về Layer 1.
- Nếu Head đóng, toàn bộ UTxO sẽ được trả về Layer 1 tự động (không cần decommit thủ công).
