# Cardano-CLIからの統合

Cardano-CLIで生成されたキーをHydra SDKで使用する方法を学びます。`CardanoCliWallet`クラスを使用すると、既存のCLIキーをNode.jsアプリケーションで使用して、プログラムによるトランザクション署名やブロックチェーンの相互作用を行うことができます。

**参照**: [Cardano-CLI ドキュメント](https://developers.cardano.org/docs/get-started/cardano-cli/basic-operations/get-started)

## Cardano-CLIでのキー生成

Cardano-CLIを使用して支払いキーペアを生成します：

```bash
cardano-cli address key-gen \
  --verification-key-file payment.vkey \
  --signing-key-file payment.skey
```

これにより、2つのファイルが作成されます：

**`payment.vkey`** (検証キー):
```json
{
    "type": "PaymentVerificationKeyShelley_ed25519",
    "description": "Payment Verification Key",
    "cborHex": "5820832ba166c8ba8afda5b9d85dfe13dd8fffd460da79a2c3cf34e107216637985b"
}
```

**`payment.skey`** (署名キー):
```json
{
    "type": "PaymentSigningKeyShelley_ed25519",
    "description": "Payment Signing Key",
    "cborHex": "5820bd09ad4f98cd103e059ab62d17a6a7d920b16d9f0eed3eb6b77d3ca8f61dc117"
}
```

::alert{type="warning"}
⚠️ **セキュリティ警告**: 署名キー (`payment.skey`) を共有したり、バージョン管理にコミットしたりしないでください。
::

## キーの検証 (オプション)

アドレスを構築してキーを検証します：

```bash
cardano-cli address build \
  --payment-verification-key-file payment.vkey \
  --testnet-magic 1 \
  --out-file payment.addr
```

**出力** (`payment.addr`):
```
addr_test1vz5hhyn6ecl66a2ca3cwfnwu8ddnp24hakfq2k37rhk28ysk8g0wz
```

::alert{type="info"}
これは[CIP-19](https://cips.cardano.org/cips/cip19/)に従った**エンタープライズアドレス**（支払いのみ、ステークキーなし）です。
::

## Hydra SDKでの使用

### 基本設定

```ts
import { CardanoCliWallet, NETWORK_ID } from '@hydra-sdk/core';

// キーファイルからcborHex値を抽出
const skey = '5820bd09ad4f98cd103e059ab62d17a6a7d920b16d9f0eed3eb6b77d3ca8f61dc117';
const vkey = '5820832ba166c8ba8afda5b9d85dfe13dd8fffd460da79a2c3cf34e107216637985b';

// ウォレットの初期化
const wallet = new CardanoCliWallet({ 
    skey, 
    vkey, 
    networkId: NETWORK_ID.TESTNET 
});

// Bech32形式でアドレスを取得
const address = wallet.getAddressBech32();
console.log('Wallet Address:', address);
// 出力: addr_test1vz5hhyn6ecl66a2ca3cwfnwu8ddnp24hakfq2k37rhk28ysk8g0wz
```

### トランザクションの例

```ts
import { 
    CardanoCliWallet, 
    NETWORK_ID,
    TxBuilder,
    BlockfrostProvider
} from '@hydra-sdk/core';

// CLIキーでウォレットを初期化
const wallet = new CardanoCliWallet({ 
    skey: '5820bd09ad4f98cd103e059ab62d17a6a7d920b16d9f0eed3eb6b77d3ca8f61dc117',
    vkey: '5820832ba166c8ba8afda5b9d85dfe13dd8fffd460da79a2c3cf34e107216637985b',
    networkId: NETWORK_ID.TESTNET 
});

// プロバイダーの設定
const provider = new BlockfrostProvider({
    projectId: 'your-blockfrost-project-id',
    network: 'preprod'
});

// トランザクションの構築
const txBuilder = new TxBuilder(provider);
const unsignedTx = await txBuilder
    // ...
    .complete();

// トランザクションの署名
const signedTxCbor = await wallet.signTx(unsignedTx.to_hex());
console.log('Signed Transaction:', signedTxCbor);

```

## APIリファレンス

### コンストラクタ

```ts
new CardanoCliWallet(options: CardanoCliWalletConfig)
```

**オプション**:
- `skey` (必須): 署名キーのCBOR hex (形式: `5820...`)
- `vkey` (必須): 検証キーのCBOR hex (形式: `5820...`)
- `networkId` (オプション): `NETWORK_ID.MAINNET` (1) または `NETWORK_ID.TESTNET` (0)、デフォルトはMAINNET
- `fetcher` (オプション): UTxOをクエリするためのカスタムfetcher
- `submitter` (オプション): トランザクション送信のためのカスタムsubmitter

### メソッド

```ts
// Bech32形式でアドレスを取得
getAddressBech32(): string

// トランザクションに署名
signTx(unsignedTxHex: string, partialSign?: boolean): Promise<string>

// ネットワークIDを取得
getNetworkId(): number

// トランザクションを送信 (コンストラクタでsubmitterが必要)
submitTx(tx: string): Promise<string>

// UTxOをクエリ (コンストラクタでfetcherが必要)
queryUTxOs(address: string): Promise<UTxO[]>
```

### プロパティ

```ts
// 支払い署名キーを取得
paymentSKey: CardanoWASM.PrivateKey

// 支払い検証キーを取得
paymentVKey: CardanoWASM.PublicKey
```
