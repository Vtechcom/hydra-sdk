# 例

Hydra SDKドキュメントの例セクションへようこそ。ここでは、SDKを始めるのに役立つ実用的なコードサンプルとユースケースを見つけることができます。

## 概要

例はいくつかのカテゴリに分類されています：

1. **[ウォレット作成](/ja/examples/wallet-creation)** - Cardanoウォレットの作成と管理
2. **[Hydra統合](/ja/examples/hydra-integration)** - Hydra Layer 2への接続とHydra Headsの管理
3. **[トランザクション構築](/ja/examples/transaction-building)** - トランザクションの構築と送信
4. **[完全なアプリケーション](/ja/examples/full-application)** - UIを含む完全なアプリケーション
5. **[Reactアプリケーション](/ja/examples/full-react-app)** - Reactベースの Cardanoアプリケーション
6. **[Vue.jsアプリケーション](/ja/examples/full-vuejs-app)** - Vue.jsベースのCardanoアプリケーション
7. **[ユーティリティの例](/ja/examples/utilities-examples)** - ユーティリティ関数の実用的な例
8. **[トランザクション署名](/ja/examples/transaction-signing)** - 基本から高度なトランザクション署名パターン

## v1.1.0の新機能

- **[ユーティリティの例](/ja/examples/utilities-examples)** - 新しいユーティリティ関数の包括的な例
- **高度なパターン** - エラー処理、プロバイダーフォールバック、パフォーマンス最適化
- **実際のシナリオ** - NFTコレクション、マーケットプレイス、トークンスワップ、ベスティングスケジュール
