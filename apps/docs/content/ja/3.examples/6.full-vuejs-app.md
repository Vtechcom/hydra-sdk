# Vue 3 + TypeScript + Vite + Hydra SDK の例

この例では、TypeScriptとViteビルドツールを使用してHydra SDKをVue.jsアプリケーションに統合する方法を示します。

**🔗 [Hydra SDK Examples - Vue + TypeScript](https://github.com/Vtechcom/hydra-sdk-examples)**

```bash
git clone https://github.com/Vtechcom/hydra-sdk-examples.git
cd hydra-sdk-examples/vue-app
```

### オプション3: スクラッチからの作成

以下の手順に従って、Hydra SDKを使用した新しいVue 3 + TypeScript + Viteプロジェクトをスクラッチから作成します：

#### 1. 新しいVueプロジェクトの作成

```bash
npm create vue@latest my-vue-app
cd ./my-vue-app
```

プロンプトが表示されたら、以下を選択します：
- ✅ TypeScript
- ✅ Router (オプション)
- ❌ その他のオプション (必要に応じて)

#### 2. Hydra SDKパッケージのインストール

```bash
pnpm add @hydra-sdk/core @hydra-sdk/transaction @hydra-sdk/bridge
```

#### 3. 必要なViteプラグインのインストール (開発依存関係として)

```bash
pnpm add vite-plugin-wasm vite-plugin-top-level-await vite-plugin-node-polyfills -D
```

#### 4. Viteの設定

`vite.config.ts`ファイルを更新します：

```typescript
import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

// https://vite.dev/config/
export default defineConfig({
  plugins: [
    vue(),
    vueDevTools(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      },
    }),
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm'],
  },
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
})
```

#### 5. Hydra SDKコンポーネントの作成

`src/components/HydraSdkExample.vue`を作成します：

```vue
<script lang="ts" setup>
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'
import { ref } from 'vue'

const mnemonic = ref(AppWallet.brew())
const wallet = ref(
  new AppWallet({
    networkId: NETWORK_ID.PREPROD,
    key: {
      type: 'mnemonic',
      words: mnemonic.value,
    },
  }),
)
const account = ref(wallet.value.getAccount())

function generateNewWallet() {
  mnemonic.value = AppWallet.brew()
  wallet.value = new AppWallet({
    networkId: NETWORK_ID.PREPROD,
    key: {
      type: 'mnemonic',
      words: mnemonic.value,
    },
  })
  account.value = wallet.value.getAccount()
}
</script>

<template>
  <div class="hydra-sdk-example">
    <h2>Hydra SDK Example</h2>
    <button @click="generateNewWallet">Generate New Wallet</button>
    <h3>Mnemonic</h3>
    <p class="break-words">
      {{ mnemonic }}
    </p>
    <h3>Base Address (Bech32)</h3>
    <p class="base-address">
      {{ account.baseAddressBech32 }}
    </p>
  </div>
</template>

<style scoped>

```

#### 6. メインビューの更新

コンポーネントを使用するように`src/views/HomeView.vue`を更新します：

```vue

</script>

  <main>
    <HydraSdkExample />
  </main>

```

## 📦 依存関係

### Hydra SDK パッケージ

- **@hydra-sdk/core** - コア機能とユーティリティ
- **@hydra-sdk/transaction** - トランザクション構築と署名
- **@hydra-sdk/bridge** - ブロックチェーン相互作用のためのブリッジ

### Vue 依存関係

- **vue** - Vue.js 3 フレームワーク
- **vue-router** - ナビゲーション用Vue Router

### Vite プラグイン (開発依存関係)

- **@vitejs/plugin-vue** - Vite用Vue.jsサポート
- **vite-plugin-vue-devtools** - Vue DevTools統合
- **vite-plugin-wasm** - Hydra SDKのためのWebAssemblyサポート
- **vite-plugin-top-level-await** - トップレベルawaitサポート
- **vite-plugin-node-polyfills** - ブラウザ互換性のためのNode.jsポリフィル

## 🔧 設定の詳細

### なぜこれらのプラグインが必要なのか

1. **@vitejs/plugin-vue**: Vite用コアVue.jsサポート
2. **vite-plugin-vue-devtools**: Vue DevToolsによる開発体験の向上
3. **vite-plugin-wasm**: Hydra SDKは暗号化操作にWebAssemblyを使用します
4. **vite-plugin-top-level-await**: モジュールレベルでのasync/awaitを有効にします
5. **vite-plugin-node-polyfills**: ブラウザで`Buffer`などのNode.js APIを提供します

### 重要な設定オプション

```typescript
nodePolyfills({
  include: ['buffer'],  // bufferポリフィルのみを含める
  globals: {
    Buffer: true,       // 暗号化操作に必要
    global: false,      // グローバルポリフィルを明示的に無効化
    process: false      // プロセスポリフィルを明示的に無効化
  }
})
```

```typescript
optimizeDeps: {
  exclude: ['@hydra-sdk/cardano-wasm']  // WASMを最適化から除外
}
```

```typescript
resolve: {
  alias: {
    '@': fileURLToPath(new URL('./src', import.meta.url))  // インポート用パスエイリアス
  }
}
```

## 🐛 トラブルシューティング

### 一般的な問題

1. **WASM読み込みエラー**
   - `vite-plugin-wasm`がインストールされ設定されていることを確認してください
   - ブラウザのWebAssemblyサポートを確認してください

2. **Buffer/Processが定義されていない**
   - `vite-plugin-node-polyfills`の設定を確認してください
   - グローバルが適切に設定されていることを確認してください

3. **TypeScriptコンパイルエラー**
   - `pnpm type-check`を実行して型の問題を特定してください
   - すべてのHydra SDK型が適切にインポートされていることを確認してください
   - tsconfigファイルでTypeScript設定を確認してください

4. **モジュール解決エラー**
   - すべてのHydra SDKパッケージがインストールされていることを確認してください
   - Viteの設定が正しいことを確認してください
   - パスエイリアスが適切に設定されていることを確認してください

5. **ビルドエラー**
   - `@hydra-sdk/cardano-wasm`が最適化から除外されていることを確認してください
   - 必要なすべてのプラグインがdevDependenciesにあることを確認してください
   - TypeScriptコンパイルが通過することを確認してください
