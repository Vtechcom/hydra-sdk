# React + Vite + Hydra SDK の例

この例では、Viteビルドツールを使用してHydra SDKをReactアプリケーションに統合する方法を示します。

### オプション3: スクラッチからの作成

以下の手順に従って、Hydra SDKを使用した新しいReact + Viteプロジェクトをスクラッチから作成します：

#### 1. 新しいViteプロジェクトの作成

```bash
npm create vite@latest my-app -- --template react
cd ./my-app
```

#### 2. Hydra SDKパッケージのインストール

```bash
pnpm add @hydra-sdk/core @hydra-sdk/transaction @hydra-sdk/bridge
```

#### 3. 必要なViteプラグインのインストール (開発依存関係として)

```bash
pnpm add vite-plugin-wasm vite-plugin-top-level-await vite-plugin-node-polyfills -D
```

#### 4. Viteの設定

`vite.config.js`ファイルを更新します：

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

// https://vite.dev/config/
export default defineConfig({
  plugins: [
    react(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      }
    })
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm']
  }
})
```

#### 5. Reactコンポーネントの更新

`src/App.jsx`の内容を以下に置き換えます：

```jsx
import { useState } from 'react'
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'
import './App.css'

function App() {
  // 新しいニーモニックフレーズを生成
  const [mnemonic, setMnemonic] = useState(AppWallet.brew())
  const [account, setAccount] = useState(null)

  const generateNewWallet = () => {
    const newMnemonic = AppWallet.brew()
    setMnemonic(newMnemonic)
    
    // ウォレットインスタンスの作成
    const wallet = new AppWallet({
      networkId: NETWORK_ID.PREPROD, // テストにはPREPRODを使用
      key: {
        type: 'mnemonic',
        words: newMnemonic
      }
    })
    setAccount(wallet.getAccount())
  }

  return (
    <div className="App">
      <h1>React + Vite + Hydra SDK</h1>
      <div className="card">
        <button onClick={generateNewWallet}>
          Generate New Wallet
        </button>
        <div className="wallet-info">
          <h3>Wallet Address:</h3>
          <p className="address">
            {account ? account.baseAddressBech32 : 'Click generate to create new account'}
          </p>
          <h3>Mnemonic Phrase:</h3>
          <p className="mnemonic">
            {account ? mnemonic.join(' ') : 'Click generate to generate mnemonic'}
          </p>
        </div>
      </div>
    </div>
  )
}

export default App
```

#### 6. アプリケーションの実行

```bash
pnpm dev
```

## 📦 依存関係

### Hydra SDK パッケージ

- **@hydra-sdk/core** - コア機能とユーティリティ
- **@hydra-sdk/transaction** - トランザクション構築と署名
- **@hydra-sdk/bridge** - ブロックチェーン相互作用のためのブリッジ

### Vite プラグイン (開発依存関係)

- **vite-plugin-wasm** - Hydra SDKのためのWebAssemblyサポート
- **vite-plugin-top-level-await** - トップレベルawaitサポート
- **vite-plugin-node-polyfills** - ブラウザ互換性のためのNode.jsポリフィル

## 🔧 設定の詳細

### なぜこれらのプラグインが必要なのか

1. **vite-plugin-wasm**: Hydra SDKは暗号化操作にWebAssemblyを使用します
2. **vite-plugin-top-level-await**: モジュールレベルでのasync/awaitを有効にします
3. **vite-plugin-node-polyfills**: ブラウザで`Buffer`などのNode.js APIを提供します

### 重要な設定オプション

```javascript
nodePolyfills({
  include: ['buffer'],  // bufferポリフィルのみを含める
  globals: {
    Buffer: true,       // 暗号化操作に必要
    global: false,      // グローバルポリフィルを明示的に無効化
    process: false      // プロセスポリフィルを明示的に無効化
  }
})
```

```javascript
optimizeDeps: {
  exclude: ['@hydra-sdk/cardano-wasm']  // WASMを最適化から除外
}
```

## 🐛 トラブルシューティング

### 一般的な問題

1. **WASM読み込みエラー**
   - `vite-plugin-wasm`がインストールされ設定されていることを確認してください
   - ブラウザのWebAssemblyサポートを確認してください

2. **Buffer/Processが定義されていない**
   - `vite-plugin-node-polyfills`の設定を確認してください
   - グローバルが適切に設定されていることを確認してください

3. **モジュール解決エラー**
   - すべてのHydra SDKパッケージがインストールされていることを確認してください
   - Viteの設定が正しいことを確認してください

4. **ビルドエラー**
   - `@hydra-sdk/cardano-wasm`が最適化から除外されていることを確認してください
   - 必要なすべてのプラグインがdevDependenciesにあることを確認してください
