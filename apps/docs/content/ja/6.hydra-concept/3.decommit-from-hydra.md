# Decommit from Hydra

`Decommit` は、Hydra Head 内の UTxO を Cardano Layer 1 に戻すプロセスです。Head を閉じずに一部資産だけをメインチェーンに戻したいときに使います。

## Decommit のイメージ

```text
┌─────────────────────────────────────────┐
│         Hydra Head (Layer 2)            │
│                                         │
│  Your UTxOs: [UTxO1, UTxO2, UTxO3]      │
│                                         │
└──────────────┬──────────────────────────┘
               │
               │ DECOMMIT
               │ (Remove from Head, return to L1)
               │
┌──────────────▼──────────────────────────┐
│         Cardano Layer 1                 │
│                                         │
│  Available: [UTxO1, UTxO2, UTxO3]       │
│  Back on main chain                     │
│                                         │
└─────────────────────────────────────────┘
```

## Decommit の流れ

1. Hydra node に `HydraBridge` で接続
2. Head の snapshot UTxO を取得
3. Decommit 対象の UTxO を選択
4. `TxBuilder` で decommit トランザクションを構築
5. ウォレットで署名
6. Hydra node 経由で decommit を送信
7. WebSocket メッセージを監視し、`DecommitApproved` / `DecommitFinalized` を確認

## Node.js 例

`nodejs-playground/src/hydra/decommit.ts` に基づく実装例です。

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { HydraBridge } from '@hydra-sdk/bridge'
import { wallet, walletAddress } from './common'
import { Resolver } from '@hydra-sdk/core'

async function main() {
  const bridge = new HydraBridge({
    url: 'ws://localhost:4001'
  })
  const connected = await bridge.connect()
  if (!connected) {
    throw new Error('Failed to connect to Hydra node')
  }
  console.log('>>> Connected to Hydra node')

  const utxoObj = await bridge.querySnapshotUtxo()
  console.log('>>> Snapshot UTxO:', utxoObj)

  const addrUtxos = await bridge.queryAddressUTxO(walletAddress)
  const txBuilder = new TxBuilder({
    isHydra: true,
    params: {
      minFeeA: 0,
      minFeeB: 0
    }
  })

  const tx = await txBuilder
    .setInputs([
      addrUtxos[0] // decommit 対象の UTxO
    ])
    .addOutput({
      address: walletAddress,
      amount: [{ unit: 'lovelace', quantity: String(2_000_000) }]
    })
    .changeAddress(walletAddress)
    .complete()

  const signedCbor = await wallet.signTx(tx.to_hex())
  const txId = Resolver.resolveTxHash(signedCbor)

  const rs = await bridge.decommit({
    cborHex: signedCbor,
    txId,
    timeout: 30000
  })
  console.log('>>> Submit tx result:', rs)
}

main()
```

### 実行コマンド

```bash
npx tsx src/hydra/decommit.ts
```

実行結果の例:

```text
>>> Connected to Hydra node
>>> Snapshot UTxO: { ... }
>>> Submit tx result: {
  decommitTxId: '7318b9...ffc49e4',
  headId: '7489fdc4...',
  tag: 'DecommitApproved',
  ...
}
```

Hydra Head WebSocket 上には、`DecommitFinalized` メッセージも流れます。

## ベストプラクティス

- 不要な L1 手数料を避けるため、必要なときだけ decommit を行う
- Decommit 対象の UTxO 内容（asset / amount）を事前にしっかり確認
- Decommit 実行後、L1 側で UTxO が戻っているかダブルチェック
- Head を close した場合は、すべての UTxO が自動的に L1 に戻るため、個別 decommit は不要
