# Commit to Hydra

`Commit` は、Cardano Layer 1 上の UTxO を Hydra Head にロックし、Layer 2 上で高速・低コストなトランザクションに利用できるようにするプロセスです。イメージとしては、L1 から「高速レーン」に資産を預け入れる操作です。

## Commit のイメージ

```text
┌─────────────────────────────────────────┐
│         Cardano Layer 1                 │
│                                         │
│  Your UTxOs: [UTxO1, UTxO2, UTxO3]      │
│                                         │
└──────────────┬──────────────────────────┘
               │
               │ COMMIT
               │ (locked on L1, available in head)
               │
┌──────────────▼──────────────────────────┐
│         Hydra Head (Layer 2)            │
│                                         │
│  Available: [UTxO1, UTxO2, UTxO3]       │
│  Ready for fast transactions            │
│                                         │
└─────────────────────────────────────────┘
```

### キーとなるポイント

- Head が `Initializing` 状態のときに commit フェーズが開く
- 参加者ごとに自分の UTxO を commit する
- Head が `Open` になった後は、新規 commit は行えない（incremental commit は別途）
- commit は常に Layer 1 の on-chain トランザクション

## 環境準備

### 要件

- Node.js 18+
- pnpm または npm
- 動作中の Hydra node
  - HTTP: `http://localhost:10005`
  - WebSocket: `ws://localhost:10005`
- Blockfrost API key（Preprod）
- Preprod 上のテスト ADA

## Empty commit で Head を開始する

Head を `Initializing` → `Open` に進めるために、空の commit（UTxO を指定しない commit）から始めることができます。

`src/empty-commit.ts`

```typescript
import { HydraApi, wallet } from './common'

async function main() {
  const commitTx = await HydraApi.commit({} as any)
  if (commitTx) {
    const signedTx = await wallet.signTx(commitTx.cborHex, true)
    console.log('Signed commit tx:', signedTx)
    const result = await HydraApi.submitCardanoTx({
      cborHex: signedTx,
      description: 'Empty commit from NodeJS Playground',
      type: 'Witnesses Tx ConwayEra'
    })
  }
}

main()
```

### 2. commit-with-utxo で指定 UTxO を commit

`src/commit-with-utxo.ts`

```typescript

import { HydraApi, wallet } from './common'

async function main() {

    'c2e3...ac2#0': {
      address: 'addr_test1...',
      datum: null,
      datumhash: null,
      inlineDatum: null,
      inlineDatumRaw: null,
      referenceScript: null,
      value: {
        lovelace: 1327480,
        e16c2dc8ae937e8d3790c7fd7168d7b994621ba14ca11415f39fed72: {
          '4d494e': 2000000000
        },
        fef67460342d081cb7881318b1f33b87626d1a1042b4c2acbbc0725d: {
          '7441424f': 1000000
        }
      }
    }
  }

  const result = await HydraApi.commit(utxoToCommit)

  if (result) {

    console.log('Signed commit tx:', signedTx)
    const submitResult = await HydraApi.submitCardanoTx({
      cborHex: signedTx,
      description: 'Commit specific UTxO from NodeJS Playground',
      type: 'Witnesses Tx ConwayEra'

  }
}

main()
```

## Incremental commit（Head Open 後の追加 deposit）

Head が `Open` 状態のときでも、`incremental commit` を使うと追加で UTxO を deposit できます。

バリエーション:

- UTxO だけを指定 → UTxO 全体を Head に deposit
- UTxO + 出力なし blueprint tx → 出力なしの blueprint にメタ情報を付与しつつ全額 deposit
- UTxO + 出力あり blueprint tx（change なし）→ 完全にバランスされた blueprint が必要
- UTxO + 出力あり blueprint tx（change address あり）→ hydra-node が自動でバランス調整（推奨）

### 推奨: partial-commit（change address あり）

`src/partial-commit.ts`（英語版と同一コード）では、`TxBuilder` で blueprint tx を作成し、その入力 UTxO 群を `HydraApi.partialDeposit` に渡すパターンを実装しています。

```bash
npx tsx ./src/partial-commit.ts
```

## Script UTxO を commit する

Plutus script でロックされた UTxO を Head に commit することも可能です（Head が `Initializing` または `Open`）。

> こちらは Hydra 公式ドキュメントの `commit-script-utxo` パターンに基づき、別途拡張実装可能です。
