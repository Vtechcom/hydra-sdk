# @hydra-sdk/cardano-wasm — 概要

Cardano操作のための包括的なWASMバインディングを提供：Value/Address/Tx/Script、metadata、hashing、witnessなど。

## インストール

```bash
npm install @hydra-sdk/cardano-wasm
```

## ヒント

- ブラウザで実行する場合は`vite-plugin-wasm`と`vite-plugin-top-level-await`を使用
- optimizeDepsから`@hydra-sdk/cardano-wasm`を除外

> 参照: [APIリファレンス](/ja/api/cardano-wasm/)
