# @hydra-sdk/bridge — 概要

完全なHydra L2統合を提供：接続、イベント、コマンド、トランザクション処理。

## インストール

```bash
npm install @hydra-sdk/bridge
```

## 主な機能

- **hydra-node v1.3.0 対応** — 最新プロトコルメッセージとスナップショット形式に完全対応
- **O(1) 残高 / UTxO 参照** — スナップショットごとにインメモリキャッシュを再構築し、`getAddressBalance()` でO(1)アクセス
- **二種類のサブミット API** — 非同期 Promise 型の `submitTxSync` と、Node.js エラーファースト型の `submitTx` コールバック
- **自動再接続** — `autoReconnect` / `reconnectInterval` / `maxReconnectAttempts` オプションで設定可能。`disconnect()` で安全に停止
- **5つのURL形式対応** — `ws://`, `wss://`, `http://`, `https://`, ホスト名のみ。ポート番号の自動補完あり

## 簡単な例

```ts
import { HydraBridge } from '@hydra-sdk/bridge'

const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	verbose: true,
	autoReconnect: true,
	reconnectInterval: 3000
})

bridge.events.on('onConnected', () => bridge.commands.init())

bridge.events.on('onMessage', payload => {
	if (payload.tag === 'HeadIsOpen') {
		// インメモリキャッシュから O(1) で残高取得
		const balance = bridge.getAddressBalance('addr_test1...')
		if (balance) {
			console.log('ADA:', balance.get('lovelace'))
		}
	}
})

bridge.connect()
```
