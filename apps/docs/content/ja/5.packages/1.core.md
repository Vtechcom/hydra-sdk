# @hydra-sdk/core — 概要

Cardanoウォレット機能を提供: HD wallet管理、トランザクション署名、ネットワーク統合、シリアライズutil、キーユーティリティ。

## インストール

```bash
npm install @hydra-sdk/core
```

## ネットワーク設定

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

// NETWORK_ID は Record<Network, number> であり、enum ではありません。
// キーは 'MAINNET' | 'PREPROD' | 'PREVIEW' です (TESTNET は存在しません):
//   NETWORK_ID = { MAINNET: 1, PREPROD: 0, PREVIEW: 0 }

const wallet = new AppWallet({
	networkId: NETWORK_ID.MAINNET, // 1
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
```

## 簡単な例

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

const wallet = new AppWallet({
	networkId: NETWORK_ID.PREPROD,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
const account = wallet.getAccount(0, 0)
console.log('Base:', account.baseAddressBech32)
```

## v1.4.0 の新機能

- **`RedeemerUtils` 名前空間 (新規)** — `PlutusData` から直接 Plutus redeemer を構築するための `mkRedeemer`、`mkSpendRedeemer`、`mkMintRedeemer`、`mkUnitRedeemer`、`mkExUnits`、`mkRedeemerTag`、`DEFAULT_EX_UNITS`
- **新しい `DatumUtils` エンコーダー** — `mkBool`、`mkOption`、`mkBytesList`、`mkIntList`、`mkOutputRef`、`mkAddress`、`parseAddress` (加えて v1.3.2 で追加された `mkList`)
- **Validation/address の再編成** — 新しい `ValidationUtils.isValidTxOutput`。`isValidAddress` と `getPubkeyHashFromAddress` は `AddressUtils` が保持するようになりました。旧 `ValidatorUtils` 名前空間は **非推奨** です (後方互換の re-export としてのみ保持)
- **`Deserializer.deserializeAmountsFromTx(cborHex)`** — トランザクション全体の出力金額を unit ごとに統合して返します
- **Protocol v11 パラメータ** — `DEFAULT_PROTOCOL_PARAMETERS` を更新 (`minPoolCost = 170000000`)
- **Resolver メモリリーク修正** — `resolveTxHash` が内部の `FixedTransaction` を解放するようになりました
