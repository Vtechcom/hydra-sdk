# @hydra-sdk/core — 概要

Cardanoウォレット機能を提供: HD wallet管理、トランザクション署名、ネットワーク統合、シリアライズutil、キーユーティリティ。

## インストール

```bash
npm install @hydra-sdk/core
```

## ネットワーク設定

```ts
enum NETWORK_ID {
	TESTNET = 0,
	MAINNET = 1,
	PREPROD = 0
}

const wallet = new AppWallet({
	networkId: NETWORK_ID.MAINNET,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
```

## 簡単な例

```ts
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

const wallet = new AppWallet({
	networkId: NETWORK_ID.PREPROD,
	key: { type: 'mnemonic', words: AppWallet.brew() }
})
const account = wallet.getAccount(0, 0)
console.log('Base:', account.baseAddressBech32)
```

## v1.3.0 の新機能

### `convertUTxOObjectToUTxOWithOptions` — 上限付き datum キャッシュ

```ts
import { Converter } from '@hydra-sdk/core'

// datum キャッシュの最大サイズを指定して変換
const utxos = Converter.convertUTxOObjectToUTxOWithOptions(snapshotUtxoObject, {
	maxDatumCacheSize: 1000  // LRU で古いエントリを自動削除
})
```

長期稼働するサーバープロセスでスナップショットを継続処理する場合、上限なしのキャッシュはメモリ増加の原因になります。`maxDatumCacheSize` を指定することで、LRU 方式で古いエントリを自動削除し、メモリ使用量を安定させます。

### Converter パフォーマンス改善

v1.3.0 では、`Converter` 内部の処理を `reduce` / `filter` から `for` ループへ書き換えました。大規模スナップショット (数千 UTxO) の変換速度が大幅に向上しています。

### ベンチマークスクリプト

`scripts/bench-converter.ts` を使用して、UTxO 変換のパフォーマンスを計測できます:

```bash
npx tsx scripts/bench-converter.ts
```
