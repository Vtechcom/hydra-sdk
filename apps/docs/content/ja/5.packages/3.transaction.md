# @hydra-sdk/transaction

トランザクションパッケージは、Plutusスクリプト、マルチアセットトランザクションなどのサポートを含む、Cardanoトランザクションの構築、管理、送信のための高度なツールを提供します。

## インストール

```bash
npm install @hydra-sdk/transaction
```

## 主なクラス

### TxBuilder

Cardanoトランザクションを構築および管理するためのメインクラスです。

#### コンストラクタ

```typescript
import TxBuilder from '@hydra-sdk/transaction'

const txBuilder = new TxBuilder({
  fetcher: customFetcher, // オプション: カスタムfetcher
  submitter: customSubmitter, // オプション: カスタムsubmitter
  isHydra: false, // オプション: Hydraモード
  params: {}, // オプション: プロトコルパラメータ
  verbose: true // オプション: 詳細モード
})
```

#### メソッド

**`txOut(address, amount)`**
トランザクションに出力を追加:

```typescript
txBuilder.txOut('addr_test...', [{ unit: 'lovelace', quantity: '1000000' }])
```

**`txIn(txHash, outputIndex, amount, address)`**
トランザクションに入力を追加:

```typescript
txBuilder.txIn('txHash...', 0, [{ unit: 'lovelace', quantity: '1000000' }], 'addr_test...')
```

**`txInScript(scriptCbor)`**
スクリプト入力を追加:

```typescript
txBuilder.txInScript('scriptCbor...')
```

**`txInDatumValue(datum)`**
入力にデータム値を追加:

```typescript
txBuilder.txInDatumValue(datum)
```

**`txInRedeemerValue(redeemer)`**
入力にリディーマー値を追加:

```typescript
txBuilder.txInRedeemerValue(redeemer)
```

**`txInCollateral(txHash, outputIndex, amount, address)`**
コラテラル入力を追加:

```typescript
txBuilder.txInCollateral('txHash...', 0, [{ unit: 'lovelace', quantity: '1000000' }], 'addr_test...')
```

**`mint(quantity, policyId, assetName)`**
新しいアセットをミント:

```typescript
txBuilder.mint('1000', 'policyId...', 'assetName...')
```

**`mintingScript(scriptCbor)`**
ミントスクリプトを追加:

```typescript
txBuilder.mintingScript('scriptCbor...')
```

**`mintRedeemerValue(redeemer)`**
ミント用のリディーマー値を追加:

```typescript
txBuilder.mintRedeemerValue(redeemer)
```

**`changeAddress(address)`**
お釣りアドレスを設定:

```typescript
txBuilder.changeAddress('addr_test...')
```

**`selectUtxosFrom(utxos)`**
トランザクション用のUTXOを選択:

```typescript
txBuilder.selectUtxosFrom(utxos)
```

**`requiredSignerHash(pubKeyHash)`**
必要な署名者を追加:

```typescript
txBuilder.requiredSignerHash('pubKeyHash...')
```

**`complete()`**
トランザクションを完了:

```typescript
const tx = await txBuilder.complete()
```

## 主なインターフェース

### TxBuilderOptions

`TxBuilder`を初期化するためのオプション:

```typescript
interface TxBuilderOptions {
  fetcher?: IFetcher
  submitter?: ISubmitter
  isHydra?: boolean
  params?: Partial<Protocol>
  verbose?: boolean
}
```

### MintAsset

アセットミント用インターフェース:

```typescript
interface MintAsset {
  assetName: string
  quantity: string
  policyId: string
  policyScript?: ScriptRef
  redeemer?: Redeemer
}
```

### Certificate

証明書用インターフェース:

```typescript
interface Certificate {
  type: CertificateType
  stakeKeyHash?: string
  poolKeyHash?: string
  rewardAddress?: string
  poolParams?: any
  epoch?: number
}
```

### Withdrawal

引き出し用インターフェース:

```typescript
interface Withdrawal {
  rewardAddress: string
  amount: string
}
```

### ValidityRange

トランザクション有効範囲用インターフェース:

```typescript
interface ValidityRange {
  invalidBefore?: number
  invalidAfter?: number
}
```
