# パッケージ
Hydra SDKドキュメントのパッケージセクションへようこそ。ここでは、インストール手順、使用例、APIリファレンスなど、各パッケージに関する詳細情報を見つけることができます。

## 概要

Hydra SDKは、4つの主要なパッケージで構成されています：

1. [**@hydra-sdk/core**](/api/core) - コアウォレット機能
2. [**@hydra-sdk/bridge**](/api/bridge) - Hydra Layer 2 統合
3. [**@hydra-sdk/transaction**](/api/transaction) - トランザクション構築ユーティリティ
4. [**@hydra-sdk/cardano-wasm**](/api/cardano-wasm) - 高度なブロックチェーン操作のためのCardano WASMバインディング
