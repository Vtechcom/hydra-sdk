## HydraBridge

Hydra Headsに接続して管理するメインクラス。

### **`HydraBridge.constructor(options: HydraBridgeOptions) → HydraBridge`**

新しいHydra Bridgeインスタンスを初期化します。

**パラメータ:**

- `options` (HydraBridgeOptions):
  - `url?`: WebSocket URL (例: 'ws://localhost:4001')
  - `connector?`: カスタムコネクタインスタンス
  - `verbose?`: 詳細ログモードを有効化
  - `noHistory?`: 完全なノード履歴の受信を無効化 (デフォルト: false)
  - `noSnapshotUtxo?`: スナップショットUTxOの可視性を無効化 (デフォルト: false)
  - `address?`: 特定のアドレスでトランザクション出力をフィルタリング

**例:**

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

// 直接WebSocket接続
const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	verbose: true
})

// 高度なオプション付き
const bridge = new HydraBridge({
	url: 'ws://localhost:4001',
	verbose: true,
	noHistory: true,
	noSnapshotUtxo: false,
	address: 'addr_test1...'
})

// Hydra Hub接続 (APIキー付き)
const bridge = new HydraBridge({
	url: 'wss://hydra-hub.example.com?X-Api-Key=your_api_key_here',
	verbose: true
})

// カスタムコネクタを使用
const bridge = new HydraBridge({
	connector: customConnector,
	verbose: true
})
```

**戻り値:** `HydraBridge`  
新しいHydra Bridgeインスタンス

## トランザクション操作

### **`HydraBridge.submitTxSync(transaction: Transaction, options?: SubmitOptions) → Promise<TxResult>`**

トランザクションを送信して確認を待ちます。

**パラメータ:**

- `transaction` (Transaction): 送信するトランザクション
- `options?` (SubmitOptions): 送信オプション
  - `timeout?`: タイムアウト (ミリ秒)

**例:**

```typescript
const result = await bridge.submitTxSync(
	{
		type: 'Witnessed Tx ConwayEra',
		description: 'Ledger Cddl Format',
		cborHex: signedTxCbor,
		txId: transactionId
	},
	{ timeout: 30000 }
)

console.log({
	txId: result.txId,
	isValid: result.isValid,
	isConfirmed: result.isConfirmed
})
```

**戻り値:** `Promise<TxResult>`  
トランザクション結果オブジェクト

## コネクタ

### **`WebsocketConnector`**

Hydra Nodeへの直接接続用の基本WebSocketコネクタ。

**コンストラクタパラメータ:**

- `websocketUrl` (string): Hydra NodeのWebSocket URL
- `noHistory?` (boolean): 完全なノード履歴の受信を無効化 (デフォルト: false)
- `noSnapshotUtxo?` (boolean): スナップショットUTxOの可視性を無効化 (デフォルト: false)
- `address?` (string): 特定のアドレスでトランザクション出力をフィルタリング

**コンストラクタ:**

```typescript
import { WebsocketConnector } from '@hydra-sdk/bridge'

// 基本接続
const connector = new WebsocketConnector({
	websocketUrl: 'ws://localhost:4001'
})

// 高度なオプション付き
const connector = new WebsocketConnector({
	websocketUrl: 'ws://localhost:4001',
	noHistory: true,
	noSnapshotUtxo: false,
	address: 'addr_test1...'
})

// Hydra Hub接続 (URL内APIキー付き)
const connector = new WebsocketConnector({
	websocketUrl: 'wss://hydra-hub.example.com?X-Api-Key=your_api_key_here'
})

// APIキーを他のオプションと組み合わせる
const connector = new WebsocketConnector({
	websocketUrl: 'wss://hydra-hub.example.com?X-Api-Key=your_api_key_here',
	noHistory: true,
	address: 'addr_test1...'
})

const bridge = new HydraBridge({
	connector: connector,
	verbose: true
})
```

## イベント処理

Bridgeは`events`プロパティを通じた包括的なイベント処理を提供します:

### **接続イベント**

```typescript
// 接続確立
bridge.events.on('onConnected', () => {
	console.log('Connected to Hydra Node')
})

// 接続喪失
bridge.events.on('onDisconnected', () => {
	console.log('Disconnected from Hydra Node')
})

// 接続エラー
bridge.events.on('onConnectError', error => {
	console.error('Connection error:', error)
})

// 一般的なエラー
bridge.events.on('onError', error => {
	console.error('Bridge error:', error)
})
```

---

### **Headライフサイクルイベント**

```typescript
bridge.events.on('onMessage', payload => {
	console.log('Message received:', payload.tag, payload.timestamp)

	switch (payload.tag) {
		case 'Greetings':
			console.log('Greeting from Head:', {
				headStatus: payload.headStatus,
				headId: payload.hydraHeadId
			})
			break

		case 'HeadIsInitializing':
			console.log('Head initializing with parties:', payload.parties)
			break

		case 'HeadIsOpen':
			console.log('Head is open and ready for transactions!')
			break

		case 'HeadIsClosed':
			console.log('Head closed, performing fanout...')
			break

		case 'HeadIsFinalized':
			console.log('Head lifecycle completed')
			break

		case 'TxValid':
			console.log('Transaction is valid:', payload.transaction)
			break

		case 'TxInvalid':
			console.log('Transaction is invalid:', {
				transaction: payload.transaction,
				error: payload.validationError
			})
			break

		case 'SnapshotConfirmed':
			console.log('Snapshot confirmed')
			break

		case 'Committed':
			console.log('UTxO committed:', payload.utxo)
			break

		case 'DecommitApproved':
			console.log('Decommit approved:', payload.decommitTxId)
			break

		case 'DecommitFinalized':
			console.log('Decommit finalized')
			break

		case 'CommandFailed':
			console.error('Command failed:', payload.clientInput)
			break
	}
})
```

## 完全な例

### 基本的なHead管理

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'

async function manageHydraHead() {
	const bridge = new HydraBridge({
		url: 'ws://localhost:4001',
		verbose: true
	})

	// 接続前にイベントハンドラをセットアップ
	bridge.events.on('onConnected', () => {
		console.log('Connected! Initializing Head...')
		bridge.commands.init()
	})

	bridge.events.on('onMessage', payload => {
		switch (payload.tag) {
			case 'HeadIsInitializing':
				console.log('Head initializing with', payload.parties.length, 'parties')
				break
			case 'HeadIsOpen':
				console.log('Head is open and ready for transactions!')
				break
			case 'TxValid':
				console.log('Transaction confirmed:', payload.transaction.txId)
				break
			case 'HeadIsClosed':
				console.log('Head closed, performing fanout...')
				bridge.commands.fanout()
				break
			case 'HeadIsFinalized':
				console.log('Head lifecycle completed')
				bridge.disconnect()
				break
		}
	})

	// 接続してプロセスを開始
	await bridge.connect()
}
```

### Hydra Head内でトランザクションを処理

```typescript
import { HydraBridge } from '@hydra-sdk/bridge'
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet } from '@hydra-sdk/core'

async function processHydraTransactions() {
	const bridge = new HydraBridge({
		url: 'ws://localhost:4001',
		verbose: true
	})

	const wallet = new AppWallet({
		networkId: 0,
		key: { type: 'mnemonic', words: AppWallet.brew() }
	})

	bridge.events.on('onConnected', async () => {
		// プロトコルパラメータを取得
		const protocolParams = await bridge.getProtocolParameters()

		// トランザクションビルダーを作成
		const txBuilder = new TxBuilder({
			isHydra: true,
			params: protocolParams
		})

		// アカウントとUTxOを取得
		const account = wallet.getAccount(0, 0)
		const addressUtxos = await bridge.queryAddressUTxO(account.baseAddressBech32)

		if (addressUtxos.length === 0) {
			console.log('No UTxOs found for address')
			return
		}

		// トランザクションをビルドして署名
		const tx = await txBuilder
			.setInputs(addressUtxos)
			.txOut(account.baseAddressBech32, [
				{ unit: 'lovelace', quantity: '1000000' }
			])
			.changeAddress(account.baseAddressBech32)
			.complete()

		const signedTx = await wallet.signTx(tx.to_hex(), false, 0, 0)

		// Hydra Headに送信
		const result = await bridge.submitTxSync(
			{
				type: 'Witnessed Tx ConwayEra',
				description: 'Ledger Cddl Format',
				cborHex: signedTx,
				txId: tx.id
			},
			{ timeout: 30000 }
		)

		console.log('Transaction successful:', result)
	})

	await bridge.connect()
}
```

## ベストプラクティス

1. **イベントセットアップ**: `connect()`を呼び出す前に、常にイベントハンドラをセットアップします
2. **エラーハンドリング**: 包括的なエラーハンドリングと再接続ロジックを実装します
3. **状態管理**: Headの状態を追跡して、有効な操作を確認します
4. **認証**:
   - Hydra Hubの場合: URLクエリパラメータでAPIキーを渡します (`?X-Api-Key=your_key`)
   - Hexcoreの場合: Socket.IO認証オプションでJWTトークンを使用します
5. **リソースクリーンアップ**: 完了したら常に`disconnect()`を呼び出します
6. **トランザクション検証**: 送信前にトランザクションを検証します
7. **タイムアウト設定**: 操作に適切なタイムアウトを設定します
8. **ログ記録**: 開発中のデバッグのため詳細モードを有効化します
