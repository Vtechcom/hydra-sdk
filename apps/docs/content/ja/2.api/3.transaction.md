## TxBuilder

Cardanoのすべての機能に包括的に対応した、Cardanoトランザクションの構築と管理用メインクラス。

### **`TxBuilder.constructor(options?: TxBuilderOptions) → TxBuilder`**

新しいトランザクションビルダーを初期化します。

**パラメータ:**
- `options?` (TxBuilderOptions): 設定オプション
  - `fetcher?`: カスタムフェッチャー
  - `submitter?`: カスタムサブミッター
  - `isHydra?`: Hydra Headのトランザクション作成を許可
  - `params?`: カスタムプロトコルパラメータ
  - `verbose?`: 詳細モードを有効化
  - `errorLogger?`: 厳格/テストモード — tx 構築で問題が発生した際に処理を継続せず例外をスローします (デフォルト: false、本番環境では非推奨)

**例:**
```typescript
import { TxBuilder } from '@hydra-sdk/transaction'

// 基本的なビルダーを作成
const txBuilder = new TxBuilder()

// カスタムプロトコルパラメータを使用
const txBuilder = new TxBuilder({
  params: {
    minFeeA: 44,
    minFeeB: 155381,
    maxTxSize: 16384
  }
})

// Hydraトランザクション用
const txBuilder = new TxBuilder({
  isHydra: true,
  params: protocolParams,
  verbose: true
})
```

**戻り値:** `TxBuilder`  
新しいTxBuilderインスタンス

### **`TxBuilder.setInputs(utxos: UTxO[], options?: { strategy: CoinSelectionStrategy }) → TxBuilder`**

ビルダーが使用できる UTxO を指定し、コイン選択戦略を選びます。ビルダーはトランザクションを完了する際に、これらの UTxO のうちどれを消費するかを選択します。これがコイン選択の公開エントリポイントです。

**パラメータ:**
- `utxos` (UTxO[]): 利用可能なUTxOのリスト
- `options?` (`{ strategy: CoinSelectionStrategy }`): コイン選択オプション。デフォルト: `{ strategy: 'LargestFirstMultiAsset' }`
  - `LargestFirst`: 最大のコインを最初に選択
  - `RandomImprove`: ランダム選択とその改善
  - `LargestFirstMultiAsset`: マルチアセット対応 (デフォルト)
  - `RandomImproveMultiAsset`: マルチアセット対応ランダム

**例:**
```typescript
const utxos = await wallet.queryUtxos()

// デフォルト戦略 (LargestFirstMultiAsset)
const tx1 = await txBuilder.setInputs(utxos).complete()

// 特定の戦略
const tx2 = await txBuilder.setInputs(utxos, { strategy: 'RandomImprove' }).complete()

// 特定の UTxO に選択を限定
const specificUtxos = utxos.filter(utxo =>
  utxo.output.amount.some(asset => asset.unit !== 'lovelace')
)
const tx3 = await txBuilder.setInputs(specificUtxos).complete()
```

**戻り値:** `TxBuilder`  
メソッドチェーン用ビルダーを返します

### **`TxBuilder.txIn(txHash: string, outputIndex: number, amount?: Asset[], address?: string) → TxBuilder`**

トランザクション入力を追加します。

**パラメータ:**
- `txHash` (string): トランザクションハッシュ
- `outputIndex` (number): 出力インデックス
- `amount?` (Asset[]): アセット金額 (オプション)
- `address?` (string): アドレス (オプション)

**例:**
```typescript
txBuilder.txIn(
  'a1b2c3d4e5f6...',
  0,
  [{ unit: 'lovelace', quantity: '2000000' }],
  'addr_test1...'
)
```

**戻り値:** `TxBuilder`

### **`TxBuilder.txOut(address: string, amount: Asset[]) → TxBuilder`**

トランザクション出力を追加します。

**パラメータ:**
- `address` (string): 受取人アドレス
- `amount` (Asset[]): アセットのリスト

**例:**
```typescript
// ADAのみ
txBuilder.txOut('addr_test1...', [
  { unit: 'lovelace', quantity: '2000000' }
])

// マルチアセット
txBuilder.txOut('addr_test1...', [
  { unit: 'lovelace', quantity: '2000000' },
  { unit: 'policyId.assetName', quantity: '100' }
])
```

**戻り値:** `TxBuilder`

### **`TxBuilder.calculateFee() → BigNum`**

最小手数料を計算します。

> **注:** 現在のリリースでは、このメソッドはスタブであり、常に `CardanoWASM.BigNum.zero()` を返します。手数料は `complete()` の内部で計算されます。実際の手数料見積もりに `calculateFee()` を使用しないでください。

**例:**
```typescript
const minFee = txBuilder.calculateFee()
console.log('Minimum fee:', minFee.to_str()) // 現在は常に '0'
```

**戻り値:** `BigNum`  
最小手数料 (現在は常に `0`)

### **`TxBuilder.minAda(output: TransactionOutput, protocolParams: Protocol) → BigNum` (静的)**

出力の最小ADAを計算します。

**パラメータ:**
- `output` (TransactionOutput): トランザクション出力
- `protocolParams` (Protocol): プロトコルパラメータ

**例:**
```typescript
const output = CardanoWASM.TransactionOutput.new(
  CardanoWASM.Address.from_bech32('addr_test1...'),
  CardanoWASM.Value.new(CardanoWASM.BigNum.from_str('1000000'))
)

const minAda = TxBuilder.minAda(output, protocolParams)
console.log('Minimum ADA:', minAda.to_str())
```

**戻り値:** `BigNum`  
最小ADA金額

## ユーティリティ関数

### datum の構築

`@hydra-sdk/transaction` パッケージは tx-builder と redeemer-builder ヘルパーのみをエクスポートします — `buildDatum` のエクスポートは **ありません**。datum 用の `PlutusData` を構築する必要がある場合は、`@hydra-sdk/core` の `DatumUtils` を使用してください。

**例:**
```typescript
import { DatumUtils } from '@hydra-sdk/core'

// Constr(0, [Int(42), Bytes('a1b2')])
const datum = DatumUtils.mkConstr(0, [
  DatumUtils.mkInt(42),
  DatumUtils.mkBytes('a1b2')
])
```

**戻り値:** `PlutusData`

---

### **`buildRedeemer(jsValue: Record<string, string>, options?) → Redeemer`**

Plutus スクリプト用のリディーマーを構築します。`jsValue` は **必須** です — 各値は `Constr(0, …)` リディーマーの `bytes` フィールドとしてエンコードされます。引数なしで呼び出すと例外をスローします。

**パラメータ:**
- `jsValue` (`Record<string, string>`): リディーマーのフィールドとしてエンコードする値
- `options?`: `{ tag?: 'SPEND' | 'MINT' | 'REWARD' | 'CERT' | 'VOTE' | 'VOTING_PROPOSAL'; index?: number | string; exUnits?: { mem: string; steps: string } }` (tag のデフォルトは `'SPEND'`、index のデフォルトは `0`)

**例:**
```typescript
import { buildRedeemer } from '@hydra-sdk/transaction'

const redeemer = buildRedeemer({ action: 'claim' }, { tag: 'SPEND', index: 0 })
```

> ほとんどの場合、`PlutusData` から直接リディーマーを構築する `emptyRedeemer(...)` (下記) または `@hydra-sdk/core` の `RedeemerUtils.mkRedeemer(...)` を使用することをおすすめします。

**戻り値:** `Redeemer`

---

### **`emptyRedeemer() → Redeemer`**

空のリディーマーを作成します。

**例:**
```typescript
import { emptyRedeemer } from '@hydra-sdk/transaction'

const redeemer = emptyRedeemer()
```

**戻り値:** `Redeemer`

---

### **`MetadataUtils.metadataObjToMetadatum(obj: any) → TransactionMetadatum`**

メタデータオブジェクトを `TransactionMetadatum` に変換します。このヘルパーは `@hydra-sdk/core` の `MetadataUtils` 名前空間にあります — `@hydra-sdk/transaction` からは **エクスポートされていません**。

**パラメータ:**
- `obj` (any): メタデータオブジェクト

**例:**
```typescript
import { MetadataUtils } from '@hydra-sdk/core'

const metadata = MetadataUtils.metadataObjToMetadatum({
  '1': 'Hello',
  '2': 12345
})
```

**戻り値:** `TransactionMetadatum`

## 型とインターフェース

### TxBuilderOptions

```typescript
interface TxBuilderOptions {
  fetcher?: IFetcher
  submitter?: ISubmitter
  isHydra?: boolean
  params?: Partial<Protocol>
  verbose?: boolean
  /**
   * 厳格/テストモード: tx 構築で問題 (例: コイン選択の失敗) が発生した際に
   * 処理を継続せず例外をスローします。デフォルト: false。本番環境向けではありません。
   */
  errorLogger?: boolean
}
```

### CoinSelectionStrategy

```typescript
type CoinSelectionStrategy =
  | 'LargestFirst'
  | 'RandomImprove'
  | 'LargestFirstMultiAsset'
  | 'RandomImproveMultiAsset'
```

> **注:** `TxBuilderOptions` と `CoinSelectionStrategy` は内部型であり、`@hydra-sdk/transaction` からは **再エクスポートされていません**。ここでは参照用に構造を示しています。コンストラクタや `setInputs` にはプレーンなオブジェクト/文字列リテラルを渡してください。

### Asset

```typescript
interface Asset {
  unit: string      // 'lovelace' または 'policyId.assetName'
  quantity: string  // 金額を文字列として
}
```

## 完全な例

### シンプルなADA送信

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { AppWallet } from '@hydra-sdk/core'

async function sendAda() {
  const wallet = new AppWallet({
    networkId: 0,
    key: { type: 'mnemonic', words: AppWallet.brew() }
  })

  const account = wallet.getAccount(0, 0)
  const utxos = await wallet.queryUtxos(account.baseAddressBech32)

  const tx = await new TxBuilder()
    .setInputs(utxos)
    .txOut('addr_test1qqr585tvlc7ylnqvz8pyqwauzrdu0mxag3m7q56grgmgu7sxu2hyfhlkwuxupa9d5085eunq2qywy7hvmvej456flknswgndm3', [
      { unit: 'lovelace', quantity: '2000000' }
    ])
    .changeAddress(account.baseAddressBech32)
    .complete()

  const signedTx = await wallet.signTx(tx.to_hex(), false, 0, 0)
  console.log('Signed transaction:', signedTx)
}
```

### Plutusスクリプト相互作用

```typescript
async function interactWithPlutusScript() {
  const scriptCbor = 'plutus_script_cbor'
  const datum = CardanoWASM.PlutusData.new_map(
    CardanoWASM.PlutusMap.new()
  )

  const tx = await new TxBuilder()
    .setInputs(utxos)
    .txIn(scriptUtxoHash, scriptUtxoIndex)
    .txInScript(scriptCbor)
    .txInDatumHash(datum)
    .txInEmptyRedeemer()
    .txInCollateral(collateralHash, 0, [{ unit: 'lovelace', quantity: '5000000' }], collateralAddress)
    .txOut(recipientAddress, [{ unit: 'lovelace', quantity: '10000000' }])
    .changeAddress(changeAddress)
    .complete()

  return tx
}
```
