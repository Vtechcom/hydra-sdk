## AppWallet

### **`AppWallet.brew(strength?: number) → string[]`**

新しいCardanoウォレットの新しいランダムニーモニックフレーズを生成します。

**パラメータ:**
- `strength?` (number): ニーモニック強度 (128 = 12単語, 160 = 15単語, 256 = 24単語)。デフォルト: 256 (24単語)

**例:**
```typescript
import { AppWallet } from '@hydra-sdk/core'

// 24単語のニーモニックを生成 (デフォルト)
const mnemonic24 = AppWallet.brew(256)

// 12単語のニーモニックを生成
const mnemonic12 = AppWallet.brew(128)

// 15単語のニーモニックを生成
const mnemonic15 = AppWallet.brew(160)

console.log('New mnemonic:', mnemonic24)
// => ['abandon', 'abandon', ..., 'zone']
```

**戻り値:** `string[]`  
ニーモニック単語の配列

### **`AppWallet.getAccount(accountIndex?: number, keyIndex?: number) → Account`**

導出されたキーとアドレスを含むアカウント情報を取得します。

**パラメータ:**
- `accountIndex?` (number): アカウントインデックス (BIP-44に従う)。デフォルト: 0
- `keyIndex?` (number): アドレスインデックス。デフォルト: 0

**例:**
```typescript
import { AppWallet, NETWORK_ID, ProviderUtils } from '@hydra-sdk/core'

const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: ['word1', 'word2', ...] },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// 最初のアカウント (アカウント 0、アドレス 0) を取得
const account = wallet.getAccount(0, 0)

console.log({
  // アドレス情報
  baseAddressBech32: account.baseAddressBech32,
  enterpriseAddressBech32: account.enterpriseAddressBech32,
  rewardAddressBech32: account.rewardAddressBech32,
  
  // キー情報
  paymentKey: account.paymentKey,
  stakeKey: account.stakeKey,
  
  // インデックス
  accountIndex: account.accountIndex,
  addressIndex: account.addressIndex
})

// デフォルト: アカウント 0、アドレス 0
const defaultAccount = wallet.getAccount()
```

**戻り値:** `Account`
- `baseAddressBech32`: ベースアドレス (支払い + ステーキング)
- `enterpriseAddressBech32`: エンタープライズアドレス (支払いのみ)
- `rewardAddressBech32`: リワードアドレス (ステーキングのみ)
- `paymentKey`: 支払いキー
- `stakeKey`: ステーキングキー
- `accountIndex`: アカウントインデックス
- `addressIndex`: アドレスインデックス

### **`AppWallet.signTx(txCbor: string, partialSign?: boolean, accountIndex?: number, keyIndex?: number) → Promise<string>`**

Cardanoトランザクションに署名します。完全署名またはパーシャル署名 (マルチシグ) に対応しています。

**パラメータ:**
- `txCbor` (string): CBOR hex形式のトランザクション
- `partialSign?` (boolean): trueの場合、パーシャル署名を実行します。デフォルト: false
- `accountIndex?` (number): アカウントインデックス。デフォルト: 0
- `keyIndex?` (number): アドレスインデックス。デフォルト: 0

**例:**
```typescript
// 完全署名
const signedTx = await wallet.signTx(unsignedTxCbor, false, 0, 0)

// パーシャル署名 (マルチシグ)
const partialSigned = await wallet.signTx(unsignedTxCbor, true, 0, 0)

console.log('Signed transaction:', signedTx)
```

**戻り値:** `Promise<string>`  
CBOR hex形式の署名トランザクション

---

### **`AppWallet.signTxs(txCbors: string[], partialSign?: boolean) → Promise<string[]>`**

**パラメータ:**

**例:**
```typescript
const signedTxs = await wallet.signTxs(

console.log('Signed transactions:', signedTxs)
```

**戻り値:** `Promise<string[]>`  
CBOR hex形式の署名トランザクション配列

### **`AppWallet.signData(address: string, payload: string, accountIndex?: number, keyIndex?: number) → Promise<{ signature: string; key: string }>`**

CIP-8 (Cardano改善提案) に従った任意のデータに署名します。

> **`AppWallet` では未実装です。** `AppWallet.signData()` を呼び出すと `[AppWallet] signData() is not implemented.` がスローされます。実際にデータへ署名できるのは `EmbeddedWallet.signData()` のみで、シグネチャは同じで `{ signature, key }` を返します。

**パラメータ:**
- `address` (string): Cardanoアドレス (bech32)
- `payload` (string): 署名するデータ
- `accountIndex?` (number): アカウントインデックス。デフォルト: 0
- `keyIndex?` (number): アドレスインデックス。デフォルト: 0

**例:**
```typescript
import { EmbeddedWallet } from '@hydra-sdk/core'

// AppWallet.signData() はスローされます — 代わりに EmbeddedWallet.signData() を使用してください
const signature = await embeddedWallet.signData(
  'addr_test1qz2fxv2umyhttkxyxp8x0...',
  'Hello World',
  0,
  0
)

console.log('Data signature:', signature)
// => { signature: '...', key: '...' }
```

**戻り値:** `Promise<{ signature: string; key: string }>`
- `signature`: hex形式の署名
- `key`: hex形式の公開キー

## プロバイダークラス

### **`BlockfrostProvider`**

ブロックチェーンデータをクエリするためのBlockfrostプロバイダー。

**コンストラクタ:**
```typescript
import { ProviderUtils } from '@hydra-sdk/core'

const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod' // または 'mainnet'
})

// fetcher と submitter にアクセス
const fetcher = blockfrostProvider.fetcher
const submitter = blockfrostProvider.submitter

// ウォレットと一緒に使用
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: mnemonic },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})
```

---

### **`OgmiosProvider`**

ブロックチェーンデータをクエリするためのOgmiosプロバイダー。

**コンストラクタ:**
```typescript
import { ProviderUtils } from '@hydra-sdk/core'

const ogmiosProvider = new ProviderUtils.OgmiosProvider({

// fetcher と submitter にアクセス
const fetcher = ogmiosProvider.fetcher

// ウォレットと一緒に使用
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,

```

---

### **`DemeterProvider`** <Badge type="tip" text="New in v1.3.2" />

[Demeter](https://demeter.run) の Blockfrost 互換ホスティングエンドポイント向けのプロバイダーです。`BlockfrostProvider` を継承しているため、同じ `fetcher`/`submitter` インターフェースを公開します。認証は `authToken` を通じてエンドポイントのサブドメインに埋め込まれます。

**コンストラクタ:**
```typescript
import { ProviderUtils } from '@hydra-sdk/core'

const demeterProvider = new ProviderUtils.DemeterProvider({
  authToken: 'blockfrost102lx3ckhzvkjjh7677g',
  network: 'preprod' // 'mainnet' | 'preprod' | 'preview'
})

// BlockfrostProvider と同じ fetcher / submitter インターフェース
const utxos = await demeterProvider.fetcher.fetchAddressUTxOs(address)

// ウォレットと一緒に使用
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: { type: 'mnemonic', words: mnemonic },
  fetcher: demeterProvider.fetcher,
  submitter: demeterProvider.submitter
})
```

エンドポイントは `https://{authToken}.cardano-{network}.blockfrost-m1.demeter.run/api/v{apiVersion ?? 0}` として構築されます。

### **`AddressUtils.isValidAddress(address: string | Uint8Array, type?: 'bech32' | 'hex' | 'bytes') → boolean`**

Cardanoアドレスが有効かどうかをチェックします。`type` のデフォルトは `'bech32'` です。

**パラメータ:**
- `address` (string | Uint8Array): 検証するアドレス
- `type?` ('bech32' | 'hex' | 'bytes'): 入力エンコーディング。デフォルト: 'bech32'

**例:**
```typescript
import { AddressUtils } from '@hydra-sdk/core'

const isValid = AddressUtils.isValidAddress('addr_test1qz2fxv2umyhttkxyxp8x0...')
console.log('Valid:', isValid) // => true または false
```

**戻り値:** `boolean`  
アドレスが有効な場合はtrue、そうでない場合はfalse

  plutusV3: [/* ...コストモデル整数... */]
