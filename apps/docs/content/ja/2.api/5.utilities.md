# @hydra-sdk/core – Utilities

> Hydra SDKは、Cardanoブロックチェーンデータ、WASM操作、一般的な開発タスクに作業するための包括的なユーティリティ関数コレクションを提供します。

## 概要

ユーティリティは複数のカテゴリに整理されています：

- **[Keys Utilities](#keys-utilities)** - 暗号キーの作成と管理
- **[Data Parsing](#data-parsing)** - データ形式間の変換
- **[Datum Utilities](#datum-utilities)** - Plutusデータ構造の作業
- **[Policy Utilities](#policy-utilities)** - ミントポリシーの管理
- **[Metadata Utilities](#metadata-utilities)** - トランザクションメタデータの変換
- **[Time Utilities](#time-utilities)** - スロットと時間の計算
- **[Provider Utilities](#provider-utilities)** - ブロックチェーンデータプロバイダーの抽象化
- **[Cardano WASM Utilities](#cardano-wasm-utilities)** - 低レベルブロックチェーン操作

---

すべてのユーティリティは、より良い整理のために名前空間付きモジュールとしてエクスポートされます：


## Keys Utilities :badge[1.1.5+]{variant="success" style="transform: translateY(-2px)"}

### **`KeysUtils.cardanoCliKeygen() → CardanoCLiKeyPair`**

Cardano CLIと互換性のあるed25519キーペアを生成します。

説明: Cardano CLI形式と互換性のある署名キーおよび検証キーを生成します。

**例:**

```typescript
import { KeysUtils } from '@hydra-sdk/core'

	skey: cardanoKeys.sk.cborHex, // PaymentSigningKeyShelley_ed25519
	vkey: cardanoKeys.vk.cborHex // PaymentVerificationKeyShelley_ed25519
})
```

**戻り値:** `CardanoCLiKeyPair`

```typescript
{
  sk: HydraCliSkey,
  vk: HydraCliVkey,
}
```

### **`KeysUtils.mnemonicToCliKey(mnemonic: string[], accountIndex?: number, keyIndex?: number)`**

**→ `CardanoCliKeyPair`** :badge[1.1.6+]{variant="success"}

BIP-39ニーモニックフレーズをCardano CLI互換のキーペアに変換します。

説明: BIP-44派生パス（m/1852'/1815'/account'/0/keyIndex）を使用してニーモニックフレーズから支払いキーを派生します。これにより、CardanoウォレットやCLIツールと互換性のあるキーを生成できます。

**パラメータ:**

- `mnemonic` (string[]): BIP-39ニーモニックワード（12または24ワード）
- `accountIndex` (number, optional): 派生パスのアカウントインデックス（デフォルト: 0）
- `keyIndex` (number, optional): 派生パスのキーインデックス（デフォルト: 0）

**例:**

```typescript
import { KeysUtils, AppWallet } from '@hydra-sdk/core'

// ランダムなニーモニックを生成
const mnemonic = AppWallet.brew()

// デフォルトのインデックスでCLIキーに変換
const keys = KeysUtils.mnemonicToCliKey(mnemonic)
console.log({
	skey: keys.sk.cborHex,
	vkey: keys.vk.cborHex
})

// 特定のアカウントインデックスを使用（複数アカウント用）
const account1Keys = KeysUtils.mnemonicToCliKey(mnemonic, 1)

// 特定のキーインデックスを使用（複数アドレス用）
const addressKeys = KeysUtils.mnemonicToCliKey(mnemonic, 0, 5)
```

**戻り値:** `CardanoCLiKeyPair`

```typescript
{
  sk: CardanoCLiSkey,  // PaymentSigningKeyShelley_ed25519
  vk: CardanoCLiVkey   // PaymentVerificationKeyShelley_ed25519
}
```

**重要な注意事項:**

- BIP-44派生パスを使用: `m/1852'/1815'/accountIndex'/0/keyIndex`
- 異なる`accountIndex`値は、同じニーモニックから異なるアカウントを作成します
- 異なる`keyIndex`値は、同じアカウントの異なる支払いアドレスを作成します
- キーは決定論的 - 同じニーモニック + インデックスは常に同じキーを生成します
- Cardano CLIおよびほとんどのCardanoウォレットと互換性があります

## Metadata Utilities

### **`MetadataUtils.metadataObjToMetadatum(metadata: any) → TransactionMetadatum`**

さまざまなデータ型をCardanoトランザクションメタデータに変換します。

**パラメータ:**

- `metadata` (any): 変換するデータ（string, number, bigint, Uint8Array, array, object, Map）

**例:**

```typescript
import { MetadataUtils } from '@hydra-sdk/core'

// 文字列を変換
const stringMetadata = MetadataUtils.metadataObjToMetadatum('Hello World')

// 数値を変換
const numberMetadata = MetadataUtils.metadataObjToMetadatum(42)

// bigintを変換
const bigintMetadata = MetadataUtils.metadataObjToMetadatum(9007199254740991n)

// バイトを変換
const bytesMetadata = MetadataUtils.metadataObjToMetadatum(
	new Uint8Array([1, 2, 3, 4])
)

// 配列を変換
const arrayMetadata = MetadataUtils.metadataObjToMetadatum([
	'item1',
	42,
	new Uint8Array([5, 6])
])

// オブジェクトをマップに変換
const objectMetadata = MetadataUtils.metadataObjToMetadatum({
	name: 'NFT Name',
	image: 'ipfs://...',
	attributes: ['trait1', 'trait2']
})

// Mapを変換
const mapMetadata = MetadataUtils.metadataObjToMetadatum(
	new Map([
		['key1', 'value1'],
		['key2', 42]
	])
)
```

**戻り値:** `TransactionMetadatum`
Cardano形式のメタデータ

**重要な注意事項:**

- 最大メタデータ `bytes` サイズ: **64 bytes**
- 最大メタデータ `text` サイズ: **64 characters**
- 配列とMapは再帰的に処理されます。メタデータ全体のサイズに注意してください

## Provider Utilities

### **`BlockfrostProvider.constructor(config: BlockfrostProviderConfig) → BlockfrostProvider`**

Cardanoブロックチェーンにクエリとトランザクション送信を行うためのBlockfrostプロバイダーを作成します。

説明: BlockfrostProviderは、UTxOの取得とトランザクション送信のためにBlockfrost APIに接続するウォレットプロバイダーです。BaseWalletProviderを拡張し、fetcherとsubmitter機能の両方を提供します。

**パラメータ:**

- `config` (BlockfrostProviderConfig):
  - `apiKey` (string): [Blockfrost Dashboard](https://blockfrost.io/)からのBlockfrost Project ID
  - `network` (BlockfrostSupportedNetworks): 接続するネットワーク（'mainnet'、'preprod'、または'preview'）
  - `apiVersion` (number, optional): Blockfrost APIバージョン（デフォルト: 0）
  - `cachingOptions` (object, optional): キャッシング設定
    - `enabled` (boolean): レスポンスキャッシングを有効化（デフォルト: false）
    - `maxSize` (number): 最大キャッシュアイテム数（デフォルト: 100）
    - `ttl` (number): ミリ秒単位の生存時間（デフォルト: 300000 - 5分）

**プロパティ:**

- `fetcher` (IFetcher): ブロックチェーンデータを取得するためのインターフェース
  - `fetchAddressUTxOs(address: string, asset?: string): Promise<UTxO[]>` - アドレスのUTxOを取得、オプションでアセットでフィルター
- `submitter` (ISubmitter): トランザクション送信のためのインターフェース
  - `submitTx(txHex: string): Promise<string>` - 署名済みトランザクションを送信し、トランザクションハッシュを返す

**例:**

```typescript
import { BlockfrostProvider } from '@hydra-sdk/core'

// 基本設定
const provider = new BlockfrostProvider({
	apiKey: 'preprodXXXXXXXXXXXXXXXXXXXX',
	network: 'preprod'
})

// APIバージョンとキャッシング付き
const providerWithCache = new BlockfrostProvider({
	apiKey: 'preprodXXXXXXXXXXXXXXXXXXXX',
	network: 'preprod',
	apiVersion: 0,
	cachingOptions: {
		enabled: true,
		maxSize: 200,
		ttl: 600000 // 10分
	}
})

// アドレスのすべてのUTxOを取得
const utxos = await provider.fetcher.fetchAddressUTxOs(
	'addr1qx2fxv2umyhttkxyxp8x0dlpdt3k6cwng5pxj3jhsydzer...'
)

// 特定のアセットを含むUTxOを取得
const assetUtxos = await provider.fetcher.fetchAddressUTxOs(
	'addr1qx2fxv2umyhttkxyxp8x0dlpdt3k6cwng5pxj3jhsydzer...',
	'lovelace' // またはpolicy_id + asset_name
)

// 署名済みトランザクションを送信
const txHash = await provider.submitter.submitTx(signedTxHex)
console.log('トランザクション送信:', txHash)
```

**戻り値:** `BlockfrostProvider`
プロバイダーインスタンス

### **`OgmiosProvider.constructor(config: OgmiosProviderConfig) → OgmiosProvider`**

JSON-RPC 2.0プロトコルを使用してクエリとトランザクション送信を行うOgmiosプロバイダーを作成します。

説明: OgmiosProviderは、UTxOの取得とトランザクション送信のためにHTTP経由でOgmios APIに接続するウォレットプロバイダーです。BaseWalletProviderを拡張し、JSON-RPC 2.0プロトコルを使用してOgmiosサーバーと通信します。

**パラメータ:**

- `config` (OgmiosProviderConfig):
  - `network` (OgmiosSupportedNetworks): 接続するネットワーク（'mainnet'、'preprod'、または'preview'）
  - `apiEndpoint` (string, optional): Ogmios APIエンドポイントURL

**プロパティ:**

- `fetcher` (IFetcher): ブロックチェーンデータを取得するためのインターフェース
  - `fetchAddressUTxOs(address: string, asset?: string): Promise<UTxO[]>` - アドレスのUTxOを取得、オプションでアセットでフィルター
- `submitter` (ISubmitter): トランザクション送信のためのインターフェース
  - `submitTx(tx: string): Promise<string>` - 署名済みトランザクションを送信し、トランザクションハッシュを返す

**例:**

```typescript
import { OgmiosProvider } from '@hydra-sdk/core'
```

## 完全な例

### 基本的なデータ変換

```typescript
import {
	ParserUtils,
	DatumUtils,
	PolicyUtils,
	SLOT_CONFIG_NETWORK,
	TimeUtils
} from '@hydra-sdk/core'

// データを変換
const hex = ParserUtils.stringToHex('Hello Cardano')
const bytes = ParserUtils.hexToBytes(hex)
console.log('Hex:', hex)
console.log('Bytes:', bytes)

// 時間を扱う
const currentSlot = TimeUtils.unixTimeToEnclosingSlot(
	Math.floor(Date.now() / 1000),
	SLOT_CONFIG_NETWORK.PREPROD
)
const readableTime = new Date(
	TimeUtils.slotToBeginUnixTime(currentSlot, SLOT_CONFIG_NETWORK.PREPROD) * 1000
)
console.log('Current slot:', currentSlot)
console.log('Readable time:', readableTime.toLocaleString())

// datumを作成
const datum = DatumUtils.mkConstr(0, [
	DatumUtils.mkInt(42),
	DatumUtils.mkBytes(hex)
])
console.log('Datum hex:', datum.to_hex())
```
