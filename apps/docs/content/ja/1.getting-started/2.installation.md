# インストール

Hydra SDK は NPM 上の複数のパッケージとして公開されており、プロジェクトに必要なものだけをインストールできます。

## システム要件

SDK をインストールする前に、以下の要件を満たしていることを確認してください。

- **Node.js**: >= 18.20.0
- **npm**: >= 8.0.0（または **pnpm** >= 8.0.0、**yarn** >= 1.22.0）
- **TypeScript**: >= 5.0.0（任意ですが推奨）

## コアパッケージ

### 個別パッケージのインストール

必要なパッケージだけをインストールします。

```bash
# Core wallet functionality | Cardano WASM bindings
npm install @hydra-sdk/cardano-wasm @hydra-sdk/core

# Hydra Layer 2 integration  
npm install @hydra-sdk/bridge

# Transaction building utilities
npm install @hydra-sdk/transaction
```

### バンドル一括インストール

ほとんどのプロジェクトでは、コアパッケージをまとめてインストールすることを推奨します。

```bash
# 主要なパッケージを一括インストール
npm install @hydra-sdk/cardano-wasm @hydra-sdk/core @hydra-sdk/bridge @hydra-sdk/transaction
```
