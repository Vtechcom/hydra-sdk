# 設定

Hydra SDK は、高性能な Cardano 処理のために WebAssembly (WASM) を活用しています。このガイドでは、SDK のパフォーマンスを最大限に引き出すためのビルドツールおよび環境設定について説明します。

## 📂 フルサンプル

完全な設定例を含む動作サンプルは、以下のリソースから確認できます。

- **[React + Vite サンプル](/ja/3.examples/5.full-react-app)** – React アプリケーションの完全なセットアップ
- **[Vue.js + TypeScript サンプル](/ja/3.examples/6.full-vuejs-app)** – Vue.js アプリケーションの完全なセットアップ
- **[Examples Repository](https://github.com/Vtechcom/hydra-sdk-examples)** – すべての例をまとめた GitHub リポジトリ

## Nuxt 3

Nuxt.js プロジェクトでは、`nuxt.config.ts` を次のように設定します。

```typescript
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineNuxtConfig({
  ssr: false, // ウォレットアプリでは SSR を無効化
  
  vite: {
    plugins: [
      wasm(),
      topLevelAwait(),
      nodePolyfills({
        include: ['buffer'],
        globals: {
          Buffer: true,
          global: false,
          process: false
        }
      })
    ],
    optimizeDeps: {
      exclude: ['@hydra-sdk/cardano-wasm']
    }
  }
})
```

## Vue.js + Vite

Vue プロジェクトの `vite.config.js` は次のように設定します。

💡 **完全な設定は [Vue.js フルサンプル](/ja/3.examples/6.full-vuejs-app) を参照してください。**

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineConfig({
  plugins: [
    vue(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      }
    })
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm']
  }
})
```

## Next.js 設定

Next.js を使用する場合は、`next.config.js` を以下のように設定します。

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  webpack: (config, { isServer }) => {
    if (!isServer) {
      config.experiments = {
        ...config.experiments,
        asyncWebAssembly: true,
        topLevelAwait: true
      }
      
      config.resolve.fallback = {
        ...config.resolve.fallback,
        crypto: false,
        stream: false,
        util: false,
        buffer: require.resolve('buffer')
      }
    }
    
    return config
  },
  
  // ウォレットページでは静的最適化を無効化
  experimental: {
    esmExternals: 'loose'
  }
}

module.exports = nextConfig
```

Next.js 13 以降で app directory を使用する場合は、`globals.d.ts` も作成します。

```typescript
declare global {
  var Buffer: typeof import('buffer').Buffer
}

export {}
```
