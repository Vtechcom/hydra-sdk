# クイックスタート

このガイドでは、Hydra SDK を使って最初の Cardano ウォレットアプリケーションを作成する手順を説明します。数分で、アカウント作成・トランザクション構築・Hydra Layer 2 への接続ができるウォレットが完成します。

## ステップ 1: インストール

まず、必要なパッケージをインストールします。

```bash
npm install @hydra-sdk/cardano-wasm @hydra-sdk/core @hydra-sdk/bridge @hydra-sdk/transaction
```

## ステップ 2: 最初のウォレットを作成

`@hydra-sdk/core` を使ってウォレットインスタンスを作成します。

```typescript
import { AppWallet, NETWORK_ID } from '@hydra-sdk/core'

// 新しい mnemonic phrase を生成
const mnemonic = AppWallet.brew()
console.log('Generated mnemonic:', mnemonic.join(' '))

// ウォレットインスタンスを作成
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD, // テストには PREPROD を使用
  key: {
    type: 'mnemonic',
    words: mnemonic
  }
})

// 最初のアカウントを取得
const account = wallet.getAccount(0, 0)
console.log('Wallet Address:', account.baseAddressBech32)
```

### 既存ウォレットの復元

既存の mnemonic からウォレットを復元する場合:

```typescript
const existingMnemonic = 'your existing mnemonic phrase here'.split(' ')

const restoredWallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: {
    type: 'mnemonic',
    words: existingMnemonic
  }
})
```

## ステップ 3: UTxO を取得してトランザクションを構築

まずウォレットアドレスから UTxO を取得し、その後 transaction builder を使ってトランザクションを構築します。

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'
import { ProviderUtils } from '@hydra-sdk/core'

// Provider を初期化（Blockfrost または Ogmios）
const blockfrostProvider = new ProviderUtils.BlockfrostProvider({
  apiKey: 'your-blockfrost-api-key',
  network: 'preprod'
})

// ウォレットに provider を設定
const wallet = new AppWallet({
  networkId: NETWORK_ID.PREPROD,
  key: {
    type: 'mnemonic',
    words: mnemonic
  },
  fetcher: blockfrostProvider.fetcher,
  submitter: blockfrostProvider.submitter
})

// ウォレットアドレスを取得
const account = wallet.getAccount(0, 0)
const walletAddress = account.baseAddressBech32

// ウォレットの UTxO を取得
const utxos = await wallet.queryUTxOs(walletAddress)
console.log('Available UTxOs:', utxos.length)

// 単純な ADA 送金トランザクションを構築
const recipientAddress = 'addr_test1...' // 送金先アドレス
const amountToSend = '1000000' // 1 ADA（lovelace 単位）

try {
  // Transaction builder を初期化
  const txBuilder = new TxBuilder()
  
  const tx = await txBuilder
    .setInputs(utxos) // 取得した UTxO を inputs に設定
    .addOutput({
      address: recipientAddress,
      amount: [{ unit: 'lovelace', quantity: amountToSend }]
    })
    .changeAddress(walletAddress) // おつりは送り主に返却
    .complete()

  console.log('Transaction built:', tx.to_hex())

  // トランザクションに署名
  const signedTx = await wallet.signTx(tx.to_hex())
  console.log('Transaction signed')

  // トランザクションを送信
  const txHash = await wallet.submitTx(signedTx)
  console.log('Transaction submitted! Hash:', txHash)

} catch (error) {
  console.error('Transaction failed:', error)
}
```

### 高度なトランザクション例

複数の output と Native Token を含むトランザクションを構築する例です。

```typescript
import { TxBuilder } from '@hydra-sdk/transaction'

const txBuilder = new TxBuilder()

// UTxO を取得
const utxos = await wallet.queryUTxOs(walletAddress)

const tx = await txBuilder
  .setInputs(utxos)
  // 1 人目の受取人に ADA を送金
  .addOutput({
    address: 'addr_test1qr...',
    amount: [{ unit: 'lovelace', quantity: '2000000' }]
  })
  // 2 人目の受取人に ADA + Native Token を送金
  .addOutput({
    address: 'addr_test1qs...',
    amount: [
      { unit: 'lovelace', quantity: '1500000' },
      { unit: 'policyId.assetName', quantity: '100' }
    ]
  })
  .changeAddress(walletAddress)
  .complete()

const signedTx = await wallet.signTx(tx.to_hex())
const txHash = await wallet.submitTx(signedTx)
console.log('Transaction hash:', txHash)
```

## ステップ 4: Hydra Layer 2 へ接続

高速な Layer 2 トランザクションのために、Hydra Head に接続する `HydraBridge` を作成します。

```typescript
import { HydraBridge, HydraPayload } from '@hydra-sdk/bridge'

// Hydra Bridge インスタンスを作成
const bridge = new HydraBridge({
  url: 'ws://localhost:4001', // Hydra Node の WebSocket URL
})

// 接続イベントを監視
bridge.events.on('onConnected', () => {
  console.log('Connected to Hydra Head!')
})

bridge.events.on('onMessage', (payload: HydraPayload) => {
    console.log('>>> / onMessage:', payload)
})

// Hydra Node に接続
await bridge.connect()
```

## HexcoreConnector を使って Hydra Layer 2 に接続

`HexcoreConnector` を利用して Hydra Head に接続する例です。

```typescript
import { HydraBridge, HexcoreConnector } from '@hydra-sdk/bridge'

const hexcoreConnector = new HexcoreConnector({
    socketIoUrl: 'wss://example.hexcore.io.vn/hydra',
    socketIoOptions: {
        auth: {
            token: 'your_auth_token'
        }
    }
})
// Hydra Bridge インスタンスを作成
const bridge = new HydraBridge({
  connector: hexcoreConnector
})

// 接続イベントを監視
bridge.events.on('onConnected', () => {
  console.log('Connected to Hydra Head!')
})

bridge.events.on('onMessage', (payload: HydraPayload) => {
    console.log('>>> / onMessage:', payload)
})

// Hydra Node に接続
await bridge.connect()
```
