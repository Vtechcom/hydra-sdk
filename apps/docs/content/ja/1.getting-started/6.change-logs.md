## 🔄 マイグレーションメモ

### パッケージ命名規約
v1.0.5 以降、すべてのパッケージは `@hydrawallet-sdk/*` から `@hydra-sdk/*` へ名称変更されています。

### 推奨設定 (v1.0.13+)
Vite ベースのプロジェクトでは、次のような polyfill 設定を推奨します:

```javascript
nodePolyfills({
  include: ['buffer'],  // ✅ Buffer のみ polyfill
  globals: {
    Buffer: true,       // ✅ 暗号処理に必要
    global: false,      // ✅ 不要な polyfill を無効化
    process: false      // ✅ 不要な polyfill を無効化
  }
})
```

**レガシー設定 (後方互換用):**

```javascript
nodePolyfills({
  globals: {
    Buffer: true,
    global: true,    // ⚠️ 推奨はしないが動作はする
    process: true    // ⚠️ 推奨はしないが動作はする
  }
})
```

### 主な Breaking Changes
- **v1.1.0**: TimeUtils の API 変更 – `resolveSlotNo()` を廃止し、`unixTimeToEnclosingSlot()` + `SLOT_CONFIG_NETWORK` へ移行
- **v1.1.0**: DatumSchema を定数ベース API に統一し、`fromJSON()` / `toJSON()` を削除
- **v1.1.0**: Serializer の直 import を廃止し、`Serializer.serializeAssetUnit()` を利用
- **v1.0.14**: DatumUtils / PolicyUtils を拡張し、mint / burn token 用の構造を変更
- **v1.0.13**: ドキュメントライセンスを MIT から Apache 2.0 へ変更
- **v1.0.12**: redeemer builder のインターフェースに `exUnits` パラメータを追加
- **v1.0.11**: トランザクション validity range の扱いを変更
- **v1.0.10**: リポジトリ URL を Vtechcom 組織へ変更
