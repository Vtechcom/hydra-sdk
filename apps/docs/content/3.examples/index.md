# Examples

Welcome to the Hydra SDK documentation examples section. Here you'll find practical code samples and use cases to help you get started with the SDK.

## Overview

The examples are organized into several categories:

1. **[Wallet Creation](/examples/wallet-creation)** - Create and manage Cardano wallets
2. **[Hydra Integration](/examples/hydra-integration)** - Connect to Hydra Layer 2 and manage Hydra Heads
3. **[Transaction Building](/examples/transaction-building)** - Build and submit transactions
4. **[Full Application](/examples/full-application)** - Complete applications with UI
5. **[React Application](/examples/full-react-app)** - React-based Cardano application
6. **[Vue.js Application](/examples/full-vuejs-app)** - Vue.js-based Cardano application
7. **[Utilities Examples](/examples/utilities-examples)** - Practical examples of utility functions
8. **[Transaction Signing](/examples/transaction-signing)** - Transaction signing patterns from basic to advanced

## New in v1.1.0

- **[Utilities Examples](/examples/utilities-examples)** - Comprehensive examples of using new utility functions
- **Advanced Patterns** - Error handling, provider fallbacks, and performance optimization
- **Real-world Scenarios** - NFT collections, marketplaces, token swaps, and vesting schedules
