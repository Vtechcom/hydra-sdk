Tài liệu này được xây dựng để các trợ lý AI và công cụ LLM có thể sử dụng. Ba phương thức truy cập được cung cấp sẵn — một MCP server, các tệp `llms.txt`, và markdown thô cho từng trang.

## MCP server

Một server [Model Context Protocol](https://modelcontextprotocol.io) được cung cấp tại `/mcp` (`https://hydrasdk.com/mcp`) qua streamable HTTP, cho phép trợ lý AI truy vấn tài liệu trực tiếp thay vì phải đoán. Server có tên **Hydra SDK** và cung cấp hai công cụ:

| Công cụ | Mục đích |
| --- | --- |
| `list-pages` | Liệt kê mọi trang tài liệu cùng tiêu đề, đường dẫn, và mô tả — dùng nó để khám phá hoặc tìm kiếm khi bạn chưa biết chính xác trang nào. |
| `get-page` | Lấy toàn bộ markdown của một trang cụ thể theo đường dẫn (ví dụ `/getting-started/installation`). |

Một luồng điển hình: gọi `list-pages` để tìm đúng đường dẫn, rồi `get-page` để đọc nó.

### Kết nối

::code-group
```bash [Claude Code]
claude mcp add --transport http hydra-sdk https://hydrasdk.com/mcp
```

```json [mcp.json]
{
  "mcpServers": {
    "hydra-sdk": {
      "url": "https://hydrasdk.com/mcp"
    }
  }
}
```
::

::tip
Khi bạn chạy tài liệu ở máy cục bộ (`pnpm dev`, cổng 3003), MCP server nằm tại `http://localhost:3003/mcp`, và dev server sẽ in ra một liên kết sâu **Install Nuxt MCP server** khi khởi động — mở nó để tự động đăng ký server trong trình soạn thảo của bạn.
::

## llms.txt

Theo quy ước [llms.txt](https://llmstxt.org), hai tệp cung cấp cho LLM toàn bộ tài liệu làm ngữ cảnh:

- **[/llms.txt](https://hydrasdk.com/llms.txt)** — một chỉ mục của mọi trang cùng liên kết và mô tả.
- **[/llms-full.txt](https://hydrasdk.com/llms-full.txt)** — toàn bộ tài liệu được nối lại thành một tệp duy nhất.

Trỏ một công cụ hỗ trợ LLM tới một trong hai URL, hoặc dán nội dung vào cuộc trò chuyện để cung cấp cho mô hình đầy đủ ngữ cảnh về Hydra SDK.

## Markdown thô

Thêm `.md` dưới tiền tố `/raw/` vào bất kỳ đường dẫn trang nào để lấy mã nguồn markdown sạch của nó — tiện lợi khi đưa một trang riêng lẻ vào mô hình:

```bash
curl https://hydrasdk.com/raw/getting-started/installation.md
```

Endpoint thô **nhận biết locale** — thêm tiền tố locale để lấy trang đã dịch:

```bash
curl https://hydrasdk.com/raw/vi/getting-started/installation.md
curl https://hydrasdk.com/raw/ja/getting-started/installation.md
```
