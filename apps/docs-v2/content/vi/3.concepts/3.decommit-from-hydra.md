Decommit là quá trình rút UTxO từ một Hydra Head đang hoạt động trở lại Cardano Layer 1. Điều này cho phép bạn thoát khỏi môi trường Layer 2 và đưa tài sản của mình trở nên khả dụng trên chuỗi chính.

## Tìm hiểu về decommit

### Decommit là gì?

Decommit loại bỏ UTxO khỏi Hydra Head và trả chúng về Layer 1 trong khi head vẫn mở. Hãy hình dung nó giống như việc chuyển tiền từ làn cao tốc trở lại con đường chính.

```
┌─────────────────────────────────────────┐
│         Hydra Head (Layer 2)            │
│                                         │
│  Your UTxOs: [UTxO1, UTxO2, UTxO3]      │
│                                         │
└──────────────┬──────────────────────────┘
			   │
			   │ DECOMMIT
			   │ (Remove from Head, return to L1)
			   │
┌──────────────▼──────────────────────────┐
│         Cardano Layer 1                 │
│                                         │
│  Available: [UTxO1, UTxO2, UTxO3]       │
│  Back on main chain                     │
│                                         │
└─────────────────────────────────────────┘
```


## Quá trình decommit

### Khi nào bạn nên decommit?
Bạn nên decommit khi muốn rút tài sản khỏi một Hydra Head mà không đóng Head. Ví dụ: chuyển tài sản trở lại ví Layer 1 của bạn hoặc rút một phần để sử dụng trên Cardano mainnet.

### Các bước để decommit
1. Kết nối tới Hydra node thông qua Hydra Bridge.
2. Truy vấn các UTxO hiện tại trong Hydra Head.
3. Xây dựng một giao dịch decommit với các UTxO mà bạn muốn rút.
4. Ký giao dịch bằng ví của bạn.
5. Gửi giao dịch decommit tới Hydra node.
6. Theo dõi trạng thái snapshot và xác nhận các UTxO đã trở về Layer 1.

```ts
// nodejs-playground/src/hydra/decommit.ts
import { TxBuilder } from '@hydra-sdk/transaction'
import { HydraBridge } from '@hydra-sdk/bridge'
import { wallet, walletAddress } from './common'
import { Resolver } from '@hydra-sdk/core'

async function main() {
	const bridge = new HydraBridge({
		url: 'ws://localhost:4001'
	})
	const connected = await bridge.connect()
	if (!connected) {
		throw new Error('Failed to connect to Hydra node')
	}
	console.log('>>> Connected to Hydra node')

	const utxoObj = await bridge.querySnapshotUtxo()

	const addrUtxos = await bridge.queryAddressUTxO(walletAddress)
	const txBuilder = new TxBuilder({
		isHydra: true,
		params: {
			minFeeA: 0,
			minFeeB: 0
		}
	})
	const tx = await txBuilder
		.setInputs([
			addrUtxos[0] // utxo to decommit
		])
		.addOutput({
			address: walletAddress,
			amount: [{ unit: 'lovelace', quantity: String(2_000_000) }]
		})
		.changeAddress(walletAddress)
		.complete()

	const signedCbor = await wallet.signTx(tx.to_hex())
	const txId = Resolver.resolveTxHash(signedCbor)

	const rs = await bridge.decommit({
		cborHex: signedCbor,
		txId,
		timeout: 30000
	})
	console.log('>>> Submit tx result:', rs)
}
main()
```

### Thực hành tốt nhất
- Chỉ decommit khi cần thiết để tránh các khoản phí Layer 1 không cần thiết.
- Kiểm tra kỹ các UTxO trước khi decommit để tránh mất tài sản do sai sót.
- Theo dõi trạng thái snapshot sau khi decommit để đảm bảo các UTxO đã trở về Layer 1.
- Nếu Head bị đóng, tất cả UTxO sẽ được trả về Layer 1 một cách tự động (không cần decommit thủ công).
