Các hướng dẫn này là những bài thực hành theo hướng tác vụ. Mỗi bài đưa bạn từ mục tiêu đến đoạn code hoạt động được. Về nền tảng khái niệm, xem [Khái niệm](/concepts); về chữ ký chính xác, xem [Tài liệu tham khảo API](/api).

::card-group
  ::card{title="Xây dựng ứng dụng ví" icon="i-lucide-wallet" to="/guides/build-wallet-app"}
  Dựng khung một ứng dụng ví hoàn chỉnh — clone-và-chạy cho React hoặc Vue, hoặc tự xây dựng với kiến trúc tầng dịch vụ.
  ::

  ::card{title="Xây dựng giao dịch" icon="i-lucide-file-signature" to="/guides/transactions"}
  Xây dựng, ký và gửi giao dịch — bao gồm ký đa chữ ký và khóa/mở khóa Plutus.
  ::

  ::card{title="Đúc và đốt token" icon="i-lucide-coins" to="/guides/mint-burn-tokens"}
  Tạo và hủy native token với minting policy và metadata.
  ::

  ::card{title="Tích hợp Hydra" icon="i-lucide-network" to="/guides/hydra-integration"}
  Kết nối với một Hydra Head, gửi giao dịch và xử lý những lỗi thường gặp.
  ::

  ::card{title="Sổ tay utilities" icon="i-lucide-wrench" to="/guides/utilities-cookbook"}
  Công thức cho datum, redeemer, policy, chuyển đổi time/slot và provider.
  ::

  ::card{title="Nhập khóa cardano-cli" icon="i-lucide-key-round" to="/guides/cardano-cli-keys"}
  Tạo khóa bằng `cardano-cli` và nạp chúng vào SDK.
  ::
::
