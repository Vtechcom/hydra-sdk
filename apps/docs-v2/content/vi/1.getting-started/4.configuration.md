Hydra SDK tận dụng WebAssembly (WASM) cho các thao tác Cardano hiệu năng cao. Hướng dẫn này trình bày cách cấu hình các công cụ build và môi trường của bạn để đạt hiệu năng tối ưu.

## Ví dụ đầy đủ

Để xem các ví dụ hoàn chỉnh, hoạt động được với cấu hình đầy đủ, hãy tham khảo kho ví dụ của chúng tôi:
- **[Ví dụ React + Vite](/guides/build-wallet-app)** - Thiết lập ứng dụng React hoàn chỉnh
- **[Ví dụ Vue.js + TypeScript](/guides/build-wallet-app)** - Thiết lập ứng dụng Vue.js hoàn chỉnh
- **[Kho ví dụ](https://github.com/Vtechcom/hydra-sdk-examples)** - Tất cả các ví dụ trên GitHub

## Nuxt 3

Với các dự án Nuxt.js, hãy cấu hình `nuxt.config.ts` của bạn:

```typescript
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineNuxtConfig({
  ssr: false, // Disable SSR for wallet applications
  
  vite: {
    plugins: [
      wasm(),
      topLevelAwait(),
      nodePolyfills({
        include: ['buffer'],
        globals: {
          Buffer: true,
          global: false,
          process: false
        }
      })
    ],
    optimizeDeps: {
      exclude: ['@hydra-sdk/cardano-wasm']
    }
  }
})
```

## Vue.js với Vite

Cấu hình `vite.config.js` của bạn cho các dự án Vue:

💡 **Xem [ví dụ Vue.js đầy đủ](/guides/build-wallet-app) để có một thiết lập hoạt động được hoàn chỉnh.**

```javascript
    exclude: ['@hydra-sdk/cardano-wasm']
  }
})
```

## Loại trừ nhiều hơn `cardano-wasm`

Các cấu hình Vite ở trên chỉ loại trừ `@hydra-sdk/cardano-wasm` khỏi bước pre-bundling dependency. Đây là một module wasm-bindgen cần `vite-plugin-wasm` và `vite-plugin-top-level-await`, nên Vite không thể pre-bundle nó.

Nếu bạn loại trừ thêm `@hydra-sdk/core` hoặc `@hydra-sdk/transaction`, dev server sẽ trả về **500** trên mọi route có import SDK:

```
The requested module '/_nuxt/@fs/.../@harmoniclabs/uplc/dist/index.js'
does not provide an export named 'Application'
```

Package bị loại trừ sẽ được Vite phục vụ nguyên trạng, nên Vite đi theo các import của nó xuống tới `@harmoniclabs/uplc`. Package đó là CommonJS, và vì chỉ có thể tiếp cận *thông qua* một package đã bị loại trừ nên Vite cũng không pre-bundle nó — kết quả là nó được phục vụ dưới dạng CJS-as-ESM, không phơi ra named export nào phân tích được.

Hãy force-include các leaf dependency để Vite pre-bundle chúng kèm interop CJS→ESM. Trong pnpm workspace, specifier trần không resolve được từ thư mục gốc của app, vì vậy hãy dùng cú pháp lồng `importer > dep`:

```typescript
optimizeDeps: {
  exclude: ['@hydra-sdk/cardano-wasm', '@hydra-sdk/core', '@hydra-sdk/transaction'],
  include: [
    '@hydra-sdk/core > @harmoniclabs/uplc',
    '@hydra-sdk/core > @harmoniclabs/plutus-data',
    '@hydra-sdk/core > @scure/base',
    '@hydra-sdk/core > axios',
    '@hydra-sdk/core > bip39',
    '@hydra-sdk/core > cbor-x'
  ]
}
```

Sau đó khởi động lại dev server với cache đã được xoá:

```bash
rm -rf node_modules/.cache/vite .nuxt/cache
```

::warning
Chỉ xoá cache thôi thì không khắc phục được. Lỗi này phát sinh một cách tất định từ tổ hợp exclude + CommonJS, nên nó sẽ quay lại ở lần tối ưu dependency kế tiếp.
::

::note
Nếu xuất hiện lỗi `does not provide an export named …` mới cho một CommonJS dependency khác, hãy thêm `@hydra-sdk/core > <that-package>` vào danh sách `include`.
::

## Cấu hình Next.js

Cấu hình Next.js trong `next.config.js` của bạn:

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  webpack: (config, { isServer }) => {
    if (!isServer) {
      config.experiments = {
        ...config.experiments,
        asyncWebAssembly: true,
      }
      
      config.resolve.fallback = {
        ...config.resolve.fallback,
        crypto: false,
        stream: false,
        util: false,
        buffer: require.resolve('buffer')
      }
    }
    
    return config
  },
  
  // Disable static optimization for wallet pages
  experimental: {
    esmExternals: 'loose'
  }
}

module.exports = nextConfig
```

Với Next.js 13+ sử dụng thư mục app, hãy tạo thêm một file `globals.d.ts`:

```typescript
declare global {
  var Buffer: typeof import('buffer').Buffer
}

export {}
```
