Hydra SDK được phát hành dưới dạng các package riêng lẻ trên NPM, cho phép bạn chỉ cài đặt những gì dự án của bạn cần.

## Cài đặt với AI assistant

Dán prompt sau vào AI coding assistant (Claude, Cursor, Copilot…) để cài đặt và cấu hình Hydra SDK. Nó trỏ assistant tới bản docs máy đọc được và nêu rõ các rule thường gây lỗi:

```text
Install and configure Hydra SDK (@hydra-sdk) in this project.

Read these for the exact steps:
- https://hydrasdk.com/raw/getting-started/installation.md
- https://hydrasdk.com/raw/getting-started/configuration.md

Rules (follow strictly):
1. Always install @hydra-sdk/cardano-wasm together with the other @hydra-sdk/* packages.
2. Never import @emurgo/cardano-serialization-lib directly — use @hydra-sdk/cardano-wasm.
3. NETWORK_ID is a Record<Network, number> with keys MAINNET | PREPROD | PREVIEW (no TESTNET), not an enum.
4. For a browser build with Vite, add vite-plugin-wasm + vite-plugin-top-level-await + a buffer polyfill, and exclude @hydra-sdk/cardano-wasm from optimizeDeps.

Then create an AppWallet on PREPROD and log its base address to verify the setup.
```

## Yêu cầu hệ thống

Trước khi cài đặt SDK, hãy đảm bảo hệ thống của bạn đáp ứng các yêu cầu sau:

- **Node.js**: >= 18.20.0
- **npm**: >= 8.0.0 (hoặc **pnpm** >= 8.0.0, **yarn** >= 1.22.0)
- **TypeScript**: >= 5.0.0 (tùy chọn nhưng được khuyến nghị)

## Các package cốt lõi

### Cài đặt từng package riêng lẻ

Cài đặt các package bạn cần — nhưng luôn bao gồm `@hydra-sdk/cardano-wasm`:

```bash
# Core wallet functionality
npm install @hydra-sdk/core @hydra-sdk/cardano-wasm

# Hydra Layer 2 integration
npm install @hydra-sdk/bridge @hydra-sdk/cardano-wasm

# Transaction building utilities
npm install @hydra-sdk/transaction @hydra-sdk/cardano-wasm
```

::note
`@hydra-sdk/cardano-wasm` là phần lõi WASM mà mọi package khác đều import thông qua nó. Mặc dù nó được kéo vào một cách bắc cầu, hãy cài đặt nó như một **dependency trực tiếp** để bộ đóng gói của bạn có thể cấu hình nó (`vite-plugin-wasm`, loại nó khỏi `optimizeDeps`) và để cơ chế phân giải `node_modules` nghiêm ngặt của pnpm tìm được nó. Xem [Cấu hình](/getting-started/configuration) để thiết lập bộ đóng gói.
::

### Cài đặt trọn bộ

Với hầu hết các dự án, hãy cài đặt các package cốt lõi cùng nhau:

```bash
# Install all essential packages
npm install @hydra-sdk/core @hydra-sdk/bridge @hydra-sdk/transaction @hydra-sdk/cardano-wasm
```
