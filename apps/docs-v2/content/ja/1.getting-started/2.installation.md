Hydra SDK は個別のパッケージとして NPM 上で公開されており、プロジェクトに必要なものだけをインストールできます。

## システム要件

SDK をインストールする前に、システムが次の要件を満たしていることを確認してください。

- **Node.js**: >= 18.20.0
- **npm**: >= 8.0.0（または **pnpm** >= 8.0.0、**yarn** >= 1.22.0）
- **TypeScript**: >= 5.0.0（任意ですが推奨）

## コアパッケージ

### 個別パッケージのインストール

必要なパッケージをインストールしてください。ただし、常に `@hydra-sdk/cardano-wasm` を含めてください。

```bash
# Core wallet functionality
npm install @hydra-sdk/core @hydra-sdk/cardano-wasm

# Hydra Layer 2 integration
npm install @hydra-sdk/bridge @hydra-sdk/cardano-wasm

# Transaction building utilities
npm install @hydra-sdk/transaction @hydra-sdk/cardano-wasm
```

::note
`@hydra-sdk/cardano-wasm` は、他のすべてのパッケージがインポート経路として通る WASM コアです。推移的に取り込まれる場合でも、**直接の依存関係**としてインストールしてください。そうすることで、バンドラーが設定でき（`vite-plugin-wasm`、`optimizeDeps` からの除外）、pnpm の厳格な `node_modules` でも解決できます。バンドラーの設定については[設定](/getting-started/configuration)を参照してください。
::

### 一括バンドルのインストール

ほとんどのプロジェクトでは、コアパッケージをまとめてインストールします。

```bash
# Install all essential packages
npm install @hydra-sdk/core @hydra-sdk/bridge @hydra-sdk/transaction @hydra-sdk/cardano-wasm
```
