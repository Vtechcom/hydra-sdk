Hydra SDK は、高性能な Cardano 操作のために WebAssembly (WASM) を活用します。このガイドでは、最適なパフォーマンスを得るためにビルドツールと環境をどのように設定するかを解説します。

- **[Vue.js + TypeScript の例](/guides/build-wallet-app)** - 完全な Vue.js アプリケーションのセットアップ

## Nuxt 3

Nuxt.js プロジェクトでは、`nuxt.config.ts` を設定します。

```typescript
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineNuxtConfig({
  ssr: false, // Disable SSR for wallet applications
  
  vite: {
    plugins: [
      wasm(),
      topLevelAwait(),
      nodePolyfills({
        include: ['buffer'],
        globals: {
          Buffer: true,
          global: false,
          process: false
        }
      })
    ],
    optimizeDeps: {
      exclude: ['@hydra-sdk/cardano-wasm']
    }
  }
})
```

## Vite を使った Vue.js

Vue プロジェクトでは `vite.config.js` を設定します。

💡 **完全に動作するセットアップについては、[完全な Vue.js の例](/guides/build-wallet-app)を参照してください。**

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineConfig({
  plugins: [
    vue(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      }
    })
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm']
  }
})
```

## Next.js の設定

Next.js は `next.config.js` で設定します。

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  webpack: (config, { isServer }) => {
    if (!isServer) {
      config.experiments = {
        ...config.experiments,
        asyncWebAssembly: true,
      }
      
      config.resolve.fallback = {
        ...config.resolve.fallback,
        crypto: false,
        stream: false,
        util: false,
        buffer: require.resolve('buffer')
      }
    }
    
    return config
  },
  
  // Disable static optimization for wallet pages
  experimental: {
    esmExternals: 'loose'
  }
}

module.exports = nextConfig
```

app ディレクトリを使う Next.js 13 以降では、`globals.d.ts` も作成します。

```typescript
declare global {
  var Buffer: typeof import('buffer').Buffer
}

export {}
```
