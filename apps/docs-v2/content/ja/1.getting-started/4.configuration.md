Hydra SDK は、高性能な Cardano 操作のために WebAssembly (WASM) を活用します。このガイドでは、最適なパフォーマンスを得るためにビルドツールと環境をどのように設定するかを解説します。

- **[Vue.js + TypeScript の例](/guides/build-wallet-app)** - 完全な Vue.js アプリケーションのセットアップ

## Nuxt 3

Nuxt.js プロジェクトでは、`nuxt.config.ts` を設定します。

```typescript
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineNuxtConfig({
  ssr: false, // Disable SSR for wallet applications
  
  vite: {
    plugins: [
      wasm(),
      topLevelAwait(),
      nodePolyfills({
        include: ['buffer'],
        globals: {
          Buffer: true,
          global: false,
          process: false
        }
      })
    ],
    optimizeDeps: {
      exclude: ['@hydra-sdk/cardano-wasm']
    }
  }
})
```

## Vite を使った Vue.js

Vue プロジェクトでは `vite.config.js` を設定します。

💡 **完全に動作するセットアップについては、[完全な Vue.js の例](/guides/build-wallet-app)を参照してください。**

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineConfig({
  plugins: [
    vue(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      }
    })
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm']
  }
})
```

## Vite を使った React

Vite を使う React プロジェクトでは、`vite.config.js` を更新します。

💡 **完全に動作するセットアップについては、[完全な React の例](/guides/build-wallet-app)を参照してください。**

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import wasm from 'vite-plugin-wasm'
import topLevelAwait from 'vite-plugin-top-level-await'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineConfig({
  plugins: [
    react(),
    wasm(),
    topLevelAwait(),
    nodePolyfills({
      include: ['buffer'],
      globals: {
        Buffer: true,
        global: false,
        process: false
      }
    })
  ],
  optimizeDeps: {
    exclude: ['@hydra-sdk/cardano-wasm']
  }
})
```

## `cardano-wasm` 以外も除外する場合

上記の Vite 設定では、依存関係の事前バンドルから `@hydra-sdk/cardano-wasm` のみを除外しています。これは `vite-plugin-wasm` と `vite-plugin-top-level-await` を必要とする wasm-bindgen モジュールであり、Vite では事前バンドルできないためです。

`@hydra-sdk/core` や `@hydra-sdk/transaction` も併せて除外すると、SDK を import しているすべてのルートで dev server が **500** を返します:

```
The requested module '/_nuxt/@fs/.../@harmoniclabs/uplc/dist/index.js'
does not provide an export named 'Application'
```

除外された package はそのまま配信されるため、Vite はその import をたどって `@harmoniclabs/uplc` に到達します。この package は CommonJS であり、除外された package を*経由してのみ*到達できるため Vite はこれも事前バンドルしません。結果として CJS-as-ESM として配信され、解析可能な named export が存在しない状態になります。

leaf dependency を force-include して、CJS→ESM の interop 付きで Vite に事前バンドルさせてください。pnpm workspace ではベアな specifier が app のルートから解決できないため、ネストした `importer > dep` 構文を使います:

```typescript
optimizeDeps: {
  exclude: ['@hydra-sdk/cardano-wasm', '@hydra-sdk/core', '@hydra-sdk/transaction'],
  include: [
    '@hydra-sdk/core > @harmoniclabs/uplc',
    '@hydra-sdk/core > @harmoniclabs/plutus-data',
    '@hydra-sdk/core > @scure/base',
    '@hydra-sdk/core > axios',
    '@hydra-sdk/core > bip39',
    '@hydra-sdk/core > cbor-x'
  ]
}
```

その後、キャッシュを削除して dev server を再起動します:

```bash
rm -rf node_modules/.cache/vite .nuxt/cache
```

::warning
キャッシュの削除だけでは解決しません。このエラーは exclude と CommonJS の組み合わせから決定論的に発生するため、次の依存関係最適化のタイミングで再発します。
::

::note
別の CommonJS dependency で新たに `does not provide an export named …` エラーが出た場合は、`@hydra-sdk/core > <that-package>` を `include` リストに追加してください。
::

## Next.js の設定

Next.js は `next.config.js` で設定します。

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  webpack: (config, { isServer }) => {
    if (!isServer) {
      config.experiments = {
        ...config.experiments,
        asyncWebAssembly: true,
      }
      
      config.resolve.fallback = {
        ...config.resolve.fallback,
        crypto: false,
        stream: false,
        util: false,
        buffer: require.resolve('buffer')
      }
    }
    
    return config
  },
  
  // Disable static optimization for wallet pages
  experimental: {
    esmExternals: 'loose'
  }
}

module.exports = nextConfig
```

app ディレクトリを使う Next.js 13 以降では、`globals.d.ts` も作成します。

```typescript
declare global {
  var Buffer: typeof import('buffer').Buffer
}

export {}
```
