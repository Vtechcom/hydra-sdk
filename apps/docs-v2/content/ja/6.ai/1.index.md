これらのドキュメントは、AIアシスタントやLLMツールで利用されることを想定して作られています。3つのアクセス方法が標準で提供されています。MCPサーバー、`llms.txt`ファイル、そしてページごとの生markdownです。

## MCPサーバー

[Model Context Protocol](https://modelcontextprotocol.io)サーバーが`/mcp`（`https://hydrasdk.com/mcp`）でstreamable HTTP経由で公開されており、AIアシスタントは推測する代わりにドキュメントを直接照会できます。このサーバーは**Hydra SDK**という名前で、2つのツールを提供します。

| ツール | 目的 |
| --- | --- |
| `list-pages` | すべてのドキュメントページをタイトル、パス、説明とともに一覧表示します。正確なページが分からないときに探索や検索に使います。 |
| `get-page` | パスを指定して特定ページの完全なmarkdownを取得します（例: `/getting-started/installation`）。 |

典型的な流れは次のとおりです。まず`list-pages`を呼んで正しいパスを見つけ、次に`get-page`でそれを読みます。

### 接続

::code-group
```bash [Claude Code]
claude mcp add --transport http hydra-sdk https://hydrasdk.com/mcp
```

```json [mcp.json]
{
  "mcpServers": {
    "hydra-sdk": {
      "url": "https://hydrasdk.com/mcp"
    }
  }
}
```
::

::tip
ドキュメントをローカルで実行する場合（`pnpm dev`、ポート3003）、MCPサーバーは`http://localhost:3003/mcp`にあります。dev サーバーは起動時に**Install Nuxt MCP server**のディープリンクを表示します。それを開くと、サーバーがエディターに自動で登録されます。
::

## llms.txt

[llms.txt](https://llmstxt.org)の規約に従い、2つのファイルがLLMにドキュメント全体をコンテキストとして提供します。

- **[/llms.txt](https://hydrasdk.com/llms.txt)** — リンクと説明付きの全ページのインデックスです。
- **[/llms-full.txt](https://hydrasdk.com/llms-full.txt)** — ドキュメント全体を1つのファイルに連結したものです。

LLM対応のツールにいずれかのURLを指定するか、内容をチャットに貼り付けて、Hydra SDKに関する完全なコンテキストをモデルに与えてください。

## 生のmarkdown

任意のページパスに`/raw/`プレフィックスを付けて`.md`を追加すると、そのクリーンなmarkdownソースが得られます。単一ページをモデルにパイプするのに便利です。

```bash
curl https://hydrasdk.com/raw/getting-started/installation.md
```

生エンドポイントは**locale対応**です。localeをプレフィックスに付けると翻訳済みページを取得できます。

```bash
curl https://hydrasdk.com/raw/vi/getting-started/installation.md
curl https://hydrasdk.com/raw/ja/getting-started/installation.md
```
