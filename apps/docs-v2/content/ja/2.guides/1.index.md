これらのガイドは実践的でタスク指向のウォークスルーです。それぞれが目標から動作するコードへとあなたを導きます。概念的な背景については [Concepts](/concepts) を、正確なシグネチャについては [API Reference](/api) を参照してください。

::card-group
  ::card{title="ウォレットアプリを構築する" icon="i-lucide-wallet" to="/guides/build-wallet-app"}
  完全なウォレットアプリケーションをスキャフォールドします。React または Vue でクローンして即実行するか、サービス層アーキテクチャで自分で構築します。
  ::

  ::card{title="トランザクションを構築する" icon="i-lucide-file-signature" to="/guides/transactions"}
  トランザクションを構築、署名、送信します。マルチシグ署名や Plutus のロック/アンロックも含みます。
  ::

  ::card{title="トークンのミント & バーン" icon="i-lucide-coins" to="/guides/mint-burn-tokens"}
  ミントポリシーとメタデータを使って、ネイティブトークンを作成・破棄します。
  ::

  ::card{title="Hydra インテグレーション" icon="i-lucide-network" to="/guides/hydra-integration"}
  Hydra Head に接続し、トランザクションを送信し、よくある落とし穴に対処します。
  ::

  ::card{title="ユーティリティ クックブック" icon="i-lucide-wrench" to="/guides/utilities-cookbook"}
  datum、redeemer、ポリシー、時刻/スロット変換、プロバイダーのためのレシピ集。
  ::

  ::card{title="cardano-cli キーをインポートする" icon="i-lucide-key-round" to="/guides/cardano-cli-keys"}
  `cardano-cli` でキーを生成し、SDK に読み込みます。
  ::
::
