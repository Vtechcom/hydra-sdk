Hydra Head 内のトランザクションは Layer 1 と同様に動作しますが、はるかに高速に実行され、手数料は最小限です。このガイドでは、Hydra でトランザクションを構築、送信、追跡する方法を説明します。

## Hydra のトランザクションを理解する

### Layer 1 との主な違い

| 項目 | Layer 1 | Hydra Head |
|--------|---------|------------|
| 確定時間 | 20 秒以上 | 1 秒未満 |
| トランザクション手数料 | 約 0.17 ADA | ごくわずか |
| スループット | 約 100 TPS | 1,000 TPS 以上 |
| スマートコントラクト | 完全な Plutus | 完全な Plutus (isomorphic) |
| ファイナリティ | 2〜3 分 | 即時 |

### Hydra におけるトランザクションのライフサイクル
```mermaid
graph TD
  A[1. Build Transaction] --> B[2. Sign with Private Key]
  B --> C["3. Submit to Hydra Head (via WebSocket)"]
  C --> D["4. Snapshot Updated (<1s)"]
  D --> E[5. Transaction Confirmed]
```

## Hydra でトランザクションを構築・送信する

### 1. 前提条件
Hydra Head にトランザクションを送信するには、Head が稼働しており、Hydra ノードに接続されている必要があります（NodeJS playground の例では WebSocket を介して接続します）。

### 2. Head 内の UTxO / 資産を確認する

```ts
// src/start-bridge.ts
import { HydraBridge } from '@hydra-sdk/bridge'
async function main() {
  const bridge = new HydraBridge({
    url: 'ws://localhost:4001'
  })
  const connected = await bridge.connect()
  if (!connected) {
    throw new Error('Failed to connect to Hydra node')
  }
  console.log('>>> Connected to Hydra node')

  const utxoObj = await bridge.querySnapshotUtxo()
  console.log('>>> Snapshot UTxO:', utxoObj)
}
main()
```

### 3. トランザクションを構築する

```ts
// src/build-tx.ts
import { HydraBridge } from '@hydra-sdk/bridge'
import { Resolver } from '@hydra-sdk/core'
import { TxBuilder } from '@hydra-sdk/transaction'
import { wallet, walletAddress } from './common'

async function main() {
  const bridge = new HydraBridge({
    url: 'ws://localhost:4001'
  })
  const connected = await bridge.connect()
  if (!connected) {
    throw new Error('Failed to connect to Hydra node')
  }
  console.log('>>> Connected to Hydra node')

  const utxoObj = await bridge.querySnapshotUtxo()
  console.log('>>> Snapshot UTxO:', utxoObj)

  const addrUtxos = await bridge.queryAddressUTxO(walletAddress)
  const txBuilder = new TxBuilder({
    isHydra: true,
    params: {
      minFeeA: 0,
      minFeeB: 0
    }
  })
  const tx = await txBuilder
    .setInputs(addrUtxos)
    .addOutput({
      address: walletAddress, // destination address
      amount: [{ unit: 'lovelace', quantity: String(2_000_000) }]
    })
    .changeAddress(walletAddress)
    .complete()

  const signedCbor = await wallet.signTx(tx.to_hex())
  const txId = Resolver.resolveTxHash(signedCbor)

  const rs = await bridge.submitTxSync({
    cborHex: signedCbor,
    type: 'Witnessed Tx ConwayEra',
    description: 'Test Hydra tx from NodeJS Playground',
    txId: txId
  })
  console.log('>>> Submit tx result:', rs)
}
main()
```

### 別の方法: コールバック形式の送信 (v1.3.0+)

`submitTx` は非ブロッキングのバリアントです。確定を `await` したくない場合に便利です:

```typescript
bridge.submitTx(
	signedTx,
	(error, result) => {
		if (error) {
			console.error('Rejected:', error.reason)
			return
		}
		console.log('Snapshot #', result!.result?.snapshot?.number)
	}
)
```
