decommit は、アクティブな Hydra Head から UTxO を Cardano Layer 1 へ引き出すプロセスです。これにより Layer 2 環境を離れ、資産をメインチェーン上で利用できるようになります。

## decommit を理解する

### decommit とは何か？

decommit は Head を開いたまま、Hydra Head から UTxO を取り除いて Layer 1 へ戻します。資金を高速レーンから本線へ戻すようなものと考えてください。

```
┌─────────────────────────────────────────┐
│         Hydra Head (Layer 2)            │
│                                         │
│  Your UTxOs: [UTxO1, UTxO2, UTxO3]      │
│                                         │
└──────────────┬──────────────────────────┘
			   │
			   │ DECOMMIT
			   │ (Remove from Head, return to L1)
			   │
┌──────────────▼──────────────────────────┐
│         Cardano Layer 1                 │
│                                         │
│  Available: [UTxO1, UTxO2, UTxO3]       │
│  Back on main chain                     │
│                                         │
└─────────────────────────────────────────┘
```


## decommit のプロセス

### いつ decommit すべきか？
Head を閉じずに Hydra Head から資産を引き出したいときに decommit を行います。例えば、資産を Layer 1 ウォレットに戻したり、一部を引き出して Cardano メインネットで使いたい場合です。

### decommit の手順
1. Hydra Bridge を介して Hydra ノードに接続します。
2. Hydra Head 内の現在の UTxO をクエリします。
3. 引き出したい UTxO を使って decommit トランザクションを構築します。
4. ウォレットでトランザクションに署名します。
5. decommit トランザクションを Hydra ノードに送信します。
6. snapshot のステータスを監視し、UTxO が Layer 1 に戻ったことを確認します。

```ts
// nodejs-playground/src/hydra/decommit.ts
import { TxBuilder } from '@hydra-sdk/transaction'
import { HydraBridge } from '@hydra-sdk/bridge'
import { wallet, walletAddress } from './common'
import { Resolver } from '@hydra-sdk/core'

async function main() {
	const bridge = new HydraBridge({
		url: 'ws://localhost:4001'
	})
	const connected = await bridge.connect()
	if (!connected) {
		throw new Error('Failed to connect to Hydra node')
	}
	console.log('>>> Connected to Hydra node')

	const utxoObj = await bridge.querySnapshotUtxo()

	const addrUtxos = await bridge.queryAddressUTxO(walletAddress)
	const txBuilder = new TxBuilder({
		isHydra: true,
		params: {
			minFeeA: 0,
			minFeeB: 0
		}
	})
	const tx = await txBuilder
		.setInputs([
			addrUtxos[0] // utxo to decommit
		])
		.addOutput({
			address: walletAddress,
			amount: [{ unit: 'lovelace', quantity: String(2_000_000) }]
		})
		.changeAddress(walletAddress)
		.complete()

	const signedCbor = await wallet.signTx(tx.to_hex())
	const txId = Resolver.resolveTxHash(signedCbor)

	const rs = await bridge.decommit({
		cborHex: signedCbor,
		txId,
		timeout: 30000
	})
	console.log('>>> Submit tx result:', rs)
}
main()
```

### ベストプラクティス
- 不要な Layer 1 手数料を避けるため、必要なときにのみ decommit してください。
- ミスによる資産の損失を避けるため、decommit する前に UTxO を慎重に確認してください。
- decommit 後は snapshot のステータスを監視し、UTxO が Layer 1 に戻ったことを確認してください。
- Head が閉じられると、すべての UTxO は自動的に Layer 1 に戻されます（手動での decommit は不要です）。
