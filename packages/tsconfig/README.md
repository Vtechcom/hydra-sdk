# @hydra-sdk/tsconfig

Shared TypeScript config for Hydra SDK monorepo. Extends latest TS with strict mode + modern features.

## Usage

```bash
pnpm add -D @hydra-sdk/tsconfig
```

```json
{
  "extends": "@hydra-sdk/tsconfig"
}
```
