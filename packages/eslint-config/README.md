# @hydra-sdk/eslint-config

Shared ESLint config for the Hydra SDK monorepo: Airbnb + TypeScript + Prettier.

## Usage

```bash
pnpm add -D @hydra-sdk/eslint-config
```

```json
{
  "extends": ["@hydra-sdk/eslint-config"]
}
```
