Locked

  • Dev-only package
  • Mock/replay + real offline node
  • Parallel-safe isolated instances
  • Versioned fixture provenance
  • Explicit binary resolution
  • Bridge-major compatibility matrix
  • Deterministic test wallet/UTxO builders

Rejected

  • Mock-only test library: wire format sẽ drift
  • Bundled 428 MB binary: package quá nặng
  • Surprise network download: CI không reproducible
  • Shared singleton Head: snapshot và UTxO race
  • Hydra protocol simulator: tạo source of truth thứ hai
  • L1 devnet, consensus và load harness trong V1
Surviving limits

Những điều package này cố ý không hứa.

NO L1

Offline mode không test deposit, decommit, close, contest, fanout hoặc unsynced states. Các đường này vẫn cần devnet riêng.

BINARY REQUIRED

Real-node tier cần hydra-node phù hợp platform. Downloader nếu có phải explicit, checksum-pinned và cacheable.

FIXTURES AGE

Mỗi Hydra release có thể đổi payload. Fixture matrix và conformance CI là chi phí duy trì bắt buộc, không phải việc làm một lần.
