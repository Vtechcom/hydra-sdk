@hydra-sdk/evaluator là evaluator transaction-level chạy offline cho Plutus: đủ context, đủ cost accounting, trả đúng IEvaluator — nhưng chỉ nhận claim tương đương node sau differential conformance.

Product lock

Không phải chạy một UPLC program. Phải đánh giá cả transaction.

01 / JOB

Real exUnits without a provider

Local dev, CI và browser worker có thể tính budget cho TxBuilder.complete() mà không cần Blockfrost key, Ogmios endpoint hoặc network.

02 / BOUNDARY

Context is mandatory

Input references chưa đủ. Evaluator cần UTxO, datum, reference script, era, slot/time, protocol parameters và cost models để dựng đúng ScriptContext.

03 / CLAIM

Deterministic, then conformant

Kết quả deterministic khi context được pin. “Node-equivalent” chỉ được nói cho version/corpus đã differential-test và công bố trong matrix.

Evaluation pipeline

CBOR vào. Context đầy đủ. Budget có provenance.

01

Decode

Transaction body, witness set, redeemer pointers, inline/reference scripts và datum.

02

Resolve

Lookup UTxO và missing ledger data từ local context source hoặc explicit additional inputs.

03

Execute

Dựng ScriptContext đúng era; chạy Plutus V1/V2/V3 bằng engine có cost accounting.

04

Report

Trả EvalAction[]; detailed mode thêm logs, script hash, context fingerprint và failure phase.

Fail closed: thiếu UTxO, datum, reference script, cost model hoặc era context là typed error. Không network fetch ngầm, không budget 0, không placeholder.
Proposed surface

Một adapter cho TxBuilder, một đường sâu để debug.

@hydra-sdk/evaluator · API direction, not implementation
import { createEvaluator } from '@hydra-sdk/evaluator'

const evaluator = createEvaluator({
  context: localLedgerContext,
  protocol: pinnedProtocolContext,
  diagnostics: 'errors'
})

const tx = await new TxBuilder({
  evaluator,
  txEvaluationMultiplier: 1.1
}).complete()

// Mesh-compatible path
await evaluator.evaluateTx(txHex, additionalUtxos, additionalTxs)

// Debug / conformance path
await evaluator.evaluateTxDetailed(txHex, { additionalUtxos })
V1 decision

Hỗ trợ ít purpose hơn, nhưng hỗ trợ đến nơi.

Khóa vào V1

  • Plutus V1, V2, V3.
  • SPEND và MINT end-to-end.
  • Node + browser/worker runtime.
  • Typed failures và bounded diagnostics.
  • Differential corpus với oracle version công bố.
  • Engine đặt sau adapter có thể thay thế.

Loại khỏi V1

  • CERT, REWARD, VOTE, PROPOSE.
  • Provider HTTP và silent fallback.
  • Submission, fee balancing, script compiler.
  • Step debugger và general-purpose UPLC playground.
  • Hydra ledger validation.
  • Claim thay thế cardano-node cho acceptance production.

Delivery gate

Chứng minh engine trước khi ổn định API.

SPIKE A

Real V3 spend

Một fixture script spend thật với datum, redeemer, resolved UTxO và oracle budget/failure.

SPIKE B

Real mint

Một minting policy thật để khóa redeemer index, policy ordering và ScriptContext.

GO / NO-GO

Match or change engine

Nếu semantics hoặc cost accounting không khớp corpus đại diện, dừng package hoặc thay engine trước khi public API stable.
